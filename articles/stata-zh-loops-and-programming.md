## `capture`

运行代码，出错时不中断

Stata

``` stata
capture command
```

R `tidystata`

``` r

capture(expression)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
成功时返回表达式结果；出错时显示失败消息，并不可见地返回 NULL。quiet =
TRUE 抑制失败提示、警告和消息，但保留打印输出。使用 capture(data \<-
update(data)) 可在更新失败时保留原对象；data \<- capture(update(data))
会在出错时赋值为
NULL。代码块中的分步赋值保留最后完成的更新；整条管道只赋值一次时，失败会保留原对象。出错前的副作用不会回滚。这是对
Stata capture 的 R 适配，而 Stata 会抑制所有输出。

[Stata 参考](https://www.stata.com/manuals/pcapture.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `foreach`

对一些变量跑循环

Stata

``` stata
foreach v of varlist v1-v5 { generate `v'_sq = `v'^2 }
```

R `dplyr`

``` r

mutate(data, across(v1:v5, ~ .x^2, .names = "{col}_sq"))
```

across() 可以代替大部分对变量的循环；其他循环可用 for (v in names) { ...
}。

[Stata 参考](https://www.stata.com/manuals/pforeach.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `forvalues`

对一些变量跑循环（带有条件语句）

Stata

``` stata
forvalues i = 1/5 { generate v`i'_sq = v`i'^2 if v`i' > 0 }
```

R `dplyr`

``` r

mutate(data, across(v1:v5, ~ if_else(.x > 0, .x^2, NA), .names = "{col}_sq"))
```

[Stata 参考](https://www.stata.com/manuals/pforvalues.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

对一些变量跑循环（变量名中有特定数字）

Stata

``` stata
forvalues i = 6/10 { forvalues j = 3/5 { replace x_`i'_`j' = x_`i'_`j' + 1 } }
```

R `dplyr`

``` r

mutate(data, across(matches("^x_([6-9]|10)_[3-5]$"), ~ .x + 1))
```

用正则表达式选择变量名。只需要一个数字范围时，可用
varlist("x\_\[6-10\]\_\*")。

[Stata 参考](https://www.stata.com/manuals/pforvalues.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `set`

设定随机数种子

Stata

``` stata
set seed 2024
```

R `base`

``` r

set.seed(2024)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

Stata 使用不同随机数流；相同数值种子不会复现相同随机数或抽样行。

参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/Random.html)
