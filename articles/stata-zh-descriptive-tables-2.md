## `tabulate`

统计单个类别变量频数

Stata

``` stata
tabulate g
```

R `tidystata`

``` r

tidystata::tab(data, g)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
存在缺失值时会单独列出一行，并在总体百分比旁给出有效百分比。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/tab.html)

使用整数频数权重制表

Stata

``` stata
tabulate g [fw=w]
```

R `tidystata`

``` r

tidystata::tab(data, g, .wt = w)
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/tab.html)

生成二维列联频数表

Stata

``` stata
tabulate g h
```

R `tidystata`

``` r

tidystata::tab2(data, g, h)
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/tab.html)

频数表中包含缺失类别

Stata

``` stata
tabulate g, missing
```

R `tidystata`

``` r

tidystata::tab(data, g)
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/tab.html)

生成完整类别指示变量组

Stata

``` stata
tabulate g, generate(d)
```

R `tidystata`

``` r

indicators <- tidystata::as_dummy(dplyr::select(data, g), g, .remove = TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
保留全部观测；类别缺失时各虚拟变量均为NA。R返回独立数据框并按类别命名；Stata的前缀d不是可替换的输出变量名。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/as_dummy.html)

频数表中包含缺失类别

Stata

``` stata
tabulate g, missing
```

R `base`

``` r

table(data$g,useNA='ifany')
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
将 R NA 列为独立类别；空字符串在 R 中仍是另一种值。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
