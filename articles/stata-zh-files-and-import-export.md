## `changeeol`

将文本文件换行统一为 Unix 格式

Stata

``` stata
changeeol source.txt destination.txt, eol(unix)
```

R `base`

``` r

writeBin(charToRaw(paste0(paste(readLines(src),collapse='\n'),'\n')),dst)
```

固定流程示例；更改时需同时调整对象名与列名。

[Stata 参考](https://www.stata.com/manuals/dchangeeol.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Stata

``` stata
changeeol source.txt destination.txt, eol(windows)
```

``` r

writeBin(charToRaw(paste0(paste(readLines(src),collapse='\r\n'),'\r\n')),dst)
```

固定流程示例；更改时需同时调整对象名与列名。

## `checksum`

计算文件完整性摘要

Stata

``` stata
checksum sample.txt
```

R `tools`

``` r

tools::md5sum(src)
```

MD5 是工作流程替代；Stata checksum 使用 POSIX
CRC，摘要数值不可直接比较。

[Stata 参考](https://www.stata.com/manuals/dchecksum.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/tools/html/md5sum.html)

将文件摘要保存为附属文本文件

Stata

``` stata
checksum sample.txt, saving(sample.sum)
```

R `tools`

``` r

digest <- tools::md5sum(src); writeLines(unname(digest),dst)
```

保存 R MD5 附属文件而非 Stata .sum 文件；Stata 无法将其作为 CRC
附属文件验证。

[Stata 参考](https://www.stata.com/manuals/dchecksum.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/tools/html/md5sum.html)

## `copy`

复制本地文件到新路径

Stata

``` stata
copy source.txt destination.txt
```

R `base`

``` r

file.copy(src,dst,overwrite=FALSE)
```

此可运行示例中的 src 与 dst 为临时路径；不涉及网络传输。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

使用本地副本覆盖目标文件

Stata

``` stata
copy source.txt destination.txt, replace
```

R `base`

``` r

file.copy(src,dst,overwrite=TRUE)
```

仅在新建临时文件中演示覆盖。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `filefilter`

替换小文本文件中的指定文本

Stata

``` stata
filefilter source.txt destination.txt, from("old") to("new")
```

R `base`

``` r

writeLines(gsub('old','new',readLines(src),fixed=TRUE),dst,useBytes=TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
适用于小文件的逐行流程；不处理二进制模式或大文件流式操作。

[Stata 参考](https://www.stata.com/manuals/dfilefilter.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

替换文本文件中的制表分隔符

Stata

``` stata
filefilter source.txt destination.txt, from(\t) to(";")
```

R `base`

``` r

writeLines(gsub('\t',';',readLines(src),fixed=TRUE),dst,useBytes=TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
用于小文本文件的字面替换；表格中的带引号分隔符需使用解析器。

[Stata 参考](https://www.stata.com/manuals/dfilefilter.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
