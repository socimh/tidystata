Cox proportional-hazards diagnostic

Stata

``` stata
estat phtest, detail
```

R `survival`

``` r

survival::cox.zph(fit, transform = "identity")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
After the same Cox fit, identity time transform matches the Stata
default time scale. Both assess proportional hazards using Schoenfeld
residuals. Current survival uses a score-test implementation, so
finite-sample statistics can differ from Stata residual-correlation
tests.

reference](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/00Index.html)

## `stset`

Declare survival-time data

Stata

``` stata
stset time, failure(died)
```

R `survival`

``` r

survival::Surv(data$time, data$died)
```

R has no declaration step: Surv(time, died) goes on the left of each
model formula.

[Stata reference](https://www.stata.com/manuals/ststset.pdf) · [R
reference](https://cran.r-project.org/package=survival)

Delayed-entry counting-process response

Stata

``` stata
stset time, enter(time entry) failure(event)
```

``` r

survival::Surv(data$entry, data$time, data$event)
```

Surv(entry,time,event) uses (entry,time\] counting-process intervals.

interval, with event coded 0/1.

## `stsplit`

Split risk intervals at fixed cut points

Stata

``` stata
stsplit period, at(3 6)
```

R `survival`

``` r

{ Surv <- survival::Surv; out <- survival::survSplit(Surv(time, event) ~ ., data = data, cut = c(3, 6), start = "start", end = "time", event = "event", episode = "period"); out$period <- c(0, 3, 6)[out$period]; out }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Zero-entry single-record subjects with an id column. R splits at 3 and 6
and converts the episode index to Stata lower-boundary labels 0,3,6.
Events remain on the final risk interval.

[Stata reference](https://www.stata.com/manuals/ststsplit.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/00Index.html)
