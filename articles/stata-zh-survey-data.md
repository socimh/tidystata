## `svy`

考虑抽样设计的 logit 模型

Stata

``` stata
svy: logit y x
```

R `survey`

``` r

survey::svyglm(y ~ x, design = design, family = quasibinomial())
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
先匹配抽样设计和缺失排除；R 与 Stata 的单 PSU
层规则、自由度和置信区间变换可能不同。

[Stata 参考](https://www.stata.com/manuals/svysvy.pdf) · [R
参考](https://cran.r-project.org/package=survey)

另有 2 个示例及替代实现

子总体估计

Stata

``` stata
svy, subpop(rural): mean x
```

``` r

design |> filter(rural == 1) |> summarise(x = srvyr::survey_mean(x, na.rm = TRUE))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

先匹配抽样设计和缺失排除；R 与 Stata 的单 PSU
层规则、自由度和置信区间变换可能不同。

[Stata 参考](https://www.stata.com/manuals/svysvy.pdf) · [R
参考](https://cran.r-project.org/package=srvyr)

## `svyset`

声明抽样设计

Stata

``` stata
svyset psu [pweight = wt], strata(stratum)
```

R `srvyr`

``` r

design <- srvyr::as_survey_design(data, ids = psu, strata = stratum, weights = wt, nest = TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
分层 PSU 概率加权设计；与 Stata 一样把 PSU
标识嵌套于层内。推断需使用相同样本、单 PSU 层规则和设计自由度。

[Stata 参考](https://www.stata.com/manuals/svysvyset.pdf) · [R
参考](https://cran.r-project.org/web/packages/srvyr/srvyr.pdf)
