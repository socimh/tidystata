## `scatter`

Scatter plot

Stata

``` stata
scatter y x
```

R `ggplot2`

``` r

ggplot(data, aes(x, y)) + geom_point()
```

[Stata
reference](https://www.stata.com/manuals/g-2graphtwowayscatter.pdf) · [R
reference](https://cran.r-project.org/package=ggplot2)

23 more examples and alternatives

Label the points

Stata

``` stata
scatter y x, mlabel(name)
```

R `ggplot2`

``` r

ggplot(data, aes(x, y, label = name)) + geom_point() + geom_text()
```

[Stata
reference](https://www.stata.com/manuals/g-2graphtwowayscatter.pdf) · [R

Scatter plot with ggplot2

Stata

``` stata
scatter y x
```

R `ggplot2`

``` r

ggplot2::ggplot(data, ggplot2::aes(x, y)) + ggplot2::geom_point()
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Maps the stated axes and layer; line sorts by x in ggplot while Stata
uses sort here. Plot themes, axis expansion, missing-point warnings and
facet scales follow R defaults.

[Stata reference](https://www.stata.com/manuals/g-2graph.pdf) · [R
reference](https://ggplot2.tidyverse.org/reference/index.html)

## `serrbar`

Plot supplied estimates and standard errors

Stata

``` stata
serrbar y se x
```

R `ggplot2`

``` r

ggplot2::ggplot(data, ggplot2::aes(x, y)) + ggplot2::geom_errorbar(ggplot2::aes(ymin = y - se, ymax = y + se)) + ggplot2::geom_point()
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Here se is a supplied standard-error variable; Stata serrbar defaults to
one standard error. Rename the variable to suit your data.

[Stata reference](https://www.stata.com/manuals/g-2graph.pdf) · [R
reference](https://ggplot2.tidyverse.org/reference/index.html)

## `spikeplot`

Plot spikes for the frequencies of distinct values

Stata

``` stata
spikeplot z
```

R `graphics`

``` r

{ counts <- as.data.frame(table(data$z)); graphics::plot(as.numeric(as.character(counts$Var1)), counts$Freq, type = "h") }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Draws one spike for each observed value with its count. Axis ticks,
spike widths, handling of missing values and graphics device styling
differ from Stata spikeplot.

[Stata reference](https://www.stata.com/manuals/g-2graph.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-release/library/graphics/html/00Index.html)
