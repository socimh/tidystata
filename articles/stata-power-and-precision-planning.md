## `power`

Calculate power for a fixed-size onemean t test

Stata

``` stata
power onemean 0 0.5, sd(1) n(40)
```

R `stats`

``` r

stats::power.t.test(n=40,delta=0.5,sd=1,type="one.sample",sig.level=0.05, strict = TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Noncentral t power counts both tails for two-sided tests. R n is
observations/pairs for one-sample/paired tests and per group for two
samples; round required n upward.

[Stata reference](https://www.stata.com/manuals/pss.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/power.t.test.html)

Calculate power for an overall three-predictor R squared test

Stata

``` stata
power rsquared 0.1, n(100) ntested(3)
```

R `pwr`

``` r

pwr::pwr.f2.test(u=3,v=96,f2=0.1/(1-0.1))
```

Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
f2=(R2_full-R2_reduced)/(1-R2_full); residual df is N minus all
predictors minus one.

Calculate power for incremental explained variance

Stata

``` stata
power rsquared 0.2 0.3, n(120) ntested(2) ncontrol(3)
```

R `stats`

``` r

stats::pf(stats::qf(0.95, df1 = 2, df2 = 114), df1 = 2, df2 = 114, ncp = 120 * (0.3 - 0.2) / (1 - 0.3), lower.tail = FALSE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Two tested and three control predictors: residual df = 120 - 2 - 3 - 1;
noncentrality = 120 \* (0.3 - 0.2) / (1 - 0.3).

``` stata
power twoproportions 0.3, n(200) power(0.8)
```

R `stats`

``` r

stats::power.prop.test(n=100,p1=0.3,p2=NULL,power=0.8,sig.level=0.05, strict = TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Pooled-null normal approximation without continuity correction; R n is
per group and two-sided power counts both rejection tails.

[Stata reference](https://www.stata.com/manuals/pss.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/power.prop.test.html)
