## `reshape`

Wide to long

Stata

``` stata
reshape long var, i(id) j(year)
```

R `tidyr`

``` r

tidyr::pivot_longer(data, tidyselect::starts_with("var"), names_to = "year", names_prefix = "var", names_transform = list(year = as.integer), values_to = "var")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Converts numeric suffixes to integer year values, matching reshape long
without string. pivot_longer() returns a text year without
names_transform and does not enforce reshape i()/j() uniqueness
constraints.

[Stata reference](https://www.stata.com/manuals/dreshape.pdf) · [R
reference](https://cran.r-project.org/package=tidyr)

Long to wide

Stata

``` stata
reshape wide var, i(id) j(year)
```

R `tidyr`

``` r

pivot_wider(data, names_from = year, values_from = var, names_prefix = "var")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Duplicate keys can create list-columns in pivot_wider(); Stata reshape
wide rejects duplicate i()/j() combinations. Validate keys first.

[Stata reference](https://www.stata.com/manuals/dreshape.pdf) · [R
reference](https://cran.r-project.org/package=tidyr)

2 more examples and alternatives

Reshape repeated measurements to long form with base R

Stata

``` stata
reshape long var, i(id) j(year)
```

R `stats`

``` r

stats::reshape(data, direction = "long", varying = list(c("var2000", "var2001")), v.names = "var", timevar = "year", times = c(2000, 2001), idvar = "id")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Explicitly list the wide columns and time values. This fixed workflow
uses var2000 and var2001; adapt those names to your data.

[Stata reference](https://www.stata.com/manuals/dreshape.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/reshape.html)

Reshape repeated measurements to wide form with base R

Stata

``` stata
reshape wide var, i(id) j(year)
```

R `stats`

``` r

stats::reshape(data, direction = "wide", v.names = "var", timevar = "year", idvar = "id", sep = "")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Requires one row per id/year combination. R row ordering and attributes
differ from Stata; compare keys and values explicitly.

[Stata reference](https://www.stata.com/manuals/dreshape.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/reshape.html)
