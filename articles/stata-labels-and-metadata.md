## `char`

Inspect custom column characteristics

Stata

``` stata
char list x[]
```

R `base`

``` r

attributes(data$x)
```

Returns all R attributes, including any custom metadata.

[Stata reference](https://www.stata.com/manuals/p.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Store a custom column characteristic

Stata

``` stata
char x[source] "questionnaire"
```

R `base`

``` r

attr(data$x,'source') <- 'questionnaire'
```

R attributes serve as local metadata; many transformations do not
preserve arbitrary attributes.

[Stata reference](https://www.stata.com/manuals/p.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `decode`

Decode numeric value labels to text

Stata

``` stata
decode x, generate(text)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, text = tidystata::decode(x))
```

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/type_conversion.html)

## `encode`

Encode nonempty categories in sorted order

Stata

``` stata
encode s, generate(code)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, code = tidystata::encode(s))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Character input gets fresh codes from 1 in UTF-8 radix order; NA and
empty strings are missing. Locale-specific Stata ordering can differ.
Factor input preserves existing indices and all levels.

[Stata reference](https://www.stata.com/manuals/dencode.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/type_conversion.html)

## `label`

Attach a numeric value-label dictionary

Stata

``` stata
label values x yesno
```

R `haven`

``` r

data$x <- haven::labelled(data$x,labels=yesno)
```

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://haven.tidyverse.org/reference/index.html)

Attach a dataset label

Stata

``` stata
label data "Research sample"
```

R `base`

``` r

attr(data,'label') <- 'Research sample'
```

Fixed workflow example; adapt the object and column names together.

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Define a reusable value-label mapping

Stata

``` stata
label define yesno 1 "No" 2 "Yes"
```

R `base`

``` r

yesno <- c(No=1,Yes=2)
```

R stores the mapping as a named vector; attach it separately to each
labelled column.

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R

## `labelbook`

Inspect value-label dictionaries by column

Stata

labelbook
```

lapply(data,function(z) attr(z,'labels'))
```

## `labmask`

Assign existing text values as numeric value labels

Stata

``` stata
labmask code, values(text)
```

R `haven`

``` r

dictionary <- unique(data[c('code','text')]); stopifnot(!anyDuplicated(dictionary$code)); data$code <- haven::labelled(data$code,stats::setNames(dictionary$code,dictionary$text))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Requires a unique text label per observed numeric code; this preserves
supplied numeric codes rather than alphabetically encoding text.

[Stata
reference](https://journals.sagepub.com/doi/pdf/10.1177/1536867X0800800208)
· [R reference](https://haven.tidyverse.org/reference/index.html)

notes x: Measured at baseline

attr(data$x,'notes') <- 'Measured at baseline'

## `numlabel`

Prefix each label with its numeric code

Stata

``` stata
numlabel, add
```

R `base`

``` r

labs <- attr(data$x,'labels'); names(labs) <- paste0(unname(labs),'. ',names(labs)); attr(data$x,'labels') <- labs
```

Fixed workflow example; adapt the object and column names together.

[Stata reference](https://www.stata.com/manuals/dlabelbook.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Remove a known numeric-code label prefix

Stata

``` stata
numlabel, remove
```

R `base`

``` r

labs <- attr(data$x,'labels'); names(labs) <- sub('^[0-9]+[.] ','',names(labs)); attr(data$x,'labels') <- labs
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Targets the demonstrated positive-integer prefix format; other masks
require a matching pattern.

[Stata reference](https://www.stata.com/manuals/dlabelbook.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `uselabel`

Make a value-label dictionary table

Stata

``` stata
uselabel using sample.dta, clear
```

R `base`

``` r

labs <- attr(data$x,'labels'); dictionary <- data.frame(lname='x',value=unname(labs),label=names(labs),trunc=0L)
```

Uses an already imported labelled column. R has no separate Stata
label-definition name; lname uses the column name.

[Stata reference](https://www.stata.com/manuals/dlabelbook.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
