## `assert`

条件不成立时报错停止

Stata

``` stata
assert x > 0
```

R `tidystata`

``` r

assert(data, x > 0)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
FALSE 和 NA
都视为失败。错误会逐条件报告失败数量和前五个失败行号；成功时不可见地返回原数据，可用于管道。与
Stata 不同，x 缺失时 x \> 0 不通过；要采用 Stata 的行为，请用
assert(data, is.na(x) \| x \> 0)。

[Stata 参考](https://www.stata.com/manuals/dassert.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `confirm`

检查变量是否存在

Stata

``` stata
confirm variable x
```

R `base`

``` r

stopifnot("x" %in% names(data))
```

[Stata 参考](https://www.stata.com/manuals/pconfirm.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/stopifnot.html)

## `count`

数据的行数

Stata

``` stata
count
```

R `base`

``` r

nrow(data)
```

[Stata 参考](https://www.stata.com/manuals/dcount.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/nrow.html)

另有 1 个示例及替代实现

计算满足条件的行数

Stata

``` stata
count if x > 0
```

R `base`

``` r

sum(data$x > 0, na.rm = TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
Stata 数值缺失比较时大于所有有限数；R 比较返回
NA。应先明确处理缺失，再使用条件。

[Stata 参考](https://www.stata.com/manuals/dcount.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/sum.html)

## `distinct`

查看某些变量未重复行的数目

Stata

``` stata
distinct x1 x2, joint
```

R `dplyr`

``` r

nrow(distinct(data, x1, x2))
```

[Stata 参考](https://www.stata-journal.com/article.html?article=dm0042)
· [R 参考](https://cran.r-project.org/package=dplyr)

## `duplicates`

列出重复个案

Stata

``` stata
duplicates list x1 x2
```

R `tidystata`

``` r

duplicates_list(data, x1, x2)
```

[Stata 参考](https://www.stata.com/manuals/dduplicates.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

报告重复个案

Stata

``` stata
duplicates report x1 x2
```

R `tidystata`

``` r

duplicates_report(data, x1, x2)
```

[Stata 参考](https://www.stata.com/manuals/dduplicates.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

Stata

duplicates tag x1 x2, generate(dup)

R `tidystata`

``` r

duplicates_tag(data, x1, x2, .name = "dup")
```

[Stata 参考](https://www.stata.com/manuals/dduplicates.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `isid`

检查变量能否唯一识别个案

Stata

``` stata
isid id wave
```

R `tidystata`

``` r

isid(data, id, wave)
```

有效键会显示确认消息，并不可见地返回原数据。默认拒绝缺失键值和空字符串；.missing
= TRUE 允许这些值，但仍要求键组合唯一。可用 suppressMessages()
静默检查。

[Stata 参考](https://www.stata.com/manuals/disid.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

mdesc

summ(data, .stat = "missing")

## `misstable`

缺失值模式

Stata

``` stata
misstable patterns
```

R `tidystata`

``` r

misstable(data, .patterns = TRUE)
```

与 Stata 相同，1 表示有观测值，0 表示缺失。

[Stata 参考](https://www.stata.com/manuals/rmisstable.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

每个变量的缺失值数目

Stata

``` stata
misstable summarize
```

R `tidystata`

``` r

misstable(data)
```

base R：colSums(is.na(data))。

[Stata 参考](https://www.stata.com/manuals/rmisstable.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)
