## `capture`

Run code and keep its result without stopping on an error

Stata

``` stata
capture command
```

R `tidystata`

``` r

capture(expression)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Returns the expression's result on success; on error, emits a failure
message and returns invisible NULL. quiet = TRUE suppresses the notice,
warnings and messages, but keeps printed output. Use capture(data \<-
update(data)) to preserve an existing object if the update fails; data
\<- capture(update(data)) assigns NULL on error. Separate assignments in
a captured block keep the last completed update; a single assignment
around a failed pipeline keeps the original target. Earlier effects are
not rolled back. This adapts Stata capture, which suppresses all output.

[Stata reference](https://www.stata.com/manuals/pcapture.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `foreach`

Same calculation for several variables

Stata

``` stata
foreach v of varlist v1-v5 { generate `v'_sq = `v'^2 }
```

R `dplyr`

``` r

mutate(data, across(v1:v5, ~ .x^2, .names = "{col}_sq"))
```

across() replaces most variable loops; for other loops R has for (v in
names) { ... }.

[Stata reference](https://www.stata.com/manuals/pforeach.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `forvalues`

Loop with a condition

Stata

``` stata
forvalues i = 1/5 { generate v`i'_sq = v`i'^2 if v`i' > 0 }
```

R `dplyr`

``` r

mutate(data, across(v1:v5, ~ if_else(.x > 0, .x^2, NA), .names = "{col}_sq"))
```

[Stata reference](https://www.stata.com/manuals/pforvalues.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Loop over variables numbered in their names

Stata

``` stata
forvalues i = 6/10 { forvalues j = 3/5 { replace x_`i'_`j' = x_`i'_`j' + 1 } }
```

R `dplyr`

``` r

mutate(data, across(matches("^x_([6-9]|10)_[3-5]$"), ~ .x + 1))
```

A regular expression picks the names. varlist("x\_\[6-10\]\_\*") works
when only one number range is needed.

[Stata reference](https://www.stata.com/manuals/pforvalues.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Run code only if a condition holds

Stata

``` stata
if `x' > 0 { display "positive" }
```

``` r

if (x > 0) print("positive")
```

Quote it: findit("if"), because if is a reserved word in R.

## `set`

Make random numbers reproducible

Stata

``` stata
set seed 2024
```

R `base`

``` r

set.seed(2024)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
set_seed(.fn, seed) sets the seed inside a pipe; see the sample rows. R
and Stata use different random-number streams; the same numeric seed
does not reproduce the same draws or selected rows.

[Stata reference](https://www.stata.com/manuals/rsetseed.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/Random.html)
