## `boottest`

Null-imposed wild cluster bootstrap using rademacher weights

Stata

``` stata
boottest treat, cluster(group) reps(199) weighttype(rademacher) seed(128)
```

R `fwildclusterboot`

``` r

fwildclusterboot::boottest(fit, param = "treat", clustid = "group", B = 199, type = "rademacher", impose_null = TRUE, conf_int = FALSE, engine = "R-lean")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed workflow; adapt the named data columns explicitly. Small
replication count is a runnable example, not an analysis recommendation.
Align bootstrap variant, clustering and finite-sample correction.
Installed fwildclusterboot emits a one-time seeding-change warning; both
R and dqrng generators are explicitly seeded. fwildclusterboot 0.13
changed RNG seeding; seed-for-seed agreement with older versions is not
expected.

[Stata
reference](https://raw.githubusercontent.com/droodman/boottest/master/boottest.sthlp)
· [R
reference](https://s3alfisc.github.io/fwildclusterboot/reference/boottest.html)

## `cem`

Coarsened exact matching on a categorical covariate

Stata

``` stata
cem category (#0), treatment(treat)
```

R `MatchIt`

``` r

MatchIt::matchit(treat ~ category, data = transform(data, category = as.integer(category) - 1L), method = "cem", estimand = "ATT", cutpoints = list(category = 0))
```

Fixed workflow; adapt the named data columns explicitly. Matching
preprocessing only; categorical levels need no continuous cutpoints. For
continuous variables, explicitly match cutpoints and estimand rather
than relying on different software defaults.

[Stata reference](https://gking.harvard.edu/cem/) · [R
reference](https://cran.r-project.org/web/packages/MatchIt/MatchIt.pdf)

## `drdid`

Two-period panel doubly robust DiD ATT point estimate

Stata

``` stata
drdid y x, ivar(id) time(time) treatment(treated) dripw
```

R `DRDID`

``` r

DRDID::drdid(yname = "y", tname = "time", idname = "id", dname = "treated", xformla = ~x, data = data, panel = TRUE, boot = FALSE, inffunc = TRUE, estMethod = "trad", trim.level = 1)
```

Long data: exactly two periods per id, with time-invariant treated-group
and baseline x. DRDID estimates ATT and analytical influence-function
SE. trad selects logit ML plus OLS for dripw; normalized IPW matches
stdipw. trim.level=1 avoids silently trimming high propensity scores.
Require overlap, conditional parallel trends and no anticipation.

[Stata
reference](https://github.com/friosavila/csdid_drdid/blob/main/code/drdid.ado)
· [R reference](https://psantanna.com/DRDID/reference/drdid.html)

## `ivreghdfe`

Instrumental variables with two absorbed effects

Stata

``` stata
ivreghdfe y z (x = instrument), absorb(id time)
```

R `fixest`

``` r

fixest::feols(y ~ z | id + time | x ~ instrument, data = data, vcov = "iid", nthreads = 1, ssc = fixest::ssc(K.adj = TRUE, K.fixef = "full", K.exact = TRUE, G.adj = TRUE, t.df = "conventional"), fixef.rm = "singleton")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Absorbed 2SLS with identical structural/instrument regressors and
singleton removal. ssc explicitly counts all FE for iid/heteroskedastic
inference and excludes cluster-nested FE for clustered inference, with
cluster-minus-one t reference. ivreghdfe activates small automatically;
package versions can differ in the remaining intercept df convention.

[Stata reference](https://github.com/sergiocorreia/ivreghdfe) · [R
reference](https://lrberge.github.io/fixest/reference/ssc.html)

## `ivregress`

Formula-based instrumental-variable regression

Stata

``` stata
ivregress 2sls y w (x = z), small
```

R `AER`

``` r

AER::ivreg(y ~ x + w | z + w, data = data)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Conventional 2SLS with identical structural regressors and instruments.
Stata small selects residual-df variance scaling and t inference,
matching the standard R fitted-model summary.

[Stata reference](https://www.stata.com/manuals/rivregress.pdf) · [R
reference](https://cran.r-project.org/web/packages/AER/AER.pdf)

Cluster-robust two-stage least squares

Stata

``` stata
ivregress 2sls y w (x = z), vce(cluster cluster) small
```

R `estimatr`

``` r

estimatr::iv_robust(y ~ x + w | z + w, data = data, clusters = cluster, se_type = "stata")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Explicit small uses cluster finite-sample scaling and t reference with
clusters minus one degrees of freedom. The structural and instrument
formulas include the same exogenous covariate.

[Stata reference](https://www.stata.com/manuals/rivregress.pdf) · [R
reference](https://cran.r-project.org/web/packages/estimatr/estimatr.pdf)

Two-stage least squares with stata covariance

Stata

``` stata
ivregress 2sls y w (x = z), vce(robust) small
```

R `estimatr`

``` r

estimatr::iv_robust(y ~ x + w | z + w, data = data, se_type = "stata")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Stata small requests the N/(N-K) HC1 correction and t-based inference.
estimatr se_type="stata" aliases HC1 for unclustered IV. Without small,
ivregress vce(robust) uses HC0 and normal reference inference, so it is
a different default.

[Stata reference](https://www.stata.com/manuals/causal.pdf) · [R
reference](https://cran.r-project.org/web/packages/estimatr/estimatr.pdf)

## `teffects`

IPW average treatment effect with joint-estimation inference

Stata

``` stata
teffects ipw (y) (treat x z)
```

R `WeightIt`

``` r

{ data <- data[stats::complete.cases(data[c("y", "treat", "x", "z")]), , drop = FALSE]; stopifnot(is.numeric(data$treat), setequal(unique(data$treat), c(0, 1))); w <- WeightIt::weightit(treat ~ x + z, data = data, method = "glm", link = "logit", estimand = "ATE", keep.mparts = TRUE); stopifnot(all(w$ps >= 1e-5 & w$ps <= 1 - 1e-5)); summary(WeightIt::lm_weightit(y ~ treat, data = data, weightit = w, vcov = "asympt"), ci = TRUE, level = .95) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Numeric binary treat: 0=control, 1=treated; continuous y; independent
observations. Use complete y,treat,x,z cases and propensity scores in
\[1e-5,1-1e-5\]. The treatment-only weighted regression is saturated, so
its treat coefficient is the normalized weighted-cell mean difference
(ATE). vcov="asympt" jointly accounts for logit-estimated weights;
summary reports robust z tests and normal 95% confidence intervals. The
intercept is the target-population control mean. This is IPW, without
covariate adjustment in the weighted outcome regression.

[Stata reference](https://www.stata.com/manuals/causalteffectsipw.pdf) ·
[R
reference](https://ngreifer.github.io/WeightIt/reference/glm_weightit.html)
