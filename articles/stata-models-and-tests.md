## `biprobit`

Fit jointly correlated binary probit equations

Stata

``` stata
biprobit y1 y2 x
```

R `VGAM`

``` r

VGAM::vglm(cbind(y1,y2)~x,family=VGAM::binom2.rho(),data=data)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Both binary equations share x and use a constant latent correlation; rho
link parameterizations differ but fitted joint probabilities have the
same model meaning.

[Stata reference](https://www.stata.com/manuals/rbiprobit.pdf) · [R
reference](https://cran.r-project.org/web/packages/VGAM/VGAM.pdf)

## `contrast`

Form group contrasts against the reference category

Stata

``` stata
contrast r.g
```

R `multcomp`

``` r

summary(multcomp::glht(fit, linfct = multcomp::mcp(g = "Dunnett")), test = multcomp::adjusted("none"))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
After one-way OLS y ~ g with the first factor level as reference;
unadjusted t tests for reference contrasts.

[Stata reference](https://www.stata.com/manuals/rcontrast.pdf) · [R
reference](https://cran.r-project.org/web/packages/multcomp/multcomp.pdf)

## `cpoisson`

Fit a right-censored Poisson count model

Stata

``` stata
cpoisson y x, ul(4)
```

R `VGAM`

``` r

VGAM::vglm(VGAM::SurvS4(y,status)~x,family=VGAM::cens.poisson(),data=data)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed right-censoring limit 4; status is one for exact counts and zero
for counts known to be at least 4. Censoring must not be treated as
truncation.

[Stata reference](https://www.stata.com/manuals/rcpoisson.pdf) · [R
reference](https://cran.r-project.org/web/packages/VGAM/VGAM.pdf)

## `elasticnet`

Fit cross-validated elasticnet linear prediction

Stata

``` stata
elasticnet linear y x z, alpha(0.5)
```

R `glmnet`

``` r

glmnet::cv.glmnet(as.matrix(data[c("x","z")]),data$y,alpha=0.5,nfolds=10)
```

Prediction workflow: folds, standardization, penalty grids, loss scaling
and lambda selection differ from Stata defaults; coefficients need not
match.

[Stata reference](https://www.stata.com/manuals/lassoelasticnet.pdf) ·
[R reference](https://cran.r-project.org/web/packages/glmnet/glmnet.pdf)

## `esize`

Estimate Cohen standardized mean differences for two independent groups

Stata

``` stata
esize twosample y, by(g) cohensd
```

R `effectsize`

``` r

effectsize::cohens_d(y~g,data=data,pooled_sd=TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses pooled SD and first-group minus second-group direction; reverse the
sign if the substantive contrast is reversed.

[Stata reference](https://www.stata.com/manuals/resize.pdf) · [R
reference](https://cran.r-project.org/web/packages/effectsize/effectsize.pdf)

## `icc`

Estimate a one-way individual-measure intraclass correlation

Stata

``` stata
icc y id
```

R `psych`

``` r

{ wide <- stats::reshape(data,idvar="id",timevar="rater",direction="wide"); psych::ICC(wide[,-1],lmer=FALSE)$results[1,,drop=FALSE] }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed balanced design has three measurements per target. R starts from
wide repeated-measure columns; ICC1 is the one-way absolute-agreement
individual-measure form.

[Stata reference](https://www.stata.com/manuals/ricc.pdf) · [R
reference](https://cran.r-project.org/web/packages/psych/psych.pdf)

## `nestreg`

Compare successively added regression blocks

Stata

``` stata
nestreg: regress y (x) (z)
```

R `stats`

``` r

{ sample <- stats::na.omit(data[c("y", "x", "z")]); reduced <- stats::lm(y ~ x, data = sample); full <- stats::lm(y ~ x + z, data = sample); stats::anova(reduced, full) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Partial F test for the two specified OLS blocks on common complete
cases; corresponds to this fixed nestreg workflow.

[Stata reference](https://www.stata.com/manuals/rnestreg.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/anova.lm.html)

## `orthog`

Orthogonalize centered predictor columns in their stated order

Stata

``` stata
orthog x z, generate(ox oz)
```

R `stats`

``` r

{ Q <- qr.Q(qr(cbind(1,as.matrix(data[c("x","z")])))); data[c("ox","oz")] <- Q[,-1,drop=FALSE]*sqrt(nrow(data)); data[c("ox","oz")] }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Unweighted QR gives an orthogonal basis with mean square one; signs can
differ from Stata modified Gram-Schmidt output.

[Stata reference](https://www.stata.com/manuals/rorthog.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/qr.html)

## `orthpoly`

Construct three orthogonal polynomial columns

Stata

``` stata
orthpoly x, generate(p1 p2 p3) degree(3)
```

R `stats`

``` r

data[c("p1","p2","p3")] <- stats::poly(data$x,degree=3)*sqrt(nrow(data))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Rescales the R orthonormal basis to mean square one; polynomial signs
and stored coefficient conventions may differ.

[Stata reference](https://www.stata.com/manuals/rorthog.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/poly.html)

## `predictnl`

Apply a nonlinear prediction transform with delta-method standard errors

Stata

``` stata
predictnl p = invlogit(predict(xb)), se(se)
```

R `stats`

``` r

{ pred <- stats::predict(fit,type="link",se.fit=TRUE); data$p <- stats::plogis(pred$fit); data$se <- data$p*(1-data$p)*pred$se.fit; data[c("p","se")] }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Run after a logit GLM. This uses the derivative p\*(1-p) and the fitted
linear-index standard error.

[Stata reference](https://www.stata.com/manuals/rpredictnl.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/predict.glm.html)

## `pwcompare`

Compare all group pairs with Tukey simultaneous intervals

Stata

``` stata
pwcompare g, mcompare(tukey)
```

R `stats`

``` r

stats::TukeyHSD(stats::aov(y~g,data=data))$g
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
After the one-way equal-variance model y on g; R TukeyHSD is not a
general replacement for adjusted margins in arbitrary models.

[Stata reference](https://www.stata.com/manuals/rpwcompare.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/TukeyHSD.html)

## `robvar`

Test equal group variances using median-centered Levene inference

Stata

``` stata
robvar y, by(g)
```

R `car`

``` r

car::leveneTest(y~factor(g),data=data,center=stats::median)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Corresponds to robvar W50; Stata additionally reports mean-centered W0
and 10-percent-trimmed W10.

[Stata reference](https://www.stata.com/manuals/rsdtest.pdf) · [R
reference](https://cran.r-project.org/web/packages/car/car.pdf)

## `runtest`

Test whether a binary threshold sequence has random runs

Stata

``` stata
runtest y, threshold(0)
```

R `stats`

``` r

{ above <- data$y>0; n1 <- sum(above); n0 <- sum(!above); runs <- 1+sum(diff(above)!=0); expected <- 1+2*n1*n0/(n1+n0); variance <- 2*n1*n0*(2*n1*n0-n1-n0)/((n1+n0)^2*(n1+n0-1)); z <- (runs-expected)/sqrt(variance); c(runs=runs,z=z,p.value=2*stats::pnorm(-abs(z))) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses the large-sample uncorrected runs statistic, matching Stata default
continuity convention; missing values must be removed before this
workflow.

[Stata reference](https://www.stata.com/manuals/rruntest.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

[Stata reference](https://www.stata.com/manuals/rslogit.pdf) · [R

## `symmi`

Test matched-table symmetry directly from cell counts

Stata

``` stata
symmi 10 8 \ 3 10
```

R `stats`

``` r

stats::mcnemar.test(matrix(c(10,8,3,10),2,byrow=TRUE),correct=FALSE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
For this 2-by-2 table the symmetry test is the uncorrected McNemar test.
Stata also reports table summaries; this R result is an htest object.

[Stata reference](https://www.stata.com/manuals/rsymmetry.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `ztest`

Test a mean using a known population standard deviation

Stata

``` stata
ztest y == 20, sd(3)
```

R `stats`

``` r

{ z <- (mean(data$y)-20)/(3/sqrt(nrow(data))); c(z=z,p.value=2*stats::pnorm(-abs(z))) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
The value 3 is assumed known as a population SD, not estimated from the
sample.

[Stata reference](https://www.stata.com/manuals/rztest.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Normal.html)

## `ztesti`

Compare independent means from known-variance summaries

Stata

``` stata
ztesti 30 10 2 40 12 3
```

R `stats`

``` r

{ z <- (10-12)/sqrt(2^2/30+3^2/40); c(z=z,p.value=2*stats::pnorm(-abs(z))) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Treats the supplied standard deviations as known and uses a normal
reference distribution. Returns the z statistic and two-sided p-value,
without Stata confidence limits.

[Stata reference](https://www.stata.com/manuals/rztest.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Normal.html)
