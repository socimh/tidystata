## `betareg`

使用cloglog均值连接拟合贝塔回归

Stata

``` stata
betareg share x, link(cloglog)
```

R `betareg`

``` r

betareg::betareg(share~x,data=data,link="cloglog",type="ML",link.phi="log")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
采用常规ML及精度参数的log链接，匹配Stata的slink(log)。不指定link.phi="log"时，betareg在恒等尺度报告常数phi，Stata则报告ln(phi)。响应须严格位于(0,1)内。

[Stata 参考](https://www.stata.com/manuals/rbetareg.pdf) · [R
参考](https://cran.r-project.org/web/packages/betareg/betareg.pdf)

## `bsqreg`

使用自助法估计分位数回归推断

Stata

``` stata
bsqreg y x z, reps(99)
```

R `quantreg`

``` r

{ fit <- quantreg::rq(y~x+z,data=data,tau=0.5); summary(fit,se="boot",R=99) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
用99次自助重复进行分位数回归推断。R与Stata的随机流及重抽样实现不同，因此自助标准误不完全相同。

[Stata 参考](https://www.stata.com/manuals/rqreg.pdf) · [R
参考](https://cran.r-project.org/web/packages/quantreg/quantreg.pdf)

## `constraint`

把线性等式约束表示为矩阵

Stata

``` stata
constraint define 1 x = z
```

R `stats`

``` r

L <- matrix(c(0,1,-1),nrow=1,dimnames=list(NULL,c("intercept","x","z")))
```

固定流程：L beta = 0表示x与z系数相等；拟合程序需实际施加约束。

## `fracreg`

使用三明治推断拟合分数logit回归

Stata

``` stata
fracreg logit share x
```

R `sandwich`

``` r

{ fit <- stats::glm(share ~ x,data=data,family=stats::quasibinomial(link="logit")); lmtest::coeftest(fit,vcov.=sandwich::vcovHC(fit,type="HC0"),df=Inf) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
准二项拟合避免非整数成功次数警告；此例显式使用三明治推断，小样本校正可能不同。

[Stata 参考](https://www.stata.com/manuals/rfracreg.pdf) · [R
参考](https://cran.r-project.org/web/packages/sandwich/sandwich.pdf)

``` r
{ fit <- stats::lm(y ~ x + z, data = data); sample <- stats::model.frame(fit); stats::coef(fit)[c("x", "z")] * vapply(sample[c("x", "z")], stats::sd, numeric(1)) / stats::sd(sample$y) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
数值变量的标准化斜率使用完整估计样本的标准差；常规OLS推断保存在fit中。

[Stata 参考](https://www.stata.com/manuals/rregress.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/lm.html)

``` r

{ fit <- stats::lm(y ~ x + z, data = data, subset = !is.na(g)); lmtest::coeftest(fit, vcov. = sandwich::vcovCL(fit, cluster = ~g, type = "HC1"), df = length(unique(stats::expand.model.frame(fit, ~g)$g)) - 1L) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

``` r
AER::tobit(y~x+z,data=data,left=0)
```
