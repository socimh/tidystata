# Documentation

Start with [Getting
started](https://socimh.github.io/tidystata/articles/getting-started.md)
for a short workflow, or [Coming from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.md)
to find the R equivalent of a Stata command.

See [Containers and missing
values](https://socimh.github.io/tidystata/articles/containers-and-missing-values.md)
for output conventions, the [function
reference](https://socimh.github.io/tidystata/reference/index.md) for
individual functions, and
[NEWS](https://socimh.github.io/tidystata/news/index.md) for release
notes.
