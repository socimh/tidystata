Bar chart of counts

Stata

``` stata

```

``` r

```

reference](https://cran.r-project.org/package=ggplot2)


## `histogram`

Histogram

Stata

``` stata

```


## `kdensity`

Density plot

Stata

``` stata
kdensity x, kernel(gaussian) bwidth(1)
```

R `ggplot2`

``` r

ggplot(data, aes(x)) + geom_density(kernel = "gaussian", bw = 1)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Both specify a Gaussian kernel and bandwidth 1. Default kdensity uses
Epanechnikov, unlike default geom_density. Density grids/rendering may
differ.

[Stata reference](https://www.stata.com/manuals/rkdensity.pdf) · [R
reference](https://ggplot2.tidyverse.org/reference/geom_density.html)
