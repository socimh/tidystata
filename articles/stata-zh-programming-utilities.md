## `about`

查看 R 版本与平台信息

Stata

``` stata
about
```

R `utils`

``` r

utils::sessionInfo()
```

报告 R 会话元数据；Stata 许可证与序列号没有 R 对应项。

[Stata 参考](https://www.stata.com/manuals/rabout.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/utils/html/sessionInfo.html)

## `adopath`

查看 R 包库搜索路径

Stata

``` stata
adopath
```

R `base`

``` r

.libPaths()
```

R 包库代替 ado 搜索文件夹；此例仅读取当前路径。

[Stata 参考](https://www.stata.com/manuals/psysdir.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `args`

在函数中接收两个位置参数

Stata

``` stata
program define addtwo
args a b
display `a'+`b'
end
```

R `base`

``` r

addtwo <- function(a,b) a+b
```

R 函数参数代替 Stata 位置宏；本例为固定程序。

[Stata 参考](https://www.stata.com/manuals/psyntax.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `continue`

跳过某次循环的剩余步骤

Stata

``` stata
forvalues i=1/4 {
    if `i'==2 continue
    display `i'
}
```

R `base`

``` r

out <- integer(); for (i in 1:4) { if(i==2) next; out <- c(out,i) }
```

固定流程示例；更改时需同时调整对象名与列名。

[Stata 参考](https://www.stata.com/manuals/pcontinue.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

提前退出循环

Stata

``` stata
forvalues i=1/4 {
    if `i'==3 continue, break
    display `i'
}
```

R `base`

``` r

out <- integer(); for (i in 1:4) { if(i==3) break; out <- c(out,i) }
```

固定流程示例；更改时需同时调整对象名与列名。

[Stata 参考](https://www.stata.com/manuals/pcontinue.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `creturn`

查看 R 版本、平台、路径与数值限制

Stata

``` stata
creturn list
```

R `base`

``` r

list(version=R.version.string,platform=R.version$platform,working_directory=getwd(),machine=.Machine)
```

返回 R 自身设置与常量，而非 Stata c 类值。

[Stata 参考](https://www.stata.com/manuals/pcreturn.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `dataex`

为小型数据示例生成可复现 R 代码

Stata

``` stata
dataex id x in 1/3
```

R `base`

``` r

example <- data[1:3,c('id','x')]; text <- utils::capture.output(dput(example))
```

dput 输出 R 重建代码，不是 Stata input
代码或论坛标记。只分享已获准公开的数据。

[Stata
参考](https://www.statalist.org/forums/forum/general-stata-discussion/general/1301224-new-on-ssc-dataex-a-command-to-generate-a-properly-formatted-data-example-for-statalist)
· [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `exit`

提前从函数返回

Stata

``` stata
program define positive
args x
if `x'<=0 exit
display `x'
end
```

R `base`

``` r

positive <- function(x) { if(x<=0) return(invisible(NULL)); x }
```

仅从函数返回；退出 R 进程会终止用户会话。

[Stata 参考](https://www.stata.com/manuals/p.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `include`

在当前求值环境执行辅助代码

Stata

``` stata
include helper.do
```

R `base`

``` r

sys.source(path,envir=environment())
```

本例仅执行受控临时 R 辅助文件；使用 R 语法替代 Stata do 文件。

[Stata 参考](https://www.stata.com/manuals/p.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `mark`

按条件生成纳入样本标记

Stata

``` stata
mark touse if g == 2
```

R `base`

``` r

data$touse <- as.integer(!is.na(data$g) & data$g==2)
```

[Stata 参考](https://www.stata.com/manuals/pmark.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `markout`

所选变量不完整时清除纳入标记

Stata

``` stata
markout touse x y
```

R `base`

``` r

data$touse <- as.integer(data$touse==1 & stats::complete.cases(data[c('x','y')]))
```

[Stata 参考](https://www.stata.com/manuals/pmark.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `matname`

为矩阵列命名

Stata

``` stata
matname X first second, columns(1..2)
```

R `base`

``` r

colnames(X)[1:2] <- c("first", "second")
```

仅替换第1、2列的名称，保留其余列名。

[Stata 参考](https://www.stata.com/manuals/pmatrixmkmat.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `mkmat`

从指定数值变量创建矩阵

Stata

``` stata
mkmat x y, matrix(X)
```

R `base`

``` r

X <- as.matrix(data[c('x','y')])
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
X 是固定矩阵对象名；R 行名不一定匹配 Stata 的 r1、r2 标签。

[Stata 参考](https://www.stata.com/manuals/pmatrixmkmat.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

排除整行缺失后创建矩阵

Stata

``` stata
mkmat x y, matrix(X) nomissing
```

R `base`

``` r

X <- as.matrix(data[stats::complete.cases(data[c('x','y')]),c('x','y')])
```

[Stata 参考](https://www.stata.com/manuals/pmatrixmkmat.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `numlist`

展开固定步长数值列表

Stata

``` stata
numlist "1(2)9"
```

R `base`

``` r

values <- seq(1,9,by=2)
```

直接构造本例列表；不解析任意 Stata numlist 字符串。

[Stata 参考](https://www.stata.com/manuals/pnumlist.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

展开递减连续数值列表

Stata

``` stata
numlist "5/1"
```

R `base`

``` r

values <- seq(5,1,by=-1)
```

用于所示 Stata 列表的直接 R 序列流程。

[Stata 参考](https://www.stata.com/manuals/pnumlist.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

sleep 1

Sys.sleep(0.001)

sysdir list

list(home=R.home(),library=R.home('library'),temporary=tempdir())

## `tempfile`

生成唯一临时文件路径

Stata

``` stata
tempfile cache
```

R `base`

``` r

path <- tempfile(fileext='.rds')
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
tempfile() 只生成名称而不创建文件；R 不保证函数退出时按 Stata
方式清除每个命名文件。

[Stata 参考](https://www.stata.com/manuals/p.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `tokenize`

拆分简单空白分隔词元

Stata

``` stata
tokenize alpha beta gamma
```

R `base`

``` r

tokens <- strsplit('alpha beta gamma',' +')[[1]]
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 返回字符向量而非位置局部宏；带引号词元的解析不同。

[Stata 参考](https://www.stata.com/manuals/ptokenize.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

vars <- grep('^x',names(data),value=TRUE)
