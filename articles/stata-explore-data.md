## `correlate`

Pearson correlations (complete cases)

Stata

``` stata
correlate x1 x2 x3
```

R `tidystata`

``` r

corr(data, x1, x2, x3)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses one common complete-case sample within each group, like Stata
correlate. Returns r and n without p-values; .wide = TRUE gives a
lower-triangular table. Optional .wt supports frequency or analytic
weights; zero-weight rows are excluded. Stata covariance, means and
display-formatting options are not implemented. Use pwcorr() for
separate pairwise samples, or pwcorr(.listwise = TRUE) for a common
sample with p-values.

[Stata reference](https://www.stata.com/manuals/rcorrelate.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `pwcorr`

Pairwise correlations

Stata

``` stata
pwcorr x1 x2 x3
```

R `tidystata`

``` r

pwcorr(data, x1, x2, x3)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
By default, each pair uses its own complete sample and returns Pearson
r, n and p; .wide = TRUE gives a lower-triangular table without n or p.
Stata prints a matrix by default and needs sig obs to show p-values and
counts. .listwise = TRUE (also Stata casewise) uses one common sample
and keeps p-values; corr() uses that sample but omits p. .adjust =
"bonferroni" or "sidak" adjusts across all distinct variable pairs
separately within each group, including pairs with undefined p-values;
adjustment is unavailable with .wide = TRUE. .method = "spearman" gives
unweighted pairwise rank correlations; spearman() uses Stata's casewise
default. Pearson weights use summed frequency weights or analytic row
counts for n; complete zero-weight rows count for analytic n only in
pairwise mode. Fractional frequency weights extend Stata's integer
convention.

[Stata reference](https://www.stata.com/manuals/rcorrelate.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `spearman`

Spearman rank correlation

Stata

``` stata
spearman x y
```

R `tidystata`

``` r

spearman(data, x, y)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses one common complete-case sample by default, like Stata spearman;
.pairwise = TRUE matches spearman, pw. Returns an ungrouped table with
var1, var2, r (rho), n and p, plus any grouping keys. P-values follow
Stata 18+'s four-moment beta approximation, with a normal fallback for n
\< 4 or an invalid beta fit; p is NA for n \< 3. Ties receive average
ranks within each sample. Constant variables give NA, where Stata
reports rho = 1. Weights are unsupported. .adjust = "bonferroni" or
"sidak" adjusts within each group across all distinct pairs, including
undefined p-values; it cannot be combined with .wide = TRUE. Base R
cor.test(..., method = "spearman") uses different p-value
approximations.

[Stata reference](https://www.stata.com/manuals/rspearman.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.test.html)
