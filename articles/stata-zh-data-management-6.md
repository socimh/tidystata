## `xpose`

转置全数值数据表

Stata

``` stata
xpose, clear
```

R `base`

``` r

data <- as.data.frame(t(as.matrix(data)))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
输入必须全为数值；R 输出列名不同于 Stata 的 v1、v2。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

转置并保留原列名

Stata

``` stata
xpose, clear varname
```

R `base`

``` r

oldnames <- names(data); data <- as.data.frame(t(as.matrix(data))); data[['_varname']] <- oldnames
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
输入必须全为数值。原列名保存在 \_varname；R 转置后列名可能不同。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
