## `areg`

吸收一个类别变量的回归

Stata

``` stata
areg y x, absorb(id)
```

R `fixest`

``` r

fixest::feols(y ~ x | id, data = data, vcov = "iid", fixef.rm = "none")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
在最小二乘中吸收 id 并使用常规协方差；与 areg 一样保留单例组。

[Stata 参考](https://www.stata.com/manuals/rareg.pdf) · [R
参考](https://lrberge.github.io/fixest/articles/standard_errors.html)

## `bootstrap`

自助法标准误

Stata

``` stata
bootstrap, reps(500): regress y x
```

R `sandwich`

``` r

{ fit <- stats::lm(y ~ x, data = data); lmtest::coeftest(fit, vcov. = sandwich::vcovBS(fit, R = 500, type = "xy"), df = Inf) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
先拟合 OLS，再按观测对重抽样 500 次，并报告基于 bootstrap
协方差的正态检验。R 与 Stata 的随机数流不同。

[Stata 参考](https://www.stata.com/manuals/rbootstrap.pdf) · [R
参考](https://cran.r-project.org/web/packages/sandwich/sandwich.pdf)

## `cluster`

K 均值聚类

Stata

``` stata
cluster kmeans x1 x2, k(3)
```

R `stats`

``` r

kmeans(na.omit(select(data, x1, x2)), centers = 3)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 默认 Hartigan-Wong k 均值和随机初始中心；Stata
初值和迭代默认不同。比较聚类须控制初始中心。

[Stata
参考](https://www.stata.com/manuals/mvclusterkmeansandkmedians.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/kmeans.html)

## `didregress`

双重差分（Stata 17 及以上）

Stata

``` stata
didregress (y) (treated), group(id) time(year)
```

R `fixest`

``` r

fixest::feols(y ~ treated | id + year, data = data, vcov = ~id)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
组、时间固定效应 DID，协方差按组聚类。id 为处理分配组；只有 DID
设计假设成立时系数才是 ATET。Stata 专用诊断需另行执行。

[Stata 参考](https://www.stata.com/manuals/causaldidregress.pdf) · [R
参考](https://lrberge.github.io/fixest/articles/standard_errors.html)

参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/AIC.html)


## `margins`

分组的预测边际

Stata

``` stata
margins g
```

R `marginaleffects`

``` r

marginaleffects::avg_predictions(fit, variables = "g", type = "response", df = if (inherits(fit, "lm") && !inherits(fit, "glm")) df.residual(fit) else Inf)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
对含因子 g 的普通 lm 或二项、泊松 glm 拟合：先把估计样本每一行设为 g
的各水平，再平均。请使用 g，因为 marginaleffects 保留 group 列名。

[Stata 参考](https://www.stata.com/manuals/rmargins.pdf) · [R
参考](https://marginaleffects.com/man/r/predictions.html)

平均边际效应

Stata

``` stata
margins, dydx(*)
```

R `marginaleffects`

``` r

marginaleffects::avg_slopes(fit, type = "response", df = if (inherits(fit, "lm") && !inherits(fit, "glm")) df.residual(fit) else Inf)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
适用于普通 lm 或二项、泊松
glm：在估计样本上平均响应尺度导数及因子离散变化；lm 使用残差 t
自由度，GLM 使用正态推断。

[Stata 参考](https://www.stata.com/manuals/rmargins.pdf) · [R
参考](https://marginaleffects.com/man/r/slopes.html)

## `mi`

在多个插补数据上估计并合并结果

Stata

``` stata
mi estimate: regress y x
```

R `mice`

``` r

mice::pool(with(imp, lm(y ~ x)))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
Rubin 合并仍需匹配与 mi estimate 的完整数据自由度和小样本校正。

[Stata 参考](https://www.stata.com/manuals/mimiestimate.pdf) · [R
参考](https://cran.r-project.org/package=mice)

多重插补

Stata

``` stata
mi impute chained (regress) x1 x2 = y, add(20) burnin(10)
```

R `mice`

``` r

{ impute_data <- data[c("x1", "x2", "y")]; predictors <- matrix(c(0, 1, 1, 1, 0, 1, 0, 0, 0), nrow = 3, byrow = TRUE, dimnames = list(names(impute_data), names(impute_data))); imp <- mice::mice(impute_data, m = 20, method = c(x1 = "norm", x2 = "norm", y = ""), predictorMatrix = predictors, maxit = 10, printFlag = FALSE) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
为数值型 x1/x2 生成 20 份链式高斯回归插补，预测变量包括彼此及完全观测的
y，迭代 10 次。明确方法和预测矩阵，替代 mice
默认值；两程序的随机抽样不相同。

[Stata 参考](https://www.stata.com/manuals/mimiimputechained.pdf) · [R
参考](https://amices.org/mice/reference/mice.html)
