链式方程插补方法：pmm

Stata

``` stata
mi impute chained (pmm, knn(5)) x z = y, add(3) rseed(108) burnin(10)
```

R `mice`

``` r

mice::mice(data, m = 3, maxit = 10, method = "pmm", seed = 108, donors = 5L, printFlag = FALSE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
对x和z进行新的FCS插补，互为预测变量并使用完整y。两软件实现相同模型族，但随机数流不同。R每链迭代10次；Stata设burnin(10)。应检查收敛，不能将示例迭代次数视为充分条件。

[Stata 参考](https://www.stata.com/manuals/mimiimputechained.pdf) · [R
参考](https://cran.r-project.org/web/packages/mice/mice.pdf)

直接合并系数向量与协方差矩阵

Stata

``` stata
mi estimate: regress y x z
```

R `mitools`

``` r

{ fits <- lapply(mice::complete(imp, "all"), function(d) stats::lm(y ~ x + z, data = d)); mitools::MIcombine(lapply(fits, stats::coef), lapply(fits, stats::vcov), df.complete = stats::df.residual(fits[[1L]])) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
按Rubin规则合并回归系数和协方差，df.complete=n-3对应截距、x、z。保留有限完整数据自由度，避免MIcombine默认无穷大。

[Stata 参考](https://www.stata.com/manuals/mimiestimate.pdf) · [R
参考](https://cran.r-project.org/web/packages/mitools/mitools.pdf)

二元Logistic链式方程插补

Stata

``` stata
mi impute chained (logit) category (pmm, knn(5)) x z = y, add(3) burnin(10)
```

R `mice`

``` r

{ methods <- mice::make.method(data); methods["category"] <- "logreg"; methods[c("x", "z")] <- "pmm"; mice::mice(data, m = 3, maxit = 10, method = methods, seed = 131, donors = 5L, printFlag = FALSE) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
数据仅含y、x、z和category，y完整；category按所述设为二分类、无序或有序因子。显式方法向量指定分类模型及x、z的PMM。三次新的FCS插补采用10次迭代，须检查收敛。两软件随机数及分离处理不同。

[Stata 参考](https://www.stata.com/manuals/mimiimputechained.pdf) · [R

``` stata
mi test x
```

