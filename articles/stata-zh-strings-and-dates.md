## `char`

从 ASCII 编码创建字符

Stata

``` stata
generate z = char(code)
```

R `base`

``` r

data$z <- vapply(data$code,intToUtf8,character(1))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
仅限 ASCII 编码 1–127；扩展字节编码不是 Unicode 码点。

[Stata 参考](https://www.stata.com/manuals/fnstringfunctions.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `clock`

把文本转换成日期时间

Stata

``` stata
generate t = clock(s, "YMDhms")
```

R `lubridate`

``` r

mutate(data, t = lubridate::ymd_hms(s))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 使用 Date/POSIXct 或 tsibble 日历类别，而非 Stata 以 1960
年为起点的数值日期时间计数；交换底层数值须转换纪元和时区。

[Stata 参考](https://www.stata.com/manuals/fndateandtimefunctions.pdf) ·
[R 参考](https://cran.r-project.org/package=lubridate)

使用显式 UTC 时区解析日期时间

Stata

``` stata
generate double z = clock(s, "YMDhms")
```

R `base`

``` r

data$z <- as.POSIXct(data$s,format='%Y-%m-%d %H:%M:%S',tz='UTC')
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
POSIXct 是带时区的自 1970 年起的秒数；Stata clock 是不带时区的自 1960
年起的毫秒数。

[Stata 参考](https://www.stata.com/manuals/fndateandtimefunctions.pdf) ·
[R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
