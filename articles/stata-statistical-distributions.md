## `F`

Evaluate the F cumulative probability

Stata

``` stata
display F(4,10,2)
```

R `stats`

``` r

```

[Stata
reference](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Fdist.html)

## `binormal`

Evaluate a correlated bivariate normal probability

Stata

``` stata
display binormal(0,0,0.4)
```

R `mvtnorm`

``` r

as.numeric(mvtnorm::pmvnorm(upper=c(0,0),corr=matrix(c(1,0.4,0.4,1),2)))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Evaluates a bivariate normal probability using mvtnorm numerical
integration. Integration tolerance and numerical rounding differ from
the Stata distribution function.

[Stata
reference](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·
[R
reference](https://cran.r-project.org/web/packages/mvtnorm/mvtnorm.pdf)

## `corr2data`

Generate pseudo-data with exactly specified sample moments

Stata

``` stata
corr2data x y, n(100)
```

R `MASS`

``` r

stats::setNames(as.data.frame(MASS::mvrnorm(n=100,mu=c(0,0),Sigma=diag(2),empirical=TRUE)),c("x","y"))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
empirical=TRUE imposes the sample mean and covariance; such pseudo-data
are not independent random draws.

[Stata reference](https://www.stata.com/manuals/dcorr2data.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/MASS/html/mvrnorm.html)
