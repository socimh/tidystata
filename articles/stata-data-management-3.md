## `gcollapse`

Collapse group means using the gcollapse workflow

Stata

``` stata
gcollapse (mean) z=x, by(g)
```

R `dplyr`

``` r

data <- dplyr::summarise(data,z=mean(x,na.rm=TRUE),.by=g)
```

[Stata
reference](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R reference](https://dplyr.tidyverse.org/reference/index.html)

Keep raw group row counts beside collapsed means

Stata

``` stata
gcollapse (mean) z=x, by(g) freq(n)
```

R `dplyr`

``` r

data <- dplyr::summarise(data,z=mean(x,na.rm=TRUE),n=dplyr::n(),.by=g)
```

[Stata
reference](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R reference](https://dplyr.tidyverse.org/reference/index.html)

Add collapsed group means back to all original rows

Stata

``` stata
gcollapse (mean) z=x, by(g) merge
```

R `dplyr`

``` r

data <- dplyr::mutate(data,z=mean(x,na.rm=TRUE),.by=g)
```

[Stata
reference](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R reference](https://dplyr.tidyverse.org/reference/index.html)

Collapse group missing-value counts

Stata

``` stata

```

``` r

data <- dplyr::summarise(data,n=sum(is.na(x)),.by=g)
```

[Stata
reference](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R reference](https://dplyr.tidyverse.org/reference/index.html)

Collapse group distinct-value counts on complete data

Stata

``` stata

```


asserted.

## `gquantiles`

Assign four empirical quantile categories

Stata

``` stata
gquantiles quartile=x, xtile nquantiles(4)
```

R `base`

``` r

cuts <- stats::quantile(data$x,c(.25,.5,.75),type=2); data$quartile <- as.integer(cut(data$x,breaks=c(-Inf,cuts,Inf),right=TRUE))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Unweighted distinct finite values; uses explicit R type-2 cutoffs and
right-closed categories. Ties can prevent equal group sizes.

[Stata
reference](https://gtools.readthedocs.io/en/latest/usage/gquantiles/) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Return selected empirical percentile cutpoints

Stata

``` stata
gquantiles x, _pctile percentiles(25 50 75)
```

R `base`

``` r

stats::quantile(data$x,c(.25,.5,.75),type=2)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Explicit R type-2 unweighted percentile workflow; no
alternative-definition or weighted numerical parity is asserted.

[Stata
reference](https://gtools.readthedocs.io/en/latest/usage/gquantiles/) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
