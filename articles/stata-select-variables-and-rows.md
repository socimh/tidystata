## `drop`

Drop rows meeting a condition

Stata

``` stata
drop if x == 1
```

R `dplyr`

``` r

filter_out(data, x == 1)
```

Stata keeps rows with missing x here, and so does filter_out(), which
needs dplyr 1.2.0 or later. With older dplyr, use filter(data, x != 1 \|
is.na(x)).

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Drop rows by position

Stata

``` stata
drop in 1/4
```

R `dplyr`

``` r

slice(data, -(1:4))
```

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Drop a variable

Stata

``` stata
drop x
```

R `dplyr`

``` r

select(data, -x)
```

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Drop several variables

Stata

``` stata
drop x1 x3-x5
```

R `dplyr`

``` r

select(data, -c(x1, x3:x5))
```

Positions work too: select(data, -c(1, 3:5)).

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `duplicates`

Drop rows that duplicate an earlier row

Stata

``` stata
duplicates drop
```

R `tidystata`

``` r

duplicates_drop(data)
```

[Stata reference](https://www.stata.com/manuals/dduplicates.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

Keep the first row for each key

Stata

``` stata
duplicates drop x1 x2, force
```

R `tidystata`

``` r

duplicates_drop(data, x1, x2, .force = TRUE)
```

distinct(data, x1, x2, .keep_all = TRUE) is the dplyr version.

[Stata reference](https://www.stata.com/manuals/dduplicates.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `keep`

Keep rows meeting a condition

Stata

``` stata
keep if x1 == 1 & x2 == 2
```

R `dplyr`

``` r

filter(data, x1 == 1 & x2 == 2)
```

filter() drops rows where the condition is NA, so rows with missing
values never pass.

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Keep some variables

Stata

``` stata
keep x1 x3-x5
```

R `dplyr`

``` r

select(data, x1, x3:x5)
```

Numbers select by position: select(data, 1, 3:5). select_or_transmute()
also computes new columns.

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Keep variables matching Stata wildcards

Stata

``` stata
keep x*
```

R `tidystata`

``` r

select(data, varlist("x*"))
```

[Stata reference](https://www.stata.com/manuals/ddrop.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `sample`

Reproducible random 10% sample

Stata

``` stata
set seed 2024; sample 10
```

R `tidystata`

``` r

data |> slice_sample(prop = 0.1) |> set_seed(2024)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
R and Stata use different random-number streams; the same numeric seed
does not reproduce the same draws or selected rows.

[Stata reference](https://www.stata.com/manuals/dsample.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

Reproducible random sample of 1000 rows

Stata

``` stata
set seed 2024; sample 1000, count
```

R `tidystata`

``` r

data |> slice_sample(n = 1000) |> set_seed(2024)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
set_seed() sets the seed before the sampling step runs, so the pipe
stays in one line. R and Stata use different random-number streams; the
same numeric seed does not reproduce the same draws or selected rows.

[Stata reference](https://www.stata.com/manuals/dsample.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)
