## `xthtaylor`

含时变与时不变内生协变量的Hausman-Taylor模型

Stata

``` stata
xthtaylor y x1 x2 a b, endog(x2 b) constant(a b)
```

R `plm`

``` r

plm::plm(y ~ x1 + x2 + a + b | x1 + a | x2, data = data, index = c("id", "time"), random.method = "ht", model = "random", inst.method = "baltagi")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
固定流程；请明确调整示例列名。R三部分公式明确区分外生协变量及时变内生协变量；时不变内生效应识别要求足够的外生时变工具变量，这些分类须有实质依据。

[Stata 参考](https://www.stata.com/manuals/xtxthtaylor.pdf) · [R
参考](https://cran.r-project.org/web/packages/plm/plm.pdf)

## `xtscc`

``` stata

```

R `plm`

``` r

{ full <- plm::within_intercept(fit, return.model = TRUE); V <- plm::vcovSCC(full, type = "sss", maxlag = 2); lmtest::coeftest(full, vcov. = V)[c("x", "z"), , drop = FALSE] }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
社区命令xtscc在组内变换后恢复总均值。within_intercept重构该模型；sss指定Stata式小样本修正，maxlag=2固定Bartlett带宽。报告的参考自由度可能因实现或版本不同而异。
