## `power`

计算固定样本量单均值t检验功效

Stata

``` stata
power onemean 0 0.5, sd(1) n(40)
```

R `stats`

``` r

stats::power.t.test(n=40,delta=0.5,sd=1,type="one.sample",sig.level=0.05, strict = TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
非中心t双侧功效计入两端拒绝概率；R的n在单样本/配对检验中为观察数/配对数，在双样本中为每组人数；所需n须向上取整。

[Stata 参考](https://www.stata.com/manuals/pss.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/power.t.test.html)
