## `egen`

生成首个非缺失值常量列

Stata

``` stata
egen z = firstnm(x)
```

R `base`

``` r

data$z <- data$x[which(!is.na(data$x))[1]]
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

生成四分位距常量列

Stata

``` stata
egen z = iqr(x)
```

R `base`

``` r

data$z <- diff(stats::quantile(data$x,c(.25,.75),na.rm=TRUE,type=2))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
使用 R 的 type 2 分位数以对应 Stata 默认经验百分位规则。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

计算 0-1 范围的百分位秩

Stata

``` stata
tempvar x_rank x_n
egen `x_rank' = rank(x), track
egen `x_n' = count(x)
generate p = (`x_rank' - 1) / (`x_n' - 1) if !missing(x)
```

R `dplyr`

``` r

data <- dplyr::mutate(data, p = dplyr::percent_rank(x))
```

使用（最小秩 - 1）/（非缺失值个数 -
1）；并列取最低秩，缺失值仍为缺失。c(2, 3, 5) 返回 c(0, 0.5,
1)。最大值并列时最高秩可能小于 1；仅一个非缺失值时秩未定义。这不同于
cume_dist() 或 stats::ecdf() 计算的累积比例。

[Stata
参考](https://www.stata.com/support/faqs/statistics/percentile-ranks-and-plotting-positions/)
· [R 参考](https://dplyr.tidyverse.org/reference/percent_rank.html)

计算 0-100 范围的百分位秩

Stata

``` stata
tempvar x_rank x_n
egen `x_rank' = rank(x), track
egen `x_n' = count(x)
generate p = 100 * (`x_rank' - 1) / (`x_n' - 1) if !missing(x)
```

R `dplyr`

``` r

data <- dplyr::mutate(data, p = 100 * dplyr::percent_rank(x))
```

使用（最小秩 - 1）/（非缺失值个数 - 1） \*
100；并列取最低秩，缺失值仍为缺失。c(2, 3, 5) 返回 c(0, 50,
100)。最大值并列时最高秩可能小于 100；仅一个非缺失值时秩未定义。这不同于
cume_dist() 或 stats::ecdf() 计算的累积比例。

[Stata
参考](https://www.stata.com/support/faqs/statistics/percentile-ranks-and-plotting-positions/)

data$score <- lookup$score[match(data$id, lookup$id)]
