## `meta`

Declare generic effect sizes and sampling variances

Stata

``` stata
meta set yi sei
```

R `metafor`

``` r

metafor::escalc(measure = "GEN", yi = yi, sei = sei, data = data)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Both examples take standard errors as sei; metafor stores their squares
as vi. escalc creates effect-size data but does not persist a
Stata-style meta declaration, labels or a default analysis model.

[Stata reference](https://www.stata.com/manuals/meta.pdf) · [R
reference](https://cran.r-project.org/web/packages/metafor/metafor.pdf)

Cumulative fixed-effect meta-analysis by year

Stata

``` stata
meta summarize, cumulative(year)
```

R `metafor`

``` r

metafor::cumul(metafor::rma(yi, vi, data = data, method = "REML"), order = data$year)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Assumes meta set used its default random(reml) declaration; metafor
explicitly selects REML. A prior Stata common/fixed/random declaration
changes the target. Match study order, missingness and heterogeneity
estimation before comparing summaries.

[Stata reference](https://www.stata.com/manuals/meta.pdf) · [R
reference](https://cran.r-project.org/web/packages/metafor/metafor.pdf)

Stata

``` stata

```

Freeman-Tukey transformed proportions

Stata

``` stata
meta esize cases n, esize(ftukeyprop)
```

R `metafor`

``` r

{ out <- metafor::escalc(measure = "PFT", xi = cases, ni = n, data = data); out$yi <- 2 * out$yi; out$vi <- 4 * out$vi; out }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Stata sums two arcsines; metafor PFT averages them. Multiply yi by 2 and
vi by 4 to match Stata scale. No continuity adjustment is needed at
zero/all events.

[Stata reference](https://www.stata.com/manuals/metametaesize.pdf) · [R
reference](https://wviechtb.github.io/metafor/reference/escalc.html)

Prediction interval for a new study's true effect

Stata

``` stata
meta summarize, random(reml) predinterval
```

R `metafor`

``` r

{ fit <- metafor::rma(yi, vi, data = data, method = "REML"); out <- stats::predict(fit); half <- stats::qt(.975, df = fit$k - 2) * sqrt(fit$tau2 + fit$se^2); out$pi.lb <- out$pred - half; out$pi.ub <- out$pred + half; out }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Random-effects REML true-effect prediction interval. The displayed
calculation uses Stata t(K-2) and sqrt(tau2+SE(mu)^2); pooled-mean
confidence limits retain their normal reference. Require at least three
studies.

[Stata reference](https://www.stata.com/manuals/metametasummarize.pdf) ·
[R
reference](https://cran.r-project.org/web/packages/metafor/metafor.pdf)

Trim-and-fill sensitivity analysis

Stata

``` stata
meta trimfill
```

R `metafor`

``` r

metafor::trimfill(metafor::rma(yi, vi, data = data, method = "REML"))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Assumes meta set used its default random(reml) declaration; metafor
explicitly selects REML. A prior Stata common/fixed/random declaration
changes the target. Match study order, missingness and heterogeneity
estimation before comparing summaries.

[Stata reference](https://www.stata.com/manuals/meta.pdf) · [R
reference](https://cran.r-project.org/web/packages/metafor/metafor.pdf)
