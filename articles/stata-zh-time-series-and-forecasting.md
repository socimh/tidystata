## `arima`

含截距MA(1)

Stata

``` stata
arima y, arima(0,0,1) vce(oim)
```

R `stats`

``` r

stats::arima(y, order = c(0, 0, 1), method = "ML")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
采用高斯极大似然及观测信息协方差。Stata的vce(oim)对应R的Hessian约定。差分模型显式加入时间变量以表示Stata漂移；季节差分使用时间/4。要求完整等间隔序列。

## `wntestq`

``` stata
predict e, residuals

```

R `stats`

``` r

stats::Box.test(stats::residuals(fit), lag = 8, type = "Ljung-Box", fitdf = 0)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
在相同AR(1)拟合后，对残差使用卡方(8)检验。fitdf=0匹配Stata的wntestq；fitdf=1属于另一种残差诊断约定。
