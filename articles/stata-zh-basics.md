## `cd`


## `findit`

查找 Stata 命令对应的 R 函数

Stata

``` stata
findit command
```

R `tidystata`

``` r

findit(command)
```

单个词和逗号分隔的变量名都可以不加引号，例如 findit(tab, sex,
region)。可以加入 findit(tab, gen) 这样的提示，完整 Stata
语法仍可放在引号内。单独查询命令时浏览整个命令族，默认显示最多五种操作；具体查询在答案明确时返回一个结果，有歧义时最多保留十个相关候选。print(n
= Inf)
展开返回的结果；使用单独的命令浏览更广泛的操作。同一操作内依次优先推荐
tidystata、tidyverse、其他包或基础 R。不带参数的 findit() 返回完整列表。

[Stata 参考](https://www.stata.com/manuals/rsearch.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

``` stata

```

R `base`

``` r

path <- "path/to/folder"
```

R 中任何对象都可以像宏一样使用：赋值一次，之后直接用名字，例如
setwd(path)。

参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
