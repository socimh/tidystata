## `xthtaylor`

Hausman-Taylor model with time-varying and invariant endogenous
covariates

Stata

``` stata
xthtaylor y x1 x2 a b, endog(x2 b) constant(a b)
```

R `plm`

``` r

plm::plm(y ~ x1 + x2 + a + b | x1 + a | x2, data = data, index = c("id", "time"), random.method = "ht", model = "random", inst.method = "baltagi")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed workflow; adapt the named data columns explicitly. The three-part
R formula explicitly separates exogenous covariates and time-varying
endogenous covariates. Identification of invariant endogenous effects
requires sufficient exogenous time-varying instruments; these
classifications need substantive justification.

[Stata reference](https://www.stata.com/manuals/xtxthtaylor.pdf) · [R
reference](https://cran.r-project.org/web/packages/plm/plm.pdf)

## `xtpcse`

Beck-Katz panel-corrected covariance

Stata

``` stata
xtpcse y x z, correlation(independent)
```

R `plm`

``` r

{ fit <- plm::plm(y ~ x + z, data = pd, model = "pooling"); lmtest::coeftest(fit, vcov. = plm::vcovBK(fit, type = "HC0", cluster = "time"), df = Inf) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Pooled OLS with Beck-Katz contemporaneous cross-panel covariance. pd
must be balanced and complete with identical time order. HC0 and df=Inf
give the unadjusted PCSE and normal-reference coefficient tests.

[Stata reference](https://www.stata.com/manuals/xtxtpcse.pdf) · [R
reference](https://cran.r-project.org/web/packages/plm/plm.pdf)

Cluster-robust panel standard errors

Stata

``` stata
xtreg y x z, fe vce(cluster id)
```

R `plm`

``` r

{ V <- plm::vcovHC(fit, method = "arellano", type = "sss", cluster = "group"); G <- length(unique(plm::index(fit)[[1L]])); lmtest::coeftest(fit, vcov. = V, df = G - 1L) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)

minus one. Require independent clusters and identical estimation
samples.

Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
fit is the matching individual within model. type="sss" uses Stata
cluster finite-sample scaling; the t reference uses the number of panels
minus one. Require independent clusters and identical estimation
samples.

[Stata reference](https://www.stata.com/manuals/xtxtreg.pdf) · [R

{ full <- plm::within_intercept(fit, return.model = TRUE); V <- plm::vcovSCC(full, type = "sss", maxlag = 2); lmtest::coeftest(full, vcov. = V)[c("x", "z"), , drop = FALSE] }

[Differs from

Stata-type small-sample scaling and maxlag=2 fixes the Bartlett
