ivregress 2sls y w (x = z), small

相同结构回归量和工具变量的传统2SLS。Stata的small指定残差自由度方差修正及t推断，与R模型标准汇总对应。

``` r

estimatr::iv_robust(y ~ x + w | z + w, data = data, clusters = cluster, se_type = "stata")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
显式small采用聚类有限样本修正，自由度为聚类数减一。结构公式及工具变量公式包含相同外生协变量。

[Stata 参考](https://www.stata.com/manuals/rivregress.pdf) · [R
参考](https://cran.r-project.org/web/packages/estimatr/estimatr.pdf)

``` stata

```

R `estimatr`

``` r

```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
Stata的small请求N/(N-K)的HC1修正及t分布推断。无聚类IV中，estimatr的se_type="stata"是HC1的别名。不指定small时，ivregress
vce(robust)采用HC0和正态参考分布，默认推断不同。

## `teffects`

IPW平均处理效应及联合估计推断

Stata

``` stata
teffects ipw (y) (treat x z)
```

R `WeightIt`

``` r

{ data <- data[stats::complete.cases(data[c("y", "treat", "x", "z")]), , drop = FALSE]; stopifnot(is.numeric(data$treat), setequal(unique(data$treat), c(0, 1))); w <- WeightIt::weightit(treat ~ x + z, data = data, method = "glm", link = "logit", estimand = "ATE", keep.mparts = TRUE); stopifnot(all(w$ps >= 1e-5 & w$ps <= 1 - 1e-5)); summary(WeightIt::lm_weightit(y ~ treat, data = data, weightit = w, vcov = "asympt"), ci = TRUE, level = .95) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
数值型二元treat：0为对照、1为处理；y为连续结局；观测相互独立。使用y、treat、x、z完整案例，并要求倾向得分位于\[1e-5,1-1e-5\]。仅含处理指标的加权回归为饱和模型，其treat系数等于归一化加权组均值之差（ATE）。vcov="asympt"联合计入logit估计权重的不确定性；summary报告稳健z检验和正态95%置信区间。截距为目标人群的对照均值。这是IPW，未在加权结局回归中额外调整协变量。

[Stata 参考](https://www.stata.com/manuals/causalteffectsipw.pdf) · [R
参考](https://ngreifer.github.io/WeightIt/reference/glm_weightit.html)
