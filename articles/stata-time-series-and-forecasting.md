## `arima`

MA(1) with intercept

Stata

``` stata
arima y, arima(0,0,1) vce(oim)
```

R `stats`

``` r

stats::arima(y, order = c(0, 0, 1), method = "ML")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Gaussian ML with observed-information covariance. Stata vce(oim) matches
the R Hessian convention. For differenced models, the explicit time
regressor supplies Stata drift; the seasonal drift regressor is time/4.
Require a complete regularly spaced series.

[Stata reference](https://www.stata.com/manuals/tsarima.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/arima.html)
