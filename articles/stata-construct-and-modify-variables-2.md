## `rename`

Rename a variable

Stata

``` stata
rename x x2
```

R `dplyr`

``` r

rename(data, x2 = x)
```

Note the order: new name = old name.

[Stata reference](https://www.stata.com/manuals/drename.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

4 more examples and alternatives

Rename several variables

Stata

``` stata
rename (a b) (c d)
```

R `dplyr`

``` r

rename(data, c = a, d = b)
```

[Stata reference](https://www.stata.com/manuals/drenamegroup.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Add a suffix to every name

Stata

``` stata
rename * *_old
```

R `dplyr`

``` r

rename_with(data, ~ paste0(.x, "_old"))
```

[Stata reference](https://www.stata.com/manuals/drenamegroup.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Make all names lower case

Stata

``` stata
rename *, lower
```

R `dplyr`

``` r

rename_with(data, tolower)
```

[Stata reference](https://www.stata.com/manuals/drenamegroup.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Upper-case some names

Stata

``` stata
rename x*, upper
```

R `dplyr`

``` r

rename_with(data, toupper, starts_with("x"))
```

[Stata reference](https://www.stata.com/manuals/drenamegroup.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `replace`

Change a variable

Stata

``` stata
replace x = x^2
```

R `dplyr`

``` r

mutate(data, x = x^2)
```

[Stata reference](https://www.stata.com/manuals/dgenerate.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

2 more examples and alternatives

Change a variable under a condition

Stata

``` stata
replace x = x^2 if x > 0
```

R `dplyr`

``` r

mutate(data, x = replace_when(x, x > 0 ~ x^2))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Stata numeric missing values compare larger than every finite number; R
comparisons return NA, and replace_when() leaves those rows unchanged.
replace_when() needs dplyr 1.2.0 or later; with older dplyr, use
if_else(x \> 0, x^2, x).

[Stata reference](https://www.stata.com/manuals/dgenerate.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Change a variable for some rows

Stata

``` stata
replace x = x^2 in 11/20
```

R `dplyr`

``` r

mutate(data, x = if_else(row_number() %in% 11:20, x^2, x))
```

[Stata reference](https://www.stata.com/manuals/dgenerate.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `rnormal`

Normal random numbers

Stata

``` stata
generate z = rnormal()
```

R `stats`

``` r

mutate(data, z = rnorm(n()))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
R and Stata use different random-number streams; the same numeric seed
does not reproduce the same draws or selected rows.

[Stata
reference](https://www.stata.com/manuals/fnrandom-numberfunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Normal.html)

## `round`

Round

Stata

``` stata
generate y = round(x, 0.1)
```

R `base`

``` r

mutate(data, y = round(x, 1))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
R's second argument is the number of decimals. R rounds halves to even
(round(0.5) is 0); Stata rounds them up.

[Stata
reference](https://www.stata.com/manuals/fnmathematicalfunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/Round.html)

## `sum`

Running sum

Stata

``` stata
generate cs = sum(x)
```

R `dplyr`

``` r

mutate(data, cs = cumsum(coalesce(x, 0)))
```

Stata's sum() function treats missing values as 0, hence coalesce(x, 0).

[Stata
reference](https://www.stata.com/manuals/fnmathematicalfunctions.pdf) ·
[R reference](https://cran.r-project.org/package=dplyr)

## `tabulate`

Dummy variables for every category

Stata

``` stata
tabulate x, generate(x_)
```

R `tidystata`

``` r

as_dummy(data, x)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
as_dummy(data, x, .names = "index") numbers the columns x_1, x_2, ... as
Stata does. Also: fastDummies::dummy_cols(data, "x"). as_dummy()
defaults to value-based column names; .names = "index" gives numbered
Stata-style suffixes. Check the missing-category indicator policy too.

[Stata reference](https://www.stata.com/manuals/rtabulateoneway.pdf) ·
[R reference](https://socimh.github.io/tidystata/reference/)

## `tostring`

Numbers to text

Stata

``` stata
tostring num_x, generate(str_x)
```

R `tidystata`

``` r

mutate(data, str_x = tostring(num_x))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Labelled values keep their codes; decode() gives the value labels
instead. Formatting and retained precision can differ from Stata
tostring; choose an explicit format when exact text or round-trip
precision matters.

[Stata reference](https://www.stata.com/manuals/ddestring.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `winsor2`

Winsorise at the 1st and 99th percentiles

Stata

``` stata
winsor2 x, cuts(1 99)
```

R `datawizard`

``` r

mutate(data, x_w = datawizard::winsorize(x, threshold = 0.01))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
datawizard uses R quantile cutpoints while winsor2 uses Stata percentile
rules; small samples and ties can therefore yield different caps.

[Stata reference](https://ideas.repec.org/c/boc/bocode/s457765.html) ·
[R reference](https://cran.r-project.org/package=datawizard)

## `xtile`

Quantile groups

Stata

``` stata
xtile q = x, nquantiles(4)
```

R `tidystata`

``` r

mutate(data, q = xtile(x, 4))
```

xtile() follows Stata's rule, so equal values stay in the same group.
Returns an ordered factor by default, or integer codes with labels =
FALSE. Inside grouped mutate(), the default is integer codes; labels =
TRUE explicitly requests labels.

[Stata reference](https://www.stata.com/manuals/dpctile.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

1 more examples and alternatives

Weighted quantile groups

Stata

``` stata
xtile q = x [aweight = w], nquantiles(4)
```

R `tidystata`

``` r

mutate(data, q = xtile(x, 4, wt = w))
```

[Stata reference](https://www.stata.com/manuals/dpctile.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)
