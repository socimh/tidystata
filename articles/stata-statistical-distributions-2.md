## `invweibullph`

Find a PH Weibull percentile

Stata

``` stata

```


## `lnigammaden`

Evaluate an inverse-gamma log density

Stata

``` stata
display lnigammaden(3,2,4)
```

R `stats`

``` r

stats::dgamma(1/4,shape=3,rate=2,log=TRUE)-2*log(4)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses the reciprocal-gamma change of variables with its log-Jacobian.
Match Stata shape and scale parameterization; numerical tail underflow
can differ.

[Stata
reference](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/GammaDist.html)

## `npnF`

Solve a noncentral F probability for noncentrality

Stata

``` stata
display npnF(4,20,2,0.5)
```

R `stats`

``` r

stats::uniroot(function(ncp) stats::pf(2,df1=4,df2=20,ncp=ncp)-0.5,c(0,50),tol=1e-10)$root
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Numerically inverts the noncentral F CDF over the displayed bracket.
Other inputs can require a different bracket; solver tolerances differ
from Stata.

[Stata
reference](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/uniroot.html)
