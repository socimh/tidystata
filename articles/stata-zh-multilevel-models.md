## `menbreg`

二次均值方差负二项混合模型

Stata

``` stata
menbreg nb x || id:, intmethod(laplace)
```

R `glmmTMB`

``` r

glmmTMB::glmmTMB(nb ~ x + (1 | id), data = data, family = glmmTMB::nbinom2())
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
采用高斯随机截距及Laplace似然的NB2模型。Stata显式intmethod(laplace)匹配此近似。R离散参数为Stata
NB2 alpha的倒数；比较辅助参数时须转换。

[Stata 参考](https://www.stata.com/manuals/memenbreg.pdf) · [R
参考](https://cran.r-project.org/web/packages/glmmTMB/glmmTMB.pdf)

## `menl`

随机系数非线性指数增长

Stata

``` stata
menl y = {A}*exp({B}*x), define(A: {a0}+{U[id]})
```

R `nlme`

``` r

nlme::nlme(y ~ A * exp(B * x), data = data, fixed = A + B ~ 1, random = A ~ 1 | id, start = c(A = 2, B = .25))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
高斯非线性混合模型，个体振幅A随机变化，指数速率B共同。两者均采用ML。初始值仅用于数值优化，不约束参数估计。

[Stata 参考](https://www.stata.com/manuals/memenl.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/nlme/html/00Index.html)
