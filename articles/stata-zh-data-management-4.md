## `merge`

记录仅主表、仅附表与匹配状态

Stata

``` stata
merge 1:1 id using other.dta, generate(status)
```

R `dplyr`

``` r

data$.master <- TRUE; other$.using <- TRUE; data <- dplyr::full_join(data,other,by='id',relationship='one-to-one'); data$status <- ifelse(is.na(data$.master),2L,ifelse(is.na(data$.using),1L,3L)); data$.master <- NULL; data$.using <- NULL
```

除非明确展示 update，非键列名需互不重复。dplyr 会为重名列添加后缀；普通
Stata merge 在匹配行保留主表取值，包括主表缺失值。

参考](https://dplyr.tidyverse.org/reference/index.html)

## `missings`

删除所选数值变量全部缺失的行

Stata

``` stata
missings dropobs x y, force
```

R `dplyr`

``` r

data <- dplyr::filter_out(data, dplyr::if_all(c(x, y), is.na))
```

filter_out() 需要 dplyr 1.2.0 或更高版本。

[Stata
参考](https://journals.sagepub.com/doi/pdf/10.1177/1536867X1501500413) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)

删除完全缺失的数值列

Stata

``` stata
missings dropvars, force
```

R `dplyr`

``` r

data <- dplyr::select(data, !dplyr::where(~ all(is.na(.x))))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
删除所有类型中完全缺失的列，而不只是数值列。

[Stata
参考](https://journals.sagepub.com/doi/pdf/10.1177/1536867X1501500413) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)

data <- dplyr::mutate(data, x = tidystata::mvdecode(x, c(-99, -98)))

data$x[data$x %in% -99] <- haven::tagged_na('a')

带标记缺失保留标记，但 R 比较仍遵循 NA 语义。
