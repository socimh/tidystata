## `alpha`

不自动反向计分地估计原始Cronbach alpha

Stata

``` stata
alpha q1 q2 q3, asis
```

R `psych`

``` r

psych::alpha(data[c("q1","q2","q3")],check.keys=FALSE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
asis关闭Stata题项方向自动调整；R中显式指定check.keys=FALSE。

[Stata 参考](https://www.stata.com/manuals/mvalpha.pdf) · [R
参考](https://cran.r-project.org/web/packages/psych/psych.pdf)

## `candisc`

估计典型线性判别方向

Stata

``` stata
candisc x y z w, group(g)
```

R `MASS`

``` r

{ sample <- droplevels(stats::model.frame(g ~ x + y + z + w, data = data, na.action = stats::na.omit)); groups <- length(unique(sample$g)); MASS::lda(g ~ x + y + z + w, data = sample, prior = rep(1 / groups, groups)) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
在完整观测因子类别间使用等先验概率；比较预测前须对齐类别标签和判别标准化。

[Stata 参考](https://www.stata.com/manuals/mv.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/MASS/html/lda.html)

## `discrim`


