## `decode`

把带标签的数值变量转换成文本变量

Stata

``` stata
decode x, generate(str_x)
```

R `tidystata`

``` r

mutate(data, str_x = decode(x))
```

[Stata 参考](https://www.stata.com/manuals/dencode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `encode`

把文本变量转换成带标签的数值变量

Stata

``` stata
encode str_x, generate(x)
```

R `tidystata`

``` r

mutate(data, x = encode(str_x))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
字符输入按 UTF-8 基数排序从 1 分配新编码；NA 和空字符串视为缺失。可能与
Stata 的区域排序不同。因子输入保留原编号和全部水平。

[Stata 参考](https://www.stata.com/manuals/dencode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/type_conversion.html)

## `label`

给数值变量的所有取值贴上标签

Stata

``` stata
label define gender 1 "male" 2 "female"
```

R `dplyr`

``` r

mutate(data, gender = factor(gender, levels = 1:2, labels = c("male", "female")))
```

R 中带标签的类别变量通常用因子（factor）存储。请明确写出
levels，确保每个取值对应正确的标签。

[Stata 参考](https://www.stata.com/manuals/dlabel.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

删除数值标签

Stata

``` stata
label drop yesno
```

R `haven`

``` r

mutate(data, x = haven::zap_labels(x))
```

[Stata 参考](https://www.stata.com/manuals/dlabel.pdf) · [R
参考](https://cran.r-project.org/package=haven)

把数值标签加到变量上

Stata

``` stata
label values x yesno
```

R `haven`

``` r

mutate(data, x = haven::labelled(x, yesno))
```

先定义一次标签，例如 yesno \<- c(No = 0, Yes = 1)，再加到任意变量上；R
中更常用的做法是 factor()。

[Stata 参考](https://www.stata.com/manuals/dlabel.pdf) · [R
参考](https://cran.r-project.org/package=haven)

给数值变量的部分取值贴上标签

Stata

``` stata
label define x 9 "Unknown" 10 "Refused"
```

R `haven`

``` r

mutate(data, x = haven::labelled(x, c(Unknown = 9, Refused = 10)))
```

haven 保留部分取值的标签，便于与 Stata 互通。tab()
显示数值标签；codebook() 报告个数和变量标签，不列出数值标签映射。

[Stata 参考](https://www.stata.com/manuals/dlabel.pdf) · [R
参考](https://cran.r-project.org/package=haven)

另有 2 个示例及替代实现

查看取值标签

Stata

``` stata
label list x
```

R `base`

``` r

levels(data$x)
```

对于用 haven 读入的带标签数据，可用 haven::print_labels(data\$x)。

[Stata 参考](https://www.stata.com/manuals/dlabel.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/levels.html)

贴上变量标签

Stata

``` stata
label variable x "Variable name"
```

R `labelled`

``` r

labelled::set_variable_labels(data, x = "Variable name")
```

从 Stata 文件读入的变量标签会被保留；variables() 和 codebook()
会显示它们。

[Stata 参考](https://www.stata.com/manuals/dlabel.pdf) · [R
参考](https://cran.r-project.org/package=labelled)

## `notes`

给变量添加注释

Stata

``` stata
notes x: Collected in wave 2
```

R `base`

``` r

attr(data$x, "note") <- "Collected in wave 2"
```

R 没有 notes 功能；通常用属性或脚本中的注释代替。

[Stata 参考](https://www.stata.com/manuals/dnotes.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/attr.html)
