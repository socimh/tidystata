## `append`

垂直合并两个数据

Stata

``` stata
append using data2
```

R `dplyr`

``` r

bind_rows(data1, data2)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
bind_rows() 使用 R 类型提升和属性规则；.id 创建字符串来源标记，而
append, generate() 使用数值码。

[Stata 参考](https://www.stata.com/manuals/dappend.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

另有 1 个示例及替代实现

垂直合并并记录每行的来源

Stata

``` stata
append using data2, generate(source)
```

R `dplyr`

``` r

dplyr::bind_rows(data1, data2, .id = "source") |> dplyr::mutate(source = as.integer(source) - 1L)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
采用数值来源编码：主数据为零，第一个using数据为一，与Stata append,
generate()一致。 bind_rows() 使用 R 类型提升和属性规则；.id
创建字符串来源标记，而 append, generate() 使用数值码。

[Stata 参考](https://www.stata.com/manuals/dappend.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `cross`

两个数据所有行的组合

Stata

``` stata
cross using data2
```

R `dplyr`

``` r

cross_join(data1, data2)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
cross_join() 为重名列加后缀；Stata cross
对重名列保留主数据值。获得相同列前须先处理重名。

[Stata 参考](https://www.stata.com/manuals/dcross.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `joinby`

在每个 id 内形成所有配对

Stata

``` stata
joinby id using data2
```

R `dplyr`

``` r

inner_join(data1, data2, by = "id", relationship = "many-to-many")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
dplyr 为重名非键列加后缀而非保留 Stata 主数据值，不创建
\_merge，也不执行声明的 1:1 键约束。

[Stata 参考](https://www.stata.com/manuals/djoinby.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `merge`

根据行的位置，水平合并两个数据

Stata

``` stata
merge 1:1 _n using data2
```

R `dplyr`

``` r

bind_cols(data1, data2)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
bind_cols() 要求行数相同（或可回收单行）并修复重名列；merge 1:1 \_n
可保留未匹配行。

[Stata 参考](https://www.stata.com/manuals/dmerge.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

根据 id 一对一合并，并报告匹配结果

Stata

``` stata
merge 1:1 id using data2
```

R `tidystata`

``` r

stata_merge(data1, data2, "1:1", by = "id")
```

与 Stata 一样保留所有个案，并生成记录匹配结果的 .merge
变量。full_join(data1, data2, by = "id") 合并但不报告。

[Stata 参考](https://www.stata.com/manuals/dmerge.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

``` r
stata_merge(data1, data2, "1:m", by = "id")
```

在 data1 中只保留 id 不在 data2 中的个案

Stata

``` stata
merge 1:1 id using data2, keep(master) keepusing(id) nogenerate
```

R `dplyr`

``` r

anti_join(data1, data2, by = "id")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
semi_join()/anti_join() 按键成员关系选择行，但不执行 Stata merge 1:1
的唯一键要求；须另行验证唯一性。

[Stata 参考](https://www.stata.com/manuals/dmerge.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

根据 id1 和 id2 合并两个数据

Stata

``` stata
merge 1:1 id1 id2 using data2, nogenerate
```

R `dplyr`

``` r

full_join(data1, data2, by = c("id1", "id2"))
```

有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

指定。 dplyr 为重名非键列加后缀而非保留 Stata 主数据值，不创建
\_merge，也不执行声明的 1:1 键约束。
