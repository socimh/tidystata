## `append`

Stack two datasets

Stata

``` stata
append using data2
```

R `dplyr`

``` r

bind_rows(data1, data2)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
bind_rows() has R type-promotion and attribute rules; .id creates string
source identifiers rather than the numeric codes of append, generate().

[Stata reference](https://www.stata.com/manuals/dappend.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

1 more examples and alternatives

Stack datasets and record where each row came from

Stata

``` stata
append using data2, generate(source)
```

R `dplyr`

``` r

dplyr::bind_rows(data1, data2, .id = "source") |> dplyr::mutate(source = as.integer(source) - 1L)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses numeric source IDs: zero for the master and one for the first using
dataset, as Stata append, generate() does. bind_rows() has R
type-promotion and attribute rules; .id creates string source
identifiers rather than the numeric codes of append, generate().

[Stata reference](https://www.stata.com/manuals/dappend.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `cross`

Every combination of rows from two datasets

Stata

``` stata
cross using data2
```

R `dplyr`

``` r

cross_join(data1, data2)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
cross_join() suffixes overlapping column names; Stata cross keeps master
values for overlapping names. Rename overlaps first to obtain the same
columns.

[Stata reference](https://www.stata.com/manuals/dcross.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `joinby`

All pairs of rows within each id

Stata

``` stata
joinby id using data2
```

R `dplyr`

``` r

inner_join(data1, data2, by = "id", relationship = "many-to-many")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
dplyr retains overlapping non-key columns with suffixes instead of Stata
master values, creates no \_merge, and does not enforce a declared 1:1
key constraint.

[Stata reference](https://www.stata.com/manuals/djoinby.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

## `merge`

Put two datasets side by side by row position

Stata

``` stata
merge 1:1 _n using data2
```

R `dplyr`

``` r

bind_cols(data1, data2)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
bind_cols() needs matching row counts (or recyclable one-row inputs) and
repairs duplicate names; merge 1:1 \_n can retain unmatched rows.

[Stata reference](https://www.stata.com/manuals/dmerge.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Merge with a match report

Stata

``` stata
merge 1:1 id using data2
```

R `tidystata`

``` r

stata_merge(data1, data2, "1:1", by = "id")
```

Like Stata, all rows are kept and a .merge column records the match
result. full_join(data1, data2, by = "id") merges without the report.

[Stata reference](https://www.stata.com/manuals/dmerge.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

Keep rows of data1 whose id is not in data2

Stata

``` stata
merge 1:1 id using data2, keep(master) keepusing(id) nogenerate
```

separately.

Merge on two keys

Stata

``` stata
merge 1:1 id1 id2 using data2, nogenerate
```

R `dplyr`

``` r

full_join(data1, data2, by = c("id1", "id2"))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Variables with the same name in both tables get suffixes; choose them
with suffix = c("\_data1", "\_data2"). dplyr retains overlapping non-key
columns with suffixes instead of Stata master values, creates no
\_merge, and does not enforce a declared 1:1 key constraint.

[Stata reference](https://www.stata.com/manuals/dmerge.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)
