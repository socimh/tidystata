## `bayesmh`

Bayesian Gaussian regression with normal and inverse-gamma priors

Stata

``` stata
bayesmh y x, likelihood(normal({var})) prior({y:}, normal(0,100)) prior({var}, igamma(1,1)) burnin(100) mcmcsize(1000) rseed(135)
```

R `MCMCpack`

``` r

draws <- MCMCpack::MCMCregress(y ~ x, data = data, burnin = 100, mcmc = 1000, b0 = 0, B0 = .01, c0 = 2, d0 = 2, seed = 135, verbose = 0)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Gaussian regression only. The coefficient priors are independent N(0,
100); B0 = .01 is their precision. c0 = d0 = 2 gives an
inverse-gamma(1, 1) prior on residual variance. The returned draws
object is a coda mcmc chain. Gibbs and Metropolis-Hastings samplers
differ; these short chains illustrate syntax, not convergence.

[Stata reference](https://www.stata.com/manuals/bayesbayesmh.pdf) · [R
reference](https://cran.r-project.org/web/packages/MCMCpack/MCMCpack.pdf)

## `bayespredict`

Posterior mean Gaussian regression response

Stata

``` stata
bayespredict pmean, mean
```

R `brms`

``` r

data$pmean <- stats::predict(fit, newdata = data, summary = TRUE, robust = FALSE)[, "Estimate"]
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
fit must be an existing univariate brmsfit using the same likelihood,
predictors and priors as the Stata model; data contains prediction rows.
predict.brmsfit summarizes simulated outcomes including observation
noise. Its mean estimates the posterior predictive mean. Match
group-level-effect treatment where applicable; Monte Carlo samples
differ.

[Stata reference](https://www.stata.com/manuals/bayesbayespredict.pdf) ·
[R
reference](https://paulbuerkner.com/brms/reference/predict.brmsfit.html)

## `bayesreps`

Replicated outcomes from a Gaussian posterior predictive distribution

Stata

``` stata
bayesreps yrep*, nreps(10)
```

R `brms`

``` r

t(brms::posterior_predict(fit, newdata = data, ndraws = 10))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
fit must be an existing univariate brmsfit matching the Stata model
likelihood, predictors and priors. Returns observations by 10 posterior
predictive replicates, including observation noise. brms randomly
selects posterior draws; match group-level-effect treatment where
applicable. Random draws and storage differ from Stata.

[Stata reference](https://www.stata.com/manuals/bayesbayespredict.pdf) ·
[R
reference](https://paulbuerkner.com/brms/reference/posterior_predict.brmsfit.html)

## `bayesstats`

Effective MCMC sample size

Stata

``` stata
bayesstats ess
```

R `coda`

``` r

{ ess <- coda::effectiveSize(draws); data.frame(ess = ess, correlation_time = nrow(draws) / ess, efficiency = ess / nrow(draws)) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
draws must be one coda mcmc chain after warmup. Reports ESS, correlation
time (draw count / ESS) and efficiency (ESS / draw count). coda uses an
autoregressive spectral estimate, whereas Stata truncates sample
autocorrelations; numerical diagnostics differ.

[Stata reference](https://www.stata.com/manuals/bayesbayesstatsess.pdf)
· [R
reference](https://cran.r-project.org/web/packages/coda/refman/coda.html)

Posterior means, standard deviations and quantiles

Stata

``` stata
bayesstats summary
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(draws), mean, sd, mcse = posterior::mcse_mean, median, ~stats::quantile(.x, probs = c(.025, .975)))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
draws must be a coda mcmc or mcmc.list object containing posterior
parameter draws, for example the result of MCMCpack::MCMCregress().
Reports means, SDs, MCSEs, medians and 95% equal-tailed intervals. MCSE
algorithms differ from Stata. Transform draws before summarizing a
transformed parameter.

[Stata
reference](https://www.stata.com/manuals/bayesbayesstatssummary.pdf) ·
[R
reference](https://mc-stan.org/posterior/reference/draws_summary.html)

``` r
posterior::summarise_draws(posterior::as_draws_array(coda::mcmc(exp(as.matrix(draws)[, "x", drop = FALSE]))), mean, sd, mcse = posterior::mcse_mean, median, ~stats::quantile(.x, probs = c(.025, .975)))
```

Ninety-percent highest-posterior-density interval

Stata

``` stata
bayesstats summary {y:x}, hpd clevel(90)
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(draws[, "x", drop = FALSE]), mean, sd, mcse = posterior::mcse_mean, median, hpd = ~coda::HPDinterval(coda::mcmc(.x), prob = .9)[1, ])
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
draws is a single coda mcmc chain with column x. Reports posterior
summaries and a 90% shortest contiguous HPD interval, rather than
interval endpoints alone. Multimodal posteriors may not have a single
HPD interval; MCSE algorithms differ from Stata.

[Stata
reference](https://www.stata.com/manuals/bayesbayesstatssummary.pdf) ·
[R
reference](https://mc-stan.org/posterior/reference/draws_summary.html)

## `bayestest`

Posterior probability of a positive slope

Stata

``` stata
bayestest interval {y:x}, lower(0)
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(coda::mcmc(1 * (draws[, "x", drop = FALSE] > 0))), mean, sd, mcse = posterior::mcse_mean)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
draws is one coda mcmc chain with parameter x. Summarizes the
interval-membership indicator: its mean is the posterior probability,
with SD and MCSE. Bounds are strict. MCSE algorithms differ from Stata;
a constant indicator may give undefined MCSE. This is not a Bayes factor
or a frequentist p-value.

[Stata
reference](https://www.stata.com/manuals/bayesbayestestinterval.pdf) ·
[R
reference](https://mc-stan.org/posterior/reference/draws_summary.html)

Posterior probability within a substantive effect interval

Stata

``` stata
bayestest interval {y:x}, lower(1.8) upper(2.2)
```

``` r
posterior::summarise_draws(posterior::as_draws_array(coda::mcmc(1 * (draws[, "x", drop = FALSE] > 1.8 & draws[, "x", drop = FALSE] < 2.2))), mean, sd, mcse = posterior::mcse_mean)
```
