## `zinb`

Fit a zero-inflated NB2 count model

Stata

``` stata
zinb count x, inflate(z)
```

R `pscl`

``` r

pscl::zeroinfl(count~x|z,data=data,dist="negbin",link="logit")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Negative-binomial theta is reciprocal to Stata alpha in the NB2
component.

[Stata reference](https://www.stata.com/manuals/rzinb.pdf) · [R
reference](https://cran.r-project.org/web/packages/pscl/pscl.pdf)

## `zip`

Fit zero-inflated Poisson with logit zero inflation

Stata

``` stata
zip count x, inflate(z)
```

R `pscl`

``` r

pscl::zeroinfl(count~x|z,data=data,dist="poisson",link="logit")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fits the stated zero-inflated Poisson model with separate count and
inflation equations. Match the inflation link, offsets and complete
cases; optimizers and coefficient labels differ.

[Stata reference](https://www.stata.com/manuals/rzip.pdf) · [R
reference](https://cran.r-project.org/web/packages/pscl/pscl.pdf)

Fit zero-inflated Poisson with probit zero inflation

Stata

``` stata
zip count x, inflate(z) probit
```

R `pscl`

``` r

pscl::zeroinfl(count~x|z,data=data,dist="poisson",link="probit")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fits the stated zero-inflated Poisson model with separate count and
inflation equations. Match the inflation link, offsets and complete
cases; optimizers and coefficient labels differ.

[Stata reference](https://www.stata.com/manuals/rzip.pdf) · [R
reference](https://cran.r-project.org/web/packages/pscl/pscl.pdf)
