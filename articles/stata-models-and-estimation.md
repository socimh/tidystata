## `betareg`

Fit beta regression with a cloglog mean link

Stata

``` stata
betareg share x, link(cloglog)
```

R `betareg`

``` r

betareg::betareg(share~x,data=data,link="cloglog",type="ML",link.phi="log")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses ordinary ML with a log link for precision, matching Stata
slink(log). Without link.phi="log", betareg reports constant phi on the
identity scale while Stata reports ln(phi). Responses must lie strictly
inside (0,1).

[Stata reference](https://www.stata.com/manuals/rbetareg.pdf) · [R
reference](https://cran.r-project.org/web/packages/betareg/betareg.pdf)

## `bsqreg`

Bootstrap quantile-regression inference

Stata

``` stata
bsqreg y x z, reps(99)
```

R `quantreg`

``` r

{ fit <- quantreg::rq(y~x+z,data=data,tau=0.5); summary(fit,se="boot",R=99) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses 99 bootstrap replications for quantile-regression inference. R and
Stata random streams and resampling implementations differ, so bootstrap
standard errors will not be identical.

[Stata reference](https://www.stata.com/manuals/rqreg.pdf) · [R
reference](https://cran.r-project.org/web/packages/quantreg/quantreg.pdf)

## `constraint`

Represent a linear equality constraint as a matrix

Stata

``` stata
constraint define 1 x = z
```

R `stats`

``` r

L <- matrix(c(0,1,-1),nrow=1,dimnames=list(NULL,c("intercept","x","z")))
```

Fixed workflow: L beta = 0 encodes equal x and z coefficients. A fitting
routine must enforce the constraint.

## `fracreg`

Fit fractional logit regression with sandwich inference

Stata

``` stata
fracreg logit share x
```

R `sandwich`

``` r

{ fit <- stats::glm(share ~ x,data=data,family=stats::quasibinomial(link="logit")); lmtest::coeftest(fit,vcov.=sandwich::vcovHC(fit,type="HC0"),df=Inf) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Quasi-binomial fit avoids a noninteger-success warning. Sandwich
inference is explicit; finite-sample corrections can differ.

[Stata reference](https://www.stata.com/manuals/rfracreg.pdf) · [R
reference](https://cran.r-project.org/web/packages/sandwich/sandwich.pdf)

## `glm`

Fit a gamma log-link model for positive outcomes

Stata

``` stata
glm y x z, family(gamma) link(log)
```

R `stats`

``` r

stats::glm(y ~ x + z, data=data, family=stats::Gamma(link="log"))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
The family and link are explicit. R and Stata can use different
dispersion scaling and reference tests even when fitted means agree;
align the sample and scale option before comparing standard errors.

[Stata reference](https://www.stata.com/manuals/rglm.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/glm.html)
