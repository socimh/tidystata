## `gcollapse`

按 gcollapse 流程汇总组均值

Stata

``` stata
gcollapse (mean) z=x, by(g)
```

R `dplyr`

``` r

data <- dplyr::summarise(data,z=mean(x,na.rm=TRUE),.by=g)
```

[Stata 参考](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)

在汇总均值旁保留组原始行数

Stata

``` stata
gcollapse (mean) z=x, by(g) freq(n)
```

R `dplyr`

``` r

data <- dplyr::summarise(data,z=mean(x,na.rm=TRUE),n=dplyr::n(),.by=g)
```

[Stata 参考](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)

将汇总组均值附回全部原始行

Stata

``` stata
gcollapse (mean) z=x, by(g) merge
```

R `dplyr`

``` r

data <- dplyr::mutate(data,z=mean(x,na.rm=TRUE),.by=g)
```

[Stata 参考](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)

汇总各组缺失值数

Stata

``` stata
gcollapse (nmissing) n=x, by(g)
```

R `dplyr`

``` r

data <- dplyr::summarise(data,n=sum(is.na(x)),.by=g)
```

[Stata 参考](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)

在完整数据中汇总各组不同值数

Stata

``` stata
gcollapse (nunique) n=x, by(g)
```

R `dplyr`

``` r

data <- dplyr::summarise(data,n=dplyr::n_distinct(x,na.rm=TRUE),.by=g)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
本例取值完整；不声称缺失类别的处理一致。

[Stata 参考](https://gtools.readthedocs.io/en/latest/usage/gcollapse/) ·
[R 参考](https://dplyr.tidyverse.org/reference/index.html)


[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
非加权流程，显式使用 R type-2
