## `areg`

Regression absorbing one categorical variable

Stata

``` stata
areg y x, absorb(id)
```

R `fixest`

``` r

fixest::feols(y ~ x | id, data = data, vcov = "iid", fixef.rm = "none")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Absorbs id in OLS with conventional covariance; retains singleton groups
as areg does.

[Stata reference](https://www.stata.com/manuals/rareg.pdf) · [R
reference](https://lrberge.github.io/fixest/articles/standard_errors.html)

## `bootstrap`

Bootstrap standard errors

Stata

``` stata
bootstrap, reps(500): regress y x
```

R `sandwich`

``` r

{ fit <- stats::lm(y ~ x, data = data); lmtest::coeftest(fit, vcov. = sandwich::vcovBS(fit, R = 500, type = "xy"), df = Inf) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fits OLS, resamples observation pairs 500 times, and reports
bootstrap-covariance normal-reference tests. Random streams differ
between R and Stata.

[Stata reference](https://www.stata.com/manuals/rbootstrap.pdf) · [R
reference](https://cran.r-project.org/web/packages/sandwich/sandwich.pdf)

## `cluster`

K-means clustering

Stata

[Stata

· [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/kmeans.html)

## `didregress`

Difference in differences (Stata 17+)

Stata

``` stata
didregress (y) (treated), group(id) time(year)
```

R `fixest`

``` r

fixest::feols(y ~ treated | id + year, data = data, vcov = ~id)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Group/time fixed-effect DID with group-clustered covariance. id is the
treatment-assignment group; the coefficient is ATET only under the DID
design assumptions. Stata diagnostics remain separate.

[Stata reference](https://www.stata.com/manuals/causaldidregress.pdf) ·
[R
reference](https://lrberge.github.io/fixest/articles/standard_errors.html)

## `margins`

Predictive margins by group

Stata

``` stata
margins g
```

R `marginaleffects`

``` r

marginaleffects::avg_predictions(fit, variables = "g", type = "response", df = if (inherits(fit, "lm") && !inherits(fit, "glm")) df.residual(fit) else Inf)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
For an ordinary lm or binomial/Poisson glm fitted with factor g: sets
every estimation-sample row to each g level before averaging. Use g,
since marginaleffects reserves the column name group.

[Stata reference](https://www.stata.com/manuals/rmargins.pdf) · [R
reference](https://marginaleffects.com/man/r/predictions.html)

Average marginal effects

Stata

``` stata
margins, dydx(*)
```

R `marginaleffects`

``` r

marginaleffects::avg_slopes(fit, type = "response", df = if (inherits(fit, "lm") && !inherits(fit, "glm")) df.residual(fit) else Inf)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
For ordinary lm or binomial/Poisson glm: averages response-scale
derivatives and factor discrete changes over the estimation sample; uses
lm residual t degrees of freedom and GLM normal inference.

[Stata reference](https://www.stata.com/manuals/rmargins.pdf) · [R
reference](https://marginaleffects.com/man/r/slopes.html)

## `mi`

Fit and combine models across imputations

Stata

``` stata
mi estimate: regress y x
```

R `mice`

``` r

mice::pool(with(imp, lm(y ~ x)))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Rubin pooling still requires matching complete-data degrees of freedom
and small-sample adjustments to mi estimate.

[Stata reference](https://www.stata.com/manuals/mimiestimate.pdf) · [R
reference](https://cran.r-project.org/package=mice)

Multiple imputation

Stata

``` stata
mi impute chained (regress) x1 x2 = y, add(20) burnin(10)
```

R `mice`

``` r

{ impute_data <- data[c("x1", "x2", "y")]; predictors <- matrix(c(0, 1, 1, 1, 0, 1, 0, 0, 0), nrow = 3, byrow = TRUE, dimnames = list(names(impute_data), names(impute_data))); imp <- mice::mice(impute_data, m = 20, method = c(x1 = "norm", x2 = "norm", y = ""), predictorMatrix = predictors, maxit = 10, printFlag = FALSE) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Creates 20 chained Gaussian-regression imputations for numeric x1/x2
using each other and fully observed y, with 10 iterations. Explicit
methods/predictors replace mice defaults; random draws do not coincide
across programs.

[Stata reference](https://www.stata.com/manuals/mimiimputechained.pdf) ·
[R reference](https://amices.org/mice/reference/mice.html)
