## `char`

Create characters from ASCII codes

Stata

``` stata
generate z = char(code)
```

R `base`

``` r

data$z <- vapply(data$code,intToUtf8,character(1))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Restricted to ASCII codes 1–127; extended-byte encodings are not Unicode
code points.

[Stata reference](https://www.stata.com/manuals/fnstringfunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `clock`

Text to a date-time

Stata

``` stata
generate t = clock(s, "YMDhms")
```

R `lubridate`

``` r

mutate(data, t = lubridate::ymd_hms(s))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
R uses Date/POSIXct or tsibble calendar classes, not Stata numeric
date/time counts from 1960; convert epochs and time zones when
exchanging underlying numeric values.

[Stata
reference](https://www.stata.com/manuals/fndateandtimefunctions.pdf) ·
[R reference](https://cran.r-project.org/package=lubridate)

Parse a date-time with an explicit UTC timezone

Stata

``` stata
generate double z = clock(s, "YMDhms")
```

R `base`

``` r

data$z <- as.POSIXct(data$s,format='%Y-%m-%d %H:%M:%S',tz='UTC')
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
POSIXct is seconds since 1970 with a timezone; Stata clock is
milliseconds since 1960 without a timezone.

[Stata
reference](https://www.stata.com/manuals/fndateandtimefunctions.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
