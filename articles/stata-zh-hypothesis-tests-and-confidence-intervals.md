## `bitest`

精确检验二元变量成功概率

Stata

``` stata
bitest b = 0.5
```

R `stats`

``` r

stats::binom.test(sum(data$b),nrow(data),p=0.5)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
返回精确双侧二项检验。代码假定所示二元样本无缺失；Stata还打印下尾和上尾概率。

[Stata 参考](https://www.stata.com/manuals/rbitest.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `nptrend`

检验比例的有序趋势

Stata

``` stata
nptrend b, group(g) carmitage
```

R `stats`

``` r

{ sample <- stats::na.omit(data[c("b", "g")]); successes <- tapply(sample$b, sample$g, sum); totals <- as.vector(table(sample$g)); stats::prop.trend.test(successes, totals, score = as.numeric(names(successes))) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
按有序数值g汇总二元变量b，两种软件均以组值作为Cochran-Armitage得分。

[Stata 参考](https://www.stata.com/manuals/rnptrend.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `sdtest`

检验一个正态总体的标准差

Stata

``` stata
sdtest y == 3
```

R `stats`

``` r

{ y <- data$y[!is.na(data$y)]; degrees <- length(y) - 1; statistic <- degrees * stats::var(y) / 3^2; c(chisq = statistic, df = degrees, p.value = 2 * min(stats::pchisq(statistic, degrees), stats::pchisq(statistic, degrees, lower.tail = FALSE))) }
```

## `sdtesti`

Stata

``` stata
sdtesti 30 . 2 40 . 3
```

R `stats`

``` r

{ f <- 2^2/3^2; c(F=f,p.value=2*min(stats::pf(f,29,39),stats::pf(f,29,39,lower.tail=FALSE))) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
使用标准差2和3、样本量30和40进行汇总数据正态理论方差比检验；句点省略未使用的均值。

[Stata 参考](https://www.stata.com/manuals/rsdtest.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)
