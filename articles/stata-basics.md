## `cd`

Change the working directory

Stata

``` stata
cd "path/to/folder"
```

R `base`

``` r

setwd("path/to/folder")
```

An RStudio project sets the working directory for you, so scripts can
use relative paths.

[Stata reference](https://www.stata.com/manuals/dcd.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/getwd.html)

## `clear`

Remove a dataset from memory

Stata

``` stata
clear
```

R `base`

``` r

rm(data)
```

Rarely needed: R holds many tables at once, each under its own name.

[Stata reference](https://www.stata.com/manuals/dclear.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/rm.html)

## `findit`

Find the R equivalent of a Stata command

Stata

``` stata
findit command
```

R `tidystata`

``` r

findit(command)
```

Bare words and comma-separated names work: findit(tab, sex, region). Add
hints such as findit(tab, gen), or quote full Stata syntax. A bare
command browses its whole family and shows up to five operations; a
clear specific query returns one answer, and ambiguous queries retain up
to ten relevant candidates. print(n = Inf) expands the returned results;
use the bare command for broader family operations. Within a matching
operation, recommendations prefer tidystata, then tidyverse, then other
packages or base R. findit() with no argument returns the whole
catalogue.

[Stata reference](https://www.stata.com/manuals/rsearch.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `global`

Store a value for later use

Stata

``` stata
global path "path/to/folder"
```

R `base`

``` r

path <- "path/to/folder"
```

Any R object works like a macro: assign it once and reuse its name, as
in setwd(path).

[Stata reference](https://www.stata.com/manuals/pmacro.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
