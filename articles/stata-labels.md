## `decode`

Turn labelled values into text

Stata

``` stata
decode x, generate(str_x)
```

R `tidystata`

``` r

mutate(data, str_x = decode(x))
```

[Stata reference](https://www.stata.com/manuals/dencode.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `encode`

Turn text into labelled categories

Stata

``` stata
encode str_x, generate(x)
```

R `tidystata`

``` r

mutate(data, x = encode(str_x))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Character input gets fresh codes from 1 in UTF-8 radix order; NA and
empty strings are missing. Locale-specific Stata ordering can differ.
Factor input preserves existing indices and all levels.

[Stata reference](https://www.stata.com/manuals/dencode.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/type_conversion.html)

## `label`

Label every value of a categorical variable

Stata

``` stata
label define gender 1 "male" 2 "female"
```

R `dplyr`

``` r

mutate(data, gender = factor(gender, levels = 1:2, labels = c("male", "female")))
```

In R a labelled categorical variable is usually a factor. Give levels
explicitly so each code gets the right label.

[Stata reference](https://www.stata.com/manuals/dlabel.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

Remove value labels

Stata

``` stata
label drop yesno
```

R `haven`

``` r

mutate(data, x = haven::zap_labels(x))
```

[Stata reference](https://www.stata.com/manuals/dlabel.pdf) · [R
reference](https://cran.r-project.org/package=haven)

Attach a value label to a variable

Stata

``` stata
label values x yesno
```

R `haven`

``` r

mutate(data, x = haven::labelled(x, yesno))
```

Define the labels once, as yesno \<- c(No = 0, Yes = 1), then attach
them to any variable; factor() is the usual R alternative.

[Stata reference](https://www.stata.com/manuals/dlabel.pdf) · [R
reference](https://cran.r-project.org/package=haven)

Label some values only

Stata

``` stata
label define x 9 "Unknown" 10 "Refused"
```

R `haven`

``` r

mutate(data, x = haven::labelled(x, c(Unknown = 9, Refused = 10)))
```

haven preserves partial value labels for a round trip to Stata. tab()
displays value labels; codebook() reports counts and variable labels
rather than value-label mappings.

[Stata reference](https://www.stata.com/manuals/dlabel.pdf) · [R
reference](https://cran.r-project.org/package=haven)

2 more examples and alternatives

Show the categories of a variable

Stata

``` stata
label list x
```

R `base`

``` r

levels(data$x)
```

For labelled data read with haven, use haven::print_labels(data\$x).

[Stata reference](https://www.stata.com/manuals/dlabel.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/levels.html)

Label a variable

Stata

``` stata
label variable x "Variable name"
```

R `labelled`

``` r

labelled::set_variable_labels(data, x = "Variable name")
```

Labels read from Stata files are kept; variables() and codebook()
display them.

[Stata reference](https://www.stata.com/manuals/dlabel.pdf) · [R
reference](https://cran.r-project.org/package=labelled)

## `notes`

Attach a note to a variable

Stata

``` stata
notes x: Collected in wave 2
```

R `base`

``` r

attr(data$x, "note") <- "Collected in wave 2"
```

R has no notes system; an attribute or a comment in the script is the
usual substitute.

[Stata reference](https://www.stata.com/manuals/dnotes.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/attr.html)
