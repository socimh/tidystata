## `cumul`

Create the empirical cumulative distribution of a variable

Stata

``` stata
cumul x, generate(c)
```

R `dplyr`

``` r

data$c <- dplyr::row_number(data$x) / sum(!is.na(data$x))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Missing values stay missing and are excluded from the denominator. By
default Stata gives tied values distinct cumulatives in an arbitrary
order; R breaks ties by row order. Weights and by() need an explicit
grouped or weighted version.

[Stata reference](https://www.stata.com/manuals/rcumul.pdf) · [R
reference](https://dplyr.tidyverse.org/reference/row_number.html)

Cumulative distribution with equal values for ties

Stata

``` stata
cumul x, generate(c) equal
```

R `dplyr`

``` r

data$c <- dplyr::cume_dist(data$x)
```

Tied values share the largest cumulative proportion, as ecdf(x)(x) does;
missing values stay missing.

[Stata reference](https://www.stata.com/manuals/rcumul.pdf) · [R
reference](https://dplyr.tidyverse.org/reference/percent_rank.html)

## `duplicates`

Retain the first observation per duplicated key

Stata

``` stata
duplicates drop id, force
```

R `tidystata`

``` r

data <- tidystata::duplicates_drop(data, id, .force = TRUE)
```

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/keys.html)
