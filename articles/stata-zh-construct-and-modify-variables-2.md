## `rename`

重命名变量

Stata

``` stata
rename x x2
```

R `dplyr`

``` r

rename(data, x2 = x)
```

注意顺序：新名字 = 旧名字。

[Stata 参考](https://www.stata.com/manuals/drename.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

另有 4 个示例及替代实现

同时重命名多个变量

Stata

``` stata
rename (a b) (c d)
```

R `dplyr`

``` r

rename(data, c = a, d = b)
```

[Stata 参考](https://www.stata.com/manuals/drenamegroup.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

给所有变量名加后缀

Stata

``` stata
rename * *_old
```

R `dplyr`

``` r

rename_with(data, ~ paste0(.x, "_old"))
```

[Stata 参考](https://www.stata.com/manuals/drenamegroup.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

批量重命名变量到小写

Stata

``` stata
rename *, lower
```

R `dplyr`

``` r

rename_with(data, tolower)
```

[Stata 参考](https://www.stata.com/manuals/drenamegroup.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

把部分变量名改为大写

Stata

``` stata
rename x*, upper
```

R `dplyr`

``` r

rename_with(data, toupper, starts_with("x"))
```

[Stata 参考](https://www.stata.com/manuals/drenamegroup.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `replace`

修改旧变量

Stata

``` stata
replace x = x^2
```

R `dplyr`

``` r

mutate(data, x = x^2)
```

[Stata 参考](https://www.stata.com/manuals/dgenerate.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

另有 2 个示例及替代实现

根据条件修改旧变量

Stata

``` stata
replace x = x^2 if x > 0
```

R `dplyr`

``` r

mutate(data, x = replace_when(x, x > 0 ~ x^2))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
Stata 数值缺失比较时大于所有有限数；R 比较返回 NA，replace_when()
会保留这些行的原值。replace_when() 需要 dplyr 1.2.0 或更高版本；较旧的
dplyr 可使用 if_else(x \> 0, x^2, x)。

[Stata 参考](https://www.stata.com/manuals/dgenerate.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

根据位置修改旧变量

Stata

``` stata
replace x = x^2 in 11/20
```

R `dplyr`

``` r

mutate(data, x = if_else(row_number() %in% 11:20, x^2, x))
```

[Stata 参考](https://www.stata.com/manuals/dgenerate.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `rnormal`

正态分布随机数

Stata

``` stata
generate z = rnormal()
```

R `stats`

``` r

mutate(data, z = rnorm(n()))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 与 Stata 使用不同随机数流；相同数值种子不会复现相同随机数或抽样行。

[Stata 参考](https://www.stata.com/manuals/fnrandom-numberfunctions.pdf)
· [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Normal.html)

## `round`

四舍五入

Stata

``` stata
generate y = round(x, 0.1)
```

R `base`

``` r

mutate(data, y = round(x, 1))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 的第二个参数是小数位数。R 对 .5 采用四舍六入五成双（round(0.5) 为
0）；Stata 则向上取整。

[Stata 参考](https://www.stata.com/manuals/fnmathematicalfunctions.pdf)
· [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/Round.html)

## `sum`

累计求和

Stata

``` stata
generate cs = sum(x)
```

R `dplyr`

``` r

mutate(data, cs = cumsum(coalesce(x, 0)))
```

Stata 的 sum() 函数把缺失值当作 0，因此这里用 coalesce(x, 0)。

[Stata 参考](https://www.stata.com/manuals/fnmathematicalfunctions.pdf)
· [R 参考](https://cran.r-project.org/package=dplyr)

## `tabulate`

生成（类别变量）x 所有取值的虚拟变量

Stata

``` stata
tabulate x, generate(x_)
```

R `tidystata`

``` r

as_dummy(data, x)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
as_dummy(data, x, .names = "index") 像 Stata 一样把新列编号为
x_1、x_2……。也可用 fastDummies::dummy_cols(data, "x")。 as_dummy()
默认按取值命名列；.names = "index" 可生成 Stata
式编号后缀。还须核对缺失类别指示列规则。

[Stata 参考](https://www.stata.com/manuals/rtabulateoneway.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `tostring`

把数值变量转换成文本变量

Stata

``` stata
tostring num_x, generate(str_x)
```

R `tidystata`

``` r

mutate(data, str_x = tostring(num_x))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
带标签的变量保留数值代码；decode() 则返回数值标签。 格式和保留精度可能与
Stata tostring 不同；需要精确文本或往返精度时须明确格式。

[Stata 参考](https://www.stata.com/manuals/ddestring.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `winsor2`

在第 1 和第 99 百分位缩尾

Stata

``` stata
winsor2 x, cuts(1 99)
```

R `datawizard`

``` r

mutate(data, x_w = datawizard::winsorize(x, threshold = 0.01))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
datawizard 使用 R 分位数切点，winsor2 使用 Stata
百分位规则；小样本和并列值可能产生不同截尾边界。

[Stata 参考](https://ideas.repec.org/c/boc/bocode/s457765.html) · [R
参考](https://cran.r-project.org/package=datawizard)

## `xtile`

根据分位数分组

Stata

``` stata
xtile q = x, nquantiles(4)
```

R `tidystata`

``` r

mutate(data, q = xtile(x, 4))
```

xtile() 遵循 Stata 的规则，相同取值总在同一组。 默认返回有序因子，labels
= FALSE 返回整数代码。在分组 mutate() 中默认返回整数代码；labels = TRUE
显式请求标签。

[Stata 参考](https://www.stata.com/manuals/dpctile.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

另有 1 个示例及替代实现

根据加权分位数分组

Stata

``` stata
xtile q = x [aweight = w], nquantiles(4)
```

R `tidystata`

``` r

mutate(data, q = xtile(x, 4, wt = w))
```

[Stata 参考](https://www.stata.com/manuals/dpctile.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)
