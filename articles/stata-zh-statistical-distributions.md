计算二项分布含边界上尾概率

Stata

``` stata

```

``` r

```

Stata上尾概率包含k；R的lower.tail=FALSE不包含其q参数值，因此应使用k-1。

[Stata 参考](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·

参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Binomial.html)


[R 参考](https://cran.r-project.org/web/packages/mvtnorm/mvtnorm.pdf)

## `corr2data`

生成样本矩精确符合指定值的伪数据

Stata

``` stata
corr2data x y, n(100)
```

R `MASS`

``` r

stats::setNames(as.data.frame(MASS::mvrnorm(n=100,mu=c(0,0),Sigma=diag(2),empirical=TRUE)),c("x","y"))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
empirical=TRUE强制样本均值和协方差符合设定；此类伪数据不是独立随机抽样。

[Stata 参考](https://www.stata.com/manuals/dcorr2data.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/MASS/html/mvrnorm.html)
