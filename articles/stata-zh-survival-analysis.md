Cox比例风险诊断

Stata

``` stata
estat phtest, detail
```

R `survival`

``` r

survival::cox.zph(fit, transform = "identity")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
在相同Cox拟合后，identity变换对应Stata默认时间尺度。两者均通过Schoenfeld残差检验比例风险。当前survival采用得分检验实现，有限样本统计量可能与Stata残差相关检验不同。

[Stata 参考](https://www.stata.com/manuals/ststcoxpostestimation.pdf) ·
[R
参考](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/00Index.html)

## `stcox`

``` stata

```

