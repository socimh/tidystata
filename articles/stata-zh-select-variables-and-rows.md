## `drop`

删除满足条件的行

Stata

``` stata
drop if x == 1
```

R `dplyr`

``` r

filter_out(data, x == 1)
```

Stata 会保留 x 缺失的行，filter_out() 也会保留；它需要 dplyr 1.2.0
或更高版本。较旧的 dplyr 可使用 filter(data, x != 1 \| is.na(x))。

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

按位置删除行

Stata

``` stata
drop in 1/4
```

R `dplyr`

``` r

slice(data, -(1:4))
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

删除单个变量

Stata

``` stata
drop x
```

R `dplyr`

``` r

select(data, -x)
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

删除多个变量

Stata

``` stata
drop x1 x3-x5
```

R `dplyr`

``` r

select(data, -c(x1, x3:x5))
```

也可以按位置删除：select(data, -c(1, 3:5))。

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

删除 x 缺失的行

Stata

``` stata
drop if missing(x)
```

R `dplyr`

``` r

filter(data, !is.na(x))
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `duplicates`

删除完全重复的行

Stata

``` stata
duplicates drop
```

R `tidystata`

``` r

duplicates_drop(data)
```

[Stata 参考](https://www.stata.com/manuals/dduplicates.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

只保留某些变量未重复行

Stata

``` stata
duplicates drop x1 x2, force
```

R `tidystata`

``` r

duplicates_drop(data, x1, x2, .force = TRUE)
```

dplyr 中的对应写法是 distinct(data, x1, x2, .keep_all = TRUE)。

[Stata 参考](https://www.stata.com/manuals/dduplicates.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `keep`

根据某些变量取值，保留数据特定行

Stata

``` stata
keep if x1 == 1 & x2 == 2
```

R `dplyr`

``` r

filter(data, x1 == 1 & x2 == 2)
```

filter() 会删除条件为 NA 的行，因此含缺失值的行不会被保留。

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

保留多个变量

Stata

``` stata
keep x1 x3-x5
```

R `dplyr`

``` r

select(data, x1, x3:x5)
```

也可以按位置选择：select(data, 1, 3:5)。select_or_transmute()
还可以同时计算新变量。

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

按通配符保留变量

Stata

``` stata
keep x*
```

R `tidystata`

``` r

select(data, varlist("x*"))
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

保留数据前几行

Stata

``` stata
keep in 1/10
```

``` r

head(data, 10)
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

保留 x 未缺失行

Stata

``` stata
keep if !missing(x)
```

R `dplyr`

``` r

filter(data, !is.na(x))
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

保留取值在列表中的行

Stata

``` stata
keep if inlist(x, 1, 3, 5)
```

``` r

filter(data, x %in% c(1, 3, 5))
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R

保留取值在某个范围内的行

Stata

``` stata
keep if inrange(x, 5000, 10000)
```

R `dplyr`

``` r

filter(data, between(x, 5000, 10000))
```

[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

Stata

``` stata
keep in -10/-1
```


[Stata 参考](https://www.stata.com/manuals/ddrop.pdf) · [R

``` stata

```

``` r

slice(data, 7:12)
```

## `sample`

抽取 10% 的随机样本，并确保可重复

Stata

``` stata
set seed 2024; sample 10
```

R `tidystata`

``` r

data |> slice_sample(prop = 0.1) |> set_seed(2024)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 与 Stata 使用不同随机数流；相同数值种子不会复现相同随机数或抽样行。

[Stata 参考](https://www.stata.com/manuals/dsample.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

抽取 1000 条个案的随机样本，并确保可重复

Stata

``` stata
set seed 2024; sample 1000, count
```

R `tidystata`

``` r

data |> slice_sample(n = 1000) |> set_seed(2024)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
set_seed() 会在抽样之前设定种子，因此可以写在同一条管道中。 R 与 Stata
使用不同随机数流；相同数值种子不会复现相同随机数或抽样行。

[Stata 参考](https://www.stata.com/manuals/dsample.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)
