## `estat`

调查均值变异系数

Stata

``` stata
estat cv
```

R `survey`

``` r

100 * survey::cv(survey::svymean(~y, des))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
以百分数报告变异系数：100\*SE(估计量)/估计量，对应Stata estat
cv。本例对象为设计加权均值y；均值接近零时不稳定。

[Stata 参考](https://www.stata.com/manuals/svyestat.pdf) · [R
参考](https://cran.r-project.org/web/packages/survey/survey.pdf)

调查Gamma对数连接模型

Stata

``` stata
svy: glm y x, family(gamma) link(log)
```

R `survey`

``` r

{ fit <- survey::svyglm(y ~ x, des, family = stats::Gamma(link = "log")); fit$df.residual <- survey::degf(des); fit }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
fit保留完整抽样设计及三明治协方差。Stata式系数检验采用summary(fit,
df.resid=survey::degf(des))；所示代码在拟合对象内设置此自由度。准分布族避免非整数权重警告。

[Stata 参考](https://www.stata.com/manuals/svy.pdf) · [R
参考](https://cran.r-project.org/web/packages/survey/survey.pdf)
