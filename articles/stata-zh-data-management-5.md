## `recode`

按 Stata 规则重编码指定取值

Stata

``` stata
recode x (1 = 10) (2 = 20), generate(z)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, z = tidystata::stata_recode(x, 1 ~ 10, 2 ~ 20))
```

未匹配的取值（包括缺失值）保持不变。规则与原始取值比较，因此
stata_recode(x, 1 ~ 2, 2 ~ 1) 可交换代码。NA ~ 0 重编码缺失值，相当于
(missing = 0)。

[Stata 参考](https://www.stata.com/manuals/drecode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/stata_recode.html)

按 Stata 规则重编码取值区间

Stata

``` stata
recode x (1/2 = 0) (3/6 = 1) (else = .), generate(binary)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, binary = tidystata::stata_recode(x, 1:2 ~ 0, 3:6 ~ 1, .default = NA))
```

在 stata_recode()（别名 recode()）中，1:2 表示闭区间 1 \<= x \<=
2（含小数），相当于 Stata 的 1/2。按第一条匹配的规则重编码。.default =
NA 相当于 else = .；不指定时保留未匹配的取值，与 Stata 相同。

[Stata 参考](https://www.stata.com/manuals/drecode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/stata_recode.html)

将闭数值区间合并为两组

Stata

``` stata
recode x (1/2=0) (3/6=1), generate(binary)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, binary = tidystata::stata_recode(x, 1:2 ~ 0, 3:6 ~ 1))
```

规则包含两端点和小数值；未匹配值保持不变。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/stata_recode.html)

重编码指定值并保留其他值

Stata

``` stata
recode x (1=10) (2=20), generate(z)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, z = tidystata::stata_recode(x, 1 ~ 10, 2 ~ 20))
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/stata_recode.html)

另有 1 个示例及替代实现

重编码取值并为新代码添加值标签

Stata

``` stata
recode x (min/2 = 0 "Low") (3/max = 1 "High"), generate(level)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, level = tidystata::stata_recode(x, Low = min:2 ~ 0, High = 3:max ~ 1))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
命名的规则为新代码添加值标签，结果为 haven_labelled
向量。原有值标签被移除，变量标签保留。Stata
会附加一个以变量命名的新值标签集。

[Stata 参考](https://www.stata.com/manuals/drecode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/stata_recode.html)

## `xi`

生成省略最低类别的虚拟变量

Stata

``` stata
xi i.g
```

R `tidystata`

``` r

data <- dplyr::select(tidystata::as_dummy(data, g, .names = "index"), -tidyselect::any_of("g_1"))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
保留原有列，并省略首个已观测类别。数值类别按取值排序；R

按类别代码命名虚拟变量，R 通过 .names="index"
按已观测类别编号。建模时使用 factor(g)；不复现 xi: 交互展开。
