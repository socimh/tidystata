## `correlate`

Pearson 相关系数（仅用完整个案）

Stata

``` stata
correlate x1 x2 x3
```

R `tidystata`

``` r

corr(data, x1, x2, x3)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
与 Stata correlate 一样，在各组内使用同一完整个案样本。返回 r 和 n，不含
p 值；.wide = TRUE 返回下三角表。.wt
支持频数或分析权重，零权重行被排除。未实现 Stata 的 covariance、means
和显示格式选项。各对变量使用各自完整样本时请用
pwcorr()；需要同一完整样本及 p 值时请用 pwcorr(.listwise = TRUE)。

[Stata 参考](https://www.stata.com/manuals/rcorrelate.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `list`

``` stata

```


打印所有行和列，不保存打印偏好。print_headtail(data) 最多显示首尾共 10

显示近似等间隔行，不插入分隔行。两者都不可见地返回完整输入，并保留已有预览偏好。如需在后续操作中保留紧凑显示，请用
preview()、preview_headtail() 或 preview_interval()；unpreview()
恢复普通打印。这些函数均保留全部数据；n
控制显示的数据行数，省略标记不计入其中。

## `oneway`

``` r
summary(aov(y ~ factor(group), data = data))
```

参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/prcomp.html)

n。允许小数频数权重是对 Stata 整数权重约定的扩展。
