## `about`

Inspect R version and platform information

Stata

``` stata
about
```

R `utils`

``` r

utils::sessionInfo()
```

Reports R session metadata; Stata license and serial information have no
R counterpart.

[Stata reference](https://www.stata.com/manuals/rabout.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/utils/html/sessionInfo.html)

## `adopath`

Inspect the package library search path

Stata

``` stata
adopath
```

R `base`

``` r

.libPaths()
```

R package libraries replace ado search directories; this only reads the
current path.

[Stata reference](https://www.stata.com/manuals/psysdir.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `args`

Receive two positional arguments in a function

Stata

``` stata
program define addtwo
args a b
display `a'+`b'
end
```

R `base`

``` r

addtwo <- function(a,b) a+b
```

R function arguments replace positional Stata macros; this is a fixed
program example.

[Stata reference](https://www.stata.com/manuals/psyntax.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `continue`

Skip the rest of one loop iteration

Stata

``` stata
forvalues i=1/4 {
    if `i'==2 continue
    display `i'
}
```

R `base`

``` r

out <- integer(); for (i in 1:4) { if(i==2) next; out <- c(out,i) }
```

Fixed workflow example; adapt the object and column names together.

[Stata reference](https://www.stata.com/manuals/pcontinue.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Exit a loop early

Stata

``` stata
forvalues i=1/4 {
    if `i'==3 continue, break
    display `i'
}
```

R `base`

``` r

out <- integer(); for (i in 1:4) { if(i==3) break; out <- c(out,i) }
```

Fixed workflow example; adapt the object and column names together.

[Stata reference](https://www.stata.com/manuals/pcontinue.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `creturn`

Inspect R version, platform, paths and numeric limits

Stata

``` stata
creturn list
```

R `base`

``` r

list(version=R.version.string,platform=R.version$platform,working_directory=getwd(),machine=.Machine)
```

Returns R's own settings and constants, not Stata's c-class values.

[Stata reference](https://www.stata.com/manuals/pcreturn.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `dataex`

Create reproducible R code for a small data example

Stata

``` stata
dataex id x in 1/3
```

R `base`

``` r

example <- data[1:3,c('id','x')]; text <- utils::capture.output(dput(example))
```

dput emits R reconstruction code, not Stata input code or forum markup.
Share only data already approved for disclosure.

[Stata
reference](https://www.statalist.org/forums/forum/general-stata-discussion/general/1301224-new-on-ssc-dataex-a-command-to-generate-a-properly-formatted-data-example-for-statalist)
· [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `exit`

Return early from a function

Stata

``` stata
program define positive
args x
if `x'<=0 exit
display `x'
end
```

R `base`

``` r

positive <- function(x) { if(x<=0) return(invisible(NULL)); x }
```

Function-level return only; quitting the R process would terminate the
user's session.

[Stata reference](https://www.stata.com/manuals/p.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `include`

Execute helper code in the current evaluation environment

Stata

``` stata
include helper.do
```

R `base`

``` r

sys.source(path,envir=environment())
```

Only sources the controlled temporary R helper here; R syntax replaces
the Stata do-file.

[Stata reference](https://www.stata.com/manuals/p.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `mark`

Create an inclusion marker from a condition

Stata

``` stata
mark touse if g == 2
```

R `base`

``` r

data$touse <- as.integer(!is.na(data$g) & data$g==2)
```

[Stata reference](https://www.stata.com/manuals/pmark.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `markout`

Clear an inclusion marker when variables are incomplete

Stata

``` stata
markout touse x y
```

R `base`

``` r

data$touse <- as.integer(data$touse==1 & stats::complete.cases(data[c('x','y')]))
```

[Stata reference](https://www.stata.com/manuals/pmark.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `matname`

Name matrix columns

Stata

``` stata
matname X first second, columns(1..2)
```

R `base`

``` r

colnames(X)[1:2] <- c("first", "second")
```

Renames columns 1 and 2 without changing names of any later columns.

[Stata reference](https://www.stata.com/manuals/pmatrixmkmat.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `mkmat`

Create a matrix from selected numeric variables

Stata

``` stata
mkmat x y, matrix(X)
```

R `base`

``` r

X <- as.matrix(data[c('x','y')])
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
X is the fixed matrix object name; R row names need not match Stata r1,
r2 labels.

[Stata reference](https://www.stata.com/manuals/pmatrixmkmat.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Create a matrix after listwise missing exclusion

Stata

``` stata
mkmat x y, matrix(X) nomissing
```

R `base`

``` r

X <- as.matrix(data[stats::complete.cases(data[c('x','y')]),c('x','y')])
```

[Stata reference](https://www.stata.com/manuals/pmatrixmkmat.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `numlist`

Expand a numeric list with a fixed step

Stata

``` stata
numlist "1(2)9"
```

R `base`

``` r

values <- seq(1,9,by=2)
```

Constructs this list directly; it does not parse arbitrary Stata numlist
strings.

[Stata reference](https://www.stata.com/manuals/pnumlist.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Expand a decreasing consecutive numeric list

Stata

``` stata
numlist "5/1"
```

R `base`

``` r

values <- seq(5,1,by=-1)
```

Direct R sequence workflow for the displayed Stata list.

[Stata reference](https://www.stata.com/manuals/pnumlist.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

query output

options()[c('width','digits','scipen')]

## `sleep`

Pause execution using milliseconds converted to seconds

Stata

``` stata
sleep 1
```

R `base`

``` r

Sys.sleep(0.001)
```

R Sys.sleep takes seconds; no machine-speed timing assertion is made.

[Stata reference](https://www.stata.com/manuals/psleep.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `sysdir`

Inspect R installation and temporary directories

Stata

``` stata
sysdir list
```

R `base`

``` r

list(home=R.home(),library=R.home('library'),temporary=tempdir())
```

Shows R directories; Stata BASE/PLUS/PERSONAL directories have no
one-to-one mapping.

[Stata reference](https://www.stata.com/manuals/psysdir.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `tempfile`

Reserve a unique temporary path

Stata

``` stata
tempfile cache
```

R `base`

``` r

path <- tempfile(fileext='.rds')
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
tempfile() reserves a name without creating a file; R does not guarantee
Stata-style cleanup of each named file when a function exits.

[Stata reference](https://www.stata.com/manuals/p.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `tokenize`

Split simple whitespace-separated tokens

Stata

``` stata
tokenize alpha beta gamma
```

R `base`

``` r

tokens <- strsplit('alpha beta gamma',' +')[[1]]
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
R returns a character vector instead of positional local macros;
quoted-token parsing differs.

[Stata reference](https://www.stata.com/manuals/ptokenize.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `unab`

Expand a column-name prefix wildcard

Stata

``` stata
unab vars : x*
```

R `base`

``` r

vars <- grep('^x',names(data),value=TRUE)
```

Handles the displayed simple prefix wildcard; this is not a complete
Stata varlist parser.

[Stata reference](https://www.stata.com/manuals/punab.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

body(base::mean.default)
