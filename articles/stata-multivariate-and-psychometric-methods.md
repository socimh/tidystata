## `alpha`

Estimate raw Cronbach alpha without reversing items

Stata

``` stata
alpha q1 q2 q3, asis
```

R `psych`

``` r

psych::alpha(data[c("q1","q2","q3")],check.keys=FALSE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
asis disables Stata item-direction reversal; check.keys=FALSE makes the
R direction rule explicit.

[Stata reference](https://www.stata.com/manuals/mvalpha.pdf) · [R
reference](https://cran.r-project.org/web/packages/psych/psych.pdf)

## `ca`

Perform simple correspondence analysis of a contingency table

Stata

``` stata
ca g h, dimensions(2) normalize(standard)
```

R `MASS`

``` r

```

same contingency table; axis signs are arbitrary.

[Stata reference](https://www.stata.com/manuals/mvca.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/MASS/html/corresp.html)

## `candisc`

Estimate canonical linear discriminant directions

Stata

``` stata
candisc x y z w, group(g)
```

R `MASS`

``` r

{ sample <- droplevels(stats::model.frame(g ~ x + y + z + w, data = data, na.action = stats::na.omit)); groups <- length(unique(sample$g)); MASS::lda(g ~ x + y + z + w, data = sample, prior = rep(1 / groups, groups)) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)

discriminant normalization before comparing predictions.

reference](https://stat.ethz.ch/R-manual/R-devel/library/MASS/html/lda.html)

## `hotelling`


``` r

{ n <- nrow(data); k <- 2; m <- colMeans(data[c("x","y")]); T2 <- n*drop(t(m)%*%solve(stats::cov(data[c("x","y")]),m)); F <- (n-k)/(k*(n-1))*T2; c(T2=T2,F=F,p.value=stats::pf(F,k,n-k,lower.tail=FALSE)) }
```
