## `dfbeta`

Obtain standardized deletion influence on one slope

Stata

``` stata
dfbeta x
```

R `stats`

``` r

stats::dfbetas(fit)[,"x"]
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Returns standardized coefficient-deletion diagnostics from dfbetas for
x; coefficient ordering, missing rows and diagnostic naming must be
aligned with the Stata model.

[Stata
reference](https://www.stata.com/manuals/rregresspostestimation.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/influence.measures.html)

## `estat`

Summarize variables in the actual estimation sample

Stata

``` stata
estat summarize
```

R `tidystata`

``` r

tidystata::summ(stats::model.frame(fit))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
After the displayed numeric OLS model, summarizes its complete-case
estimation sample with N, mean, SD, minimum and maximum; factor-variable
expansions require their explicit numeric model columns.

[Stata
reference](https://www.stata.com/manuals/rregresspostestimation.pdf) ·
[R reference](https://socimh.github.io/tidystata/reference/summ.html)

Compute variance inflation factors after OLS

Stata

``` stata
estat vif
```

R `car`

``` r

car::vif(fit)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
car returns ordinary VIFs for one-degree-of-freedom terms and
generalized VIFs for multi-parameter terms. Stata estat vif reports
column-level VIFs, so factor-term output is not directly
interchangeable.

[Stata
reference](https://www.stata.com/manuals/rregresspostestimation.pdf) ·
[R reference](https://cran.r-project.org/web/packages/car/car.pdf)

Test heteroskedasticity against one predictor using a studentized
statistic

Stata

``` stata
estat hettest x, iid
```

R `lmtest`

``` r

lmtest::bptest(fit,varformula=~x,data=data,studentize=TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses the studentized Koenker version of the Breusch-Pagan test,
corresponding to the iid variant shown. Match the auxiliary regressors
and estimation sample; the default bptest differs from default Stata
hettest.

[Stata
reference](https://www.stata.com/manuals/rregresspostestimation.pdf) ·
[R reference](https://cran.r-project.org/web/packages/lmtest/lmtest.pdf)

[Stata
