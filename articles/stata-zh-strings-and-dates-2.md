## `strofreal`

将数值格式化为补零文本

Stata

``` stata
generate z = strofreal(x, "%06.0f")
```

R `base`

``` r

data$z <- sprintf('%06.0f',data$x)
```

[Stata 参考](https://www.stata.com/manuals/fnstringfunctions.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `strpos`

是否包含某段文本

Stata

``` stata
generate has = strpos(name, "a") > 0
```

R `stringr`

``` r

mutate(data, has = str_detect(name, fixed("a")))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
R 的 Unicode、正则和大小写规则可能不同于非 ustr Stata 函数；Stata
空字符串即缺失，R 则区分空串和 NA。

[Stata 参考](https://www.stata.com/manuals/fnstringfunctions.pdf) · [R
参考](https://cran.r-project.org/package=stringr)

定位 ASCII 子串并以零表示未找到

Stata

``` stata

```

``` r

position <- regexpr('cat',data$s,fixed=TRUE); data$z <- ifelse(position<0,0L,as.integer(position))
```

[Stata 参考](https://www.stata.com/manuals/fnstringfunctions.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `strtoname`

``` stata

```


[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

``` r

data$z <- substr(gsub('[^A-Za-z0-9_]','_',data$s),1,32); data$z <- ifelse(grepl('^[0-9]',data$z),paste0('_',data$z),data$z)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
仅演示短 ASCII 名称；R 语法名称与 Stata 保留名规则不同。

参考](https://cran.r-project.org/package=stringr)
