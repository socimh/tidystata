## `egen`

Repeat the first nonmissing value

Stata

``` stata
egen z = firstnm(x)
```

R `base`

``` r

data$z <- data$x[which(!is.na(data$x))[1]]
```

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Repeat the interquartile range

Stata

``` stata
egen z = iqr(x)
```

R `base`

``` r

data$z <- diff(stats::quantile(data$x,c(.25,.75),na.rm=TRUE,type=2))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Uses R quantile type 2 for Stata's default empirical percentile rule.

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)


R `dplyr`

``` r

data <- dplyr::mutate(data, p = dplyr::percent_rank(x))
```

Uses (minimum rank - 1) / (nonmissing count - 1). Ties receive the
lowest rank; missing values stay missing. For c(2, 3, 5), returns c(0,
0.5, 1). With tied maxima the top rank can be below 1; a single observed
value has an undefined rank. This differs from cumulative proportions
computed by cume_dist() or stats::ecdf().

[Stata
reference](https://www.stata.com/support/faqs/statistics/percentile-ranks-and-plotting-positions/)
· [R reference](https://dplyr.tidyverse.org/reference/percent_rank.html)

Stata

``` stata
tempvar x_rank x_n
egen `x_rank' = rank(x), track
egen `x_n' = count(x)
generate p = 100 * (`x_rank' - 1) / (`x_n' - 1) if !missing(x)
```

R `dplyr`

``` r

data <- dplyr::mutate(data, p = 100 * dplyr::percent_rank(x))
```

Uses (minimum rank - 1) / (nonmissing count - 1) \* 100. Ties receive
the lowest rank; missing values stay missing. For c(2, 3, 5), returns
c(0, 50, 100). With tied maxima the top rank can be below 100; a single
observed value has an undefined rank. This differs from cumulative
proportions computed by cume_dist() or stats::ecdf().

[Stata
reference](https://www.stata.com/support/faqs/statistics/percentile-ranks-and-plotting-positions/)
