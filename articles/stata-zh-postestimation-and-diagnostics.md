Stata

``` stata
dfbeta x
```


[Stata 参考](https://www.stata.com/manuals/rregresspostestimation.pdf) ·

参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/influence.measures.html)

用学生化统计量检验与指定变量相关的异方差

Stata

``` stata
estat hettest x, iid
```

R `lmtest`

``` r

lmtest::bptest(fit,varformula=~x,data=data,studentize=TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
采用学生化Koenker版Breusch-Pagan检验，对应所示iid变体。须统一辅助回归变量和估计样本；bptest默认值不同于Stata默认hettest。

[Stata 参考](https://www.stata.com/manuals/rregresspostestimation.pdf) ·
[R 参考](https://cran.r-project.org/web/packages/lmtest/lmtest.pdf)

[R 参考](https://cran.r-project.org/web/packages/lmtest/lmtest.pdf)
