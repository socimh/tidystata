## `invweibullph`

计算比例风险威布尔分位数

Stata

``` stata
display invweibullph(2,0.5,0.9)
```

R `stats`

``` r

stats::qweibull(0.9, shape=2, scale=0.5^(-1/2))
```

## `lnigammaden`

计算逆伽马分布对数密度

Stata

``` stata
display lnigammaden(3,2,4)
```

R `stats`

``` r

stats::dgamma(1/4,shape=3,rate=2,log=TRUE)-2*log(4)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
使用倒数gamma变量变换及其对数Jacobian。须统一Stata的形状和尺度参数化；数值尾部下溢行为可能不同。

[Stata 参考](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·
[R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/GammaDist.html)

## `lnmvnormalden`

计算多变量正态对数密度

Stata

``` stata
matrix M = (0,0)
matrix V = I(2)
matrix X = (1,2)
display lnmvnormalden(M,V,X)
```

R `mvtnorm`

``` r

mvtnorm::dmvnorm(x=c(1,2),mean=c(0,0),sigma=diag(2),log=TRUE)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
固定示例：均值M=(0,0)，协方差V=I(2)，求值向量X=(1,2)。

[Stata 参考](https://www.stata.com/manuals/fnstatisticalfunctions.pdf) ·
[R 参考](https://cran.r-project.org/web/packages/mvtnorm/mvtnorm.pdf)

