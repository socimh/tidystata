## `ceil`

向上取整

Stata

``` stata
generate y = ceil(x)
```

R `base`

``` r

mutate(data, y = ceiling(x))
```

[Stata 参考](https://www.stata.com/manuals/fnmathematicalfunctions.pdf)
· [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/Round.html)

## `clonevar`

克隆一个变量

Stata

``` stata
clonevar x2 = x
```

R `dplyr`

``` r

mutate(data, x2 = x)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
mutate(x2 = x) 复制 R 向量和属性，但不完整复现 Stata clonevar
的变量特征及注释。

[Stata 参考](https://www.stata.com/manuals/dclonevar.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `collapse`

用统计量分组描述若干变量，并替换原数据

Stata

``` stata
collapse (mean) x1 x2, by(group)
```

R `dplyr`

``` r

summarise(data, across(c(x1, x2), ~ mean(.x, na.rm = TRUE)), .by = group)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
像 collapse 一样替换数据需要赋值：data \<- summarise(...)。summ(data,
x1, x2, .by = group) 则只显示汇总表。 R 保留缺失分组键；Stata tabstat
by() 和 tabulate summarize() 默认排除缺失分组类别。应核对分组样本。

[Stata 参考](https://www.stata.com/manuals/dcollapse.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

对不同变量使用不同的统计量

Stata

``` stata
collapse (count) n = x (sum) total = y, by(group)
```

R `dplyr`

``` r

summarise(data, n = sum(!is.na(x)), total = sum(y, na.rm = TRUE), .by = group)
```

[Stata 参考](https://www.stata.com/manuals/dcollapse.pdf) · [R
参考](https://cran.r-project.org/package=dplyr)

## `cond`

按条件取不同的值

Stata

``` stata
generate y = cond(x > 0, 1, 0)
```

R `dplyr`

``` r

mutate(data, y = if_else(x > 0, 1, 0))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
x 缺失时，Stata 的 cond() 取第一个值（缺失值视为很大）；if_else() 返回
NA。 Stata 数值缺失比较时大于所有有限数；R 比较返回
NA。应先明确处理缺失，再使用条件。

[Stata 参考](https://www.stata.com/manuals/fnprogrammingfunctions.pdf) ·
[R 参考](https://cran.r-project.org/package=dplyr)

## `destring`

把文本变量转换成数值变量

Stata

``` stata
destring str_x, generate(num_x)
```

R `tidystata`

``` r

mutate(data, num_x = destring(str_x))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
不是数字的文本会变为 NA 并给出警告，相当于 force 选项。destring(str_x,
ignore = "kg") 会先删除这些字符，相当于 ignore()，因此 "10 kg" 得到 10。
无效数字文本在此变为 NA 并警告；Stata destring 未指定 force
时拒绝转换含此类文本的变量。

[Stata 参考](https://www.stata.com/manuals/ddestring.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

## `egen`

根据分位数，将连续变量均等地分成类别变量

Stata

``` stata
egen bins = cut(x), group(10)
```

R `tidystata`

``` r

mutate(data, bins = xtile(x, 10))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
egen cut(), group() 有自己的分组规则；xtile() 遵循 Stata 的
xtile，这是分位数分组的常用命令。

[Stata 参考](https://www.stata.com/manuals/degen.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

1/0；需要一致存储类型时使用 as.integer()。

[Stata 参考](https://www.stata.com/manuals/degen.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/)

根据给定的切点分组

Stata

``` stata

```

``` r

```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

即使区间开闭一致，仍存储数值下界。

[Stata 参考](https://www.stata.com/manuals/degen.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/cut.html)

## `recode`

重编码变量

Stata

``` stata
recode x (1/5 = 1) (6/10 = 2) (11/15 = 3) (else = .), generate(x3g)
```

R `tidystata`

``` r

mutate(data, x3g = stata_recode(x, 1:5 ~ 1, 6:10 ~ 2, 11:15 ~ 3, .default = NA))
```

不满足任何条件的取值为 NA，相当于 Stata 的 else =
.。tidystata::stata_recode(x, 1:5 ~ 1, 6:10 ~ 2, 11:15 ~ 3, .default =
NA) 直接沿用 Stata 规则：1:5 是包含小数的闭区间；不指定 .default
时保留未匹配的取值。也可使用 car::recode()，或 dplyr 1.2.0 起的
replace_values()。

[Stata 参考](https://www.stata.com/manuals/drecode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/stata_recode.html)
