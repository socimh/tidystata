为汇总条形添加数值标签

Stata

``` stata
graph bar (mean) y, over(group) blabel(bar)
```

R `ggplot2`

``` r

{ plot_data <- aggregate(y ~ group, data, mean); ggplot2::ggplot(plot_data, ggplot2::aes(group, y)) + ggplot2::geom_col() + ggplot2::geom_text(ggplot2::aes(label = round(y, 1)), vjust = -0.3) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
复现所示计数、百分比或汇总图层，不复现Stata的graph显示默认值。须统一类别顺序和缺失处理；ggplot主题、轴尺度及柱标签采用R约定。

[Stata 参考](https://www.stata.com/manuals/g-2graph.pdf) · [R
参考](https://ggplot2.tidyverse.org/reference/index.html)

## `histogram`

直方图

Stata

``` stata
histogram x
```


[与 Stata
