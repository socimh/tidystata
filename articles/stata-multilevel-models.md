## `menbreg`

Negative-binomial mixed model with quadratic mean variance

Stata

``` stata
menbreg nb x || id:, intmethod(laplace)
```

R `glmmTMB`

``` r

glmmTMB::glmmTMB(nb ~ x + (1 | id), data = data, family = glmmTMB::nbinom2())
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
NB2 with a Gaussian random intercept and Laplace likelihood. Stata
intmethod(laplace) explicitly matches the approximation. R dispersion is
the inverse of Stata NB2 alpha; compare transformed ancillary
parameters.

reference](https://cran.r-project.org/web/packages/glmmTMB/glmmTMB.pdf)

## `menl`

Nonlinear exponential growth with random asymptote coefficient

Stata

``` stata
menl y = {A}*exp({B}*x), define(A: {a0}+{U[id]})
```

R `nlme`

``` r

nlme::nlme(y ~ A * exp(B * x), data = data, fixed = A + B ~ 1, random = A ~ 1 | id, start = c(A = 2, B = .25))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Gaussian nonlinear mixed model with random subject amplitude A and a
common exponential rate B. Both fit by ML. Starting values are numerical
aids, not a restriction on parameter estimates.

[Stata reference](https://www.stata.com/manuals/memenl.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/nlme/html/00Index.html)

xtoprobit ordinal x

ordinal::clmm(ordinal ~ x + (1 | id), data = data, link = "probit", nAGQ = 12)
