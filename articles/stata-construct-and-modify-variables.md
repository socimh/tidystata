``` stata
clonevar x2 = x
```

## `collapse`

Replace the data with group means

Stata

``` stata
collapse (mean) x1 x2, by(group)
```

R `dplyr`

``` r

summarise(data, across(c(x1, x2), ~ mean(.x, na.rm = TRUE)), .by = group)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Assign the result to replace the data, as collapse does: data \<-
summarise(...). summ(data, x1, x2, .by = group) shows a summary table
instead. R retains missing grouping keys; Stata tabstat by() and
tabulate summarize() exclude missing grouping categories unless
requested. Check the intended grouping sample.

[Stata reference](https://www.stata.com/manuals/dcollapse.pdf) · [R
reference](https://cran.r-project.org/package=dplyr)

``` r

summarise(data, n = sum(!is.na(x)), total = sum(y, na.rm = TRUE), .by = group)
```

reference](https://cran.r-project.org/package=dplyr)

## `cond`

One value if a condition holds, another if not

Stata

``` stata
generate y = cond(x > 0, 1, 0)
```

R `dplyr`

``` r

mutate(data, y = if_else(x > 0, 1, 0))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
With missing x, Stata's cond() takes the first value (missing counts as
large); if_else() returns NA. Stata numeric missing values compare
larger than every finite number; R comparisons return NA. Handle missing
values explicitly before applying the condition.

[Stata
reference](https://www.stata.com/manuals/fnprogrammingfunctions.pdf) ·
[R reference](https://cran.r-project.org/package=dplyr)

## `destring`

Text to numbers

Stata

``` stata
destring str_x, generate(num_x)
```

R `tidystata`

``` r

mutate(data, num_x = destring(str_x))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Text that is not a number becomes NA with a warning, as with force.
destring(str_x, ignore = "kg") removes those characters first, like
ignore(), so "10 kg" gives 10. Invalid numeric text becomes NA with a
warning here; Stata destring without force refuses conversion of a
variable containing such text.

[Stata reference](https://www.stata.com/manuals/ddestring.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

## `egen`

Ten groups of about equal size

Stata

``` stata
egen bins = cut(x), group(10)
```

R `tidystata`

``` r

mutate(data, bins = xtile(x, 10))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
egen cut(), group() has its own grouping rule; xtile() follows Stata's
xtile, the usual command for quantile groups.

[Stata reference](https://www.stata.com/manuals/degen.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/)

Groups by given cutpoints

Stata

``` stata

```

## `recode`

Recode ranges of values

Stata

``` stata
recode x (1/5 = 1) (6/10 = 2) (11/15 = 3) (else = .), generate(x3g)
```

R `tidystata`

``` r

mutate(data, x3g = stata_recode(x, 1:5 ~ 1, 6:10 ~ 2, 11:15 ~ 3, .default = NA))
```

Values that match no condition become NA, like else = . in Stata.
tidystata::stata_recode(x, 1:5 ~ 1, 6:10 ~ 2, 11:15 ~ 3, .default = NA)
follows Stata's rules directly: 1:5 is a closed range including
decimals, and without .default unmatched values are kept. car::recode()
and, from dplyr 1.2.0, replace_values() are other options.

[Stata reference](https://www.stata.com/manuals/drecode.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/stata_recode.html)
