## `bayesmh`

正态及逆Gamma先验的贝叶斯高斯回归

Stata

``` stata
bayesmh y x, likelihood(normal({var})) prior({y:}, normal(0,100)) prior({var}, igamma(1,1)) burnin(100) mcmcsize(1000) rseed(135)
```

R `MCMCpack`

``` r

draws <- MCMCpack::MCMCregress(y ~ x, data = data, burnin = 100, mcmc = 1000, b0 = 0, B0 = .01, c0 = 2, d0 = 2, seed = 135, verbose = 0)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
仅高斯回归。系数采用相互独立的N(0,100)先验；B0=.01是其精度。c0=d0=2对应残差方差的逆Gamma(1,1)先验。返回的draws是coda的mcmc链。Gibbs与Metropolis-Hastings采样器不同；短链仅演示语法，不能证明收敛。

[Stata 参考](https://www.stata.com/manuals/bayesbayesmh.pdf) · [R
参考](https://cran.r-project.org/web/packages/MCMCpack/MCMCpack.pdf)

## `bayespredict`

高斯回归响应的后验均值

Stata

``` stata
bayespredict pmean, mean
```

R `brms`

``` r

data$pmean <- stats::predict(fit, newdata = data, summary = TRUE, robust = FALSE)[, "Estimate"]
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
fit须为已拟合的单变量brmsfit，并与Stata模型采用相同似然、预测变量及先验；data包含待预测观测。predict.brmsfit汇总含观测噪声的模拟结局，其均值估计后验预测均值。含分组效应时须匹配其处理；蒙特卡洛抽样不同。

[Stata 参考](https://www.stata.com/manuals/bayesbayespredict.pdf) · [R
参考](https://paulbuerkner.com/brms/reference/predict.brmsfit.html)

## `bayesreps`

高斯后验预测分布的重复结局

Stata

``` stata
bayesreps yrep*, nreps(10)
```

R `brms`

``` r

t(brms::posterior_predict(fit, newdata = data, ndraws = 10))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
fit须为已拟合的单变量brmsfit，并匹配Stata模型的似然、预测变量及先验。返回观测行乘以10次后验预测重复的矩阵，包含观测噪声。brms随机选择后验抽样；含分组效应时须匹配其处理。随机抽样及存储方式与Stata不同。

[Stata 参考](https://www.stata.com/manuals/bayesbayespredict.pdf) · [R
参考](https://paulbuerkner.com/brms/reference/posterior_predict.brmsfit.html)

## `bayesstats`

MCMC有效样本量

Stata

``` stata
bayesstats ess
```

R `coda`

``` r

{ ess <- coda::effectiveSize(draws); data.frame(ess = ess, correlation_time = nrow(draws) / ess, efficiency = ess / nrow(draws)) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
draws须为去除预热期的单条coda
mcmc链。报告ESS、相关时间（抽样数/ESS）及效率（ESS/抽样数）。coda采用自回归谱估计，Stata采用截断样本自相关；诊断数值会有差异。

[Stata 参考](https://www.stata.com/manuals/bayesbayesstatsess.pdf) · [R
参考](https://cran.r-project.org/web/packages/coda/refman/coda.html)

后验均值标准差和分位数

Stata

``` stata
bayesstats summary
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(draws), mean, sd, mcse = posterior::mcse_mean, median, ~stats::quantile(.x, probs = c(.025, .975)))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
draws须为包含参数后验抽样的coda
mcmc或mcmc.list对象，例如MCMCpack::MCMCregress()的结果。报告均值、标准差、MCSE、中位数及95%等尾区间。MCSE算法与Stata不同。变换参数时须先变换抽样再汇总。

[Stata 参考](https://www.stata.com/manuals/bayesbayesstatssummary.pdf) ·
[R 参考](https://mc-stan.org/posterior/reference/draws_summary.html)

变换系数的后验汇总

Stata

``` stata
bayesstats summary (effect:exp({y:x}))
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(coda::mcmc(exp(as.matrix(draws)[, "x", drop = FALSE]))), mean, sd, mcse = posterior::mcse_mean, median, ~stats::quantile(.x, probs = c(.025, .975)))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
draws须为包含参数后验抽样的coda
mcmc或mcmc.list对象，例如MCMCpack::MCMCregress()的结果。报告均值、标准差、MCSE、中位数及95%等尾区间。MCSE算法与Stata不同。变换参数时须先变换抽样再汇总。

[Stata 参考](https://www.stata.com/manuals/bayesbayesstatssummary.pdf) ·
[R 参考](https://mc-stan.org/posterior/reference/draws_summary.html)

90%最高后验密度区间

Stata

``` stata
bayesstats summary {y:x}, hpd clevel(90)
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(draws[, "x", drop = FALSE]), mean, sd, mcse = posterior::mcse_mean, median, hpd = ~coda::HPDinterval(coda::mcmc(.x), prob = .9)[1, ])
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
draws为含x列的单条coda
mcmc链。报告后验汇总及90%最短连续HPD区间，而非仅返回区间端点。多峰后验可能不存在单一HPD区间；MCSE算法与Stata不同。

[Stata 参考](https://www.stata.com/manuals/bayesbayesstatssummary.pdf) ·
[R 参考](https://mc-stan.org/posterior/reference/draws_summary.html)

## `bayestest`

斜率为正的后验概率

Stata

``` stata
bayestest interval {y:x}, lower(0)
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(coda::mcmc(1 * (draws[, "x", drop = FALSE] > 0))), mean, sd, mcse = posterior::mcse_mean)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
draws为含参数x的单条coda
mcmc链。汇总区间指示变量：其均值为后验概率，并报告标准差与MCSE。使用严格不等式。MCSE算法与Stata不同；指示变量恒定时MCSE可能无法定义。这不是贝叶斯因子或频率学派p值。

[Stata 参考](https://www.stata.com/manuals/bayesbayestestinterval.pdf) ·
[R 参考](https://mc-stan.org/posterior/reference/draws_summary.html)

效应位于实质区间的后验概率

Stata

``` stata
bayestest interval {y:x}, lower(1.8) upper(2.2)
```

R `posterior`

``` r

posterior::summarise_draws(posterior::as_draws_array(coda::mcmc(1 * (draws[, "x", drop = FALSE] > 1.8 & draws[, "x", drop = FALSE] < 2.2))), mean, sd, mcse = posterior::mcse_mean)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
draws为含参数x的单条coda
mcmc链。汇总区间指示变量：其均值为后验概率，并报告标准差与MCSE。使用严格不等式。MCSE算法与Stata不同；指示变量恒定时MCSE可能无法定义。这不是贝叶斯因子或频率学派p值。

[Stata 参考](https://www.stata.com/manuals/bayesbayestestinterval.pdf) ·
