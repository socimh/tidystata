## `spdistance`

Distance between two identified planar locations

Stata

``` stata
spdistance 1 2
```

R `base`

``` r

sqrt(sum((as.numeric(data[data$id == 1, c("x", "y")]) - as.numeric(data[data$id == 2, c("x", "y")]))^2))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed workflow; adapt the named data columns explicitly. Planar
Euclidean distance only; longitude/latitude require a geodesic
calculation and explicit units.

[Stata reference](https://www.stata.com/manuals/spspdistance.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `spgenerate`

Compute a spatially lagged covariate

Stata

``` stata
spgenerate nearby = W*value
```

R `base`

``` r

drop(W %*% data$value)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
W rows and columns must be in the same id order as data\$value, with
identical normalization to Stata. The result is a spatial lag, not a
mean unless W is row-normalized.

[Stata reference](https://www.stata.com/manuals/spspgenerate.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `spmatrix`

Row-standardized inverse-distance spatial weights

Stata

``` stata
spmatrix create idistance W, normalize(row)
```

R `stats`

``` r

{ D <- as.matrix(stats::dist(data[c("x", "y")])); W <- matrix(0, nrow(D), ncol(D)); off <- row(D) != col(D); W[off] <- 1 / D[off]; W / rowSums(W) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed workflow; adapt the named data columns explicitly. Planar
distances, distinct non-coincident locations and matching row/column ID
order are required. Stata defaults to spectral normalization, so row
normalization is explicit.

[Stata reference](https://www.stata.com/manuals/spspmatrixcreate.pdf) ·
[R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)
