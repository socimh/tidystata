## `arima`

ARIMA model

Stata

``` stata
arima y, ar(1/2)
```

R `stats`

``` r

stats::arima(data$y, order = c(2, 0, 0), method = "ML")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Stationary AR(2) fitted by maximum likelihood. Use the same regular time
series and sample; initialization and optimizer details can differ. R
intercept is the process mean, so convert an AR-equation constant before
comparing.

[Stata reference](https://www.stata.com/manuals/tsarima.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/arima.html)

## `carryforward`

Carry the last observed value forward

Stata

``` stata
carryforward x, replace
```

R `tidyr`

``` r

tidyr::fill(data, x, .direction = "down")
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
group_by(data, id) first to fill within each panel unit. fill() crosses
panel boundaries unless grouped first; group_by(id) is needed for
within-unit carryforward.

[Stata reference](https://ideas.repec.org/c/boc/bocode/s444902.html) ·
[R reference](https://cran.r-project.org/package=tidyr)

## `d.`

First difference within each panel

Stata

``` stata
generate d_x = D.x
```

R `tidystata`

``` r

mutate(data, d_x = stata_diff(x, time = year), .by = id)
```

stata_diff(x, 2, time = year) is D2.x, the difference of differences.

[Stata
reference](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R reference](https://socimh.github.io/tidystata/reference/)

## `f.`

Lead within each panel

Stata

``` stata
generate lead_x = F.x
```

R `tidystata`

``` r

mutate(data, lead_x = stata_lead(x, time = year), .by = id)
```

Gaps in year give missing values, as in Stata.

[Stata
reference](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R reference](https://socimh.github.io/tidystata/reference/)

## `l.`

Lag within each panel

Stata

``` stata
generate lag_x = L.x
```

R `tidystata`

``` r

mutate(data, lag_x = stata_lag(x, time = year), .by = id)
```

Like Stata, gaps in year give missing values; dplyr::lag() shifts rows
instead. Use stata_lag(x, 2, time = year) for L2.x and unit = "month"
for monthly dates.

[Stata
reference](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R reference](https://socimh.github.io/tidystata/reference/)

1 more examples and alternatives

Two-period lag within each panel

Stata

``` stata
generate lag2_x = L2.x
```

R `tidystata`

``` r

dplyr::mutate(data, lag2_x = tidystata::stata_lag(x, 2, time = year), .by = id)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Shifts two time units within id and returns missing across gaps,
matching L2.x; dplyr lag would shift observed rows.

[Stata
reference](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R
reference](https://socimh.github.io/tidystata/reference/stata_lag.html)

## `tsfill`

Add rows for missing time points

Stata

``` stata
tsfill
```

R `tsibble`

``` r

tsibble::fill_gaps(ts_data)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
fill_gaps() fills each key's observed range by default; choose .full
explicitly for common panel bounds and ensure the tsibble interval
matches the Stata delta.

[Stata reference](https://www.stata.com/manuals/tstsfill.pdf) · [R
reference](https://cran.r-project.org/package=tsibble)

## `xtline`

One line plot per panel unit

Stata

``` stata
xtline y
```

R `ggplot2`

``` r

ggplot(data, aes(year, y)) + geom_line() + facet_wrap(~id)
```

aes(group = id) without facets draws all units in one plot, like the
overlay option.

[Stata reference](https://www.stata.com/manuals/xtxtline.pdf) · [R
reference](https://cran.r-project.org/package=ggplot2)

## `xtset`

Declare panel data

Stata

``` stata
xtset id year
```

R `tsibble`

``` r

tsibble::as_tsibble(data, key = id, index = year)
```

tidystata needs no declaration: stata_lag(x, time = year) with .by = id,
and fixest takes panel.id = ~id + year.

[Stata reference](https://www.stata.com/manuals/xtxtset.pdf) · [R
reference](https://cran.r-project.org/package=tsibble)
