## `bitest`

Test a binary success probability exactly

Stata

``` stata
bitest b = 0.5
```

R `stats`

``` r

stats::binom.test(sum(data$b),nrow(data),p=0.5)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Returns an exact two-sided binomial test. The code assumes the displayed
binary sample has no missing values; Stata additionally prints lower-
and upper-tail probabilities.

[Stata reference](https://www.stata.com/manuals/rbitest.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

## `nptrend`

``` r

{ sample <- stats::na.omit(data[c("b", "g")]); successes <- tapply(sample$b, sample$g, sum); totals <- as.vector(table(sample$g)); stats::prop.trend.test(successes, totals, score = as.numeric(names(successes))) }
```
