## `arima`

ARIMA 模型

Stata

``` stata
arima y, ar(1/2)
```

R `stats`

``` r

stats::arima(data$y, order = c(2, 0, 0), method = "ML")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
以最大似然拟合平稳
AR(2)。需使用相同等间隔时间序列和样本；初始化及优化器实现可能不同。R 的
intercept 为过程均值，比较前需转换 AR 方程常数。

[Stata 参考](https://www.stata.com/manuals/tsarima.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/arima.html)

## `carryforward`

用上一个非缺失值向下填充

Stata

``` stata
carryforward x, replace
```

R `tidyr`

``` r

tidyr::fill(data, x, .direction = "down")
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
先 group_by(data, id) 即可在每个面板个体内填充。 fill()
未先分组时会跨面板单位填补；单位内 carryforward 须先 group_by(id)。

[Stata 参考](https://ideas.repec.org/c/boc/bocode/s444902.html) · [R
参考](https://cran.r-project.org/package=tidyr)

## `d.`

面板内的一阶差分

Stata

``` stata
generate d_x = D.x
```

R `tidystata`

``` r

mutate(data, d_x = stata_diff(x, time = year), .by = id)
```

stata_diff(x, 2, time = year) 即 D2.x（差分的差分）。

[Stata
参考](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R 参考](https://socimh.github.io/tidystata/reference/)

## `f.`

面板内的前定变量

Stata

``` stata
generate lead_x = F.x
```

R `tidystata`

``` r

mutate(data, lead_x = stata_lead(x, time = year), .by = id)
```

与 Stata 相同，year 中断处为缺失值。

[Stata
参考](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R 参考](https://socimh.github.io/tidystata/reference/)

## `l.`

面板内的滞后变量

Stata

``` stata
generate lag_x = L.x
```

R `tidystata`

``` r

mutate(data, lag_x = stata_lag(x, time = year), .by = id)
```

与 Stata 相同，year 中断处为缺失值；dplyr::lag() 则只是按行移动。L2.x 用
stata_lag(x, 2, time = year)，月度日期加 unit = "month"。

[Stata
参考](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R 参考](https://socimh.github.io/tidystata/reference/)

另有 1 个示例及替代实现

面板内的二期滞后

Stata

``` stata
generate lag2_x = L2.x
```

R `tidystata`

``` r

dplyr::mutate(data, lag2_x = tidystata::stata_lag(x, 2, time = year), .by = id)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
在各 id 内滞后两个时间单位，跨缺口返回缺失，匹配 L2.x；dplyr lag
仅移动观测行。

[Stata
参考](https://www.stata.com/manuals/u11.pdf#u11.4.4Time-seriesvarlists)
· [R 参考](https://socimh.github.io/tidystata/reference/stata_lag.html)

## `tsfill`

补齐缺失的时间点

Stata

``` stata
tsfill
```

R `tsibble`

``` r

tsibble::fill_gaps(ts_data)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
fill_gaps() 默认补齐各键观测范围；共同面板边界须明确设 .full，并保证
tsibble 间隔匹配 Stata delta。

[Stata 参考](https://www.stata.com/manuals/tstsfill.pdf) · [R
参考](https://cran.r-project.org/package=tsibble)

## `xtline`

每个面板个体一张折线图

Stata

``` stata
xtline y
```

R `ggplot2`

``` r

ggplot(data, aes(year, y)) + geom_line() + facet_wrap(~id)
```

不分面而使用 aes(group = id) 会把所有个体画在一张图上，相当于 overlay
选项。

[Stata 参考](https://www.stata.com/manuals/xtxtline.pdf) · [R
参考](https://cran.r-project.org/package=ggplot2)

## `xtset`

声明面板数据

Stata

``` stata
xtset id year
```

R `tsibble`

``` r

tsibble::as_tsibble(data, key = id, index = year)
```

tidystata 无需声明：stata_lag(x, time = year) 配合 .by = id；fixest 用
panel.id = ~id + year。

[Stata 参考](https://www.stata.com/manuals/xtxtset.pdf) · [R
参考](https://cran.r-project.org/package=tsibble)
