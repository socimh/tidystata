## `meta`

声明通用效应量与抽样方差

Stata

``` stata
meta set yi sei
```

R `metafor`

``` r

metafor::escalc(measure = "GEN", yi = yi, sei = sei, data = data)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
两端均以sei输入标准误；metafor将其平方存为vi。escalc生成效应量数据，但不持久保存Stata式meta声明、标签或默认分析模型。

[Stata 参考](https://www.stata.com/manuals/meta.pdf) · [R
参考](https://cran.r-project.org/web/packages/metafor/metafor.pdf)

按年份累积的固定效应元分析

Stata

``` stata
meta summarize, cumulative(year)
```

R `metafor`

``` r

metafor::cumul(metafor::rma(yi, vi, data = data, method = "REML"), order = data$year)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
假定meta
set采用默认的random(reml)声明；metafor显式选择REML。Stata先前的common、fixed或random声明会改变目标。比较汇总结果前须统一研究顺序、缺失处理和异质性估计。

[Stata 参考](https://www.stata.com/manuals/meta.pdf) · [R
参考](https://cran.r-project.org/web/packages/metafor/metafor.pdf)

Freeman-Tukey变换比例

Stata

``` stata
meta esize cases n, esize(ftukeyprop)
```

R `metafor`

``` r

{ out <- metafor::escalc(measure = "PFT", xi = cases, ni = n, data = data); out$yi <- 2 * out$yi; out$vi <- 4 * out$vi; out }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
Stata将两个反正弦值相加，metafor的PFT取其平均。将yi乘2、vi乘4以匹配Stata尺度。零事件或全事件均不需连续性修正。

[Stata 参考](https://www.stata.com/manuals/metametaesize.pdf) · [R
参考](https://wviechtb.github.io/metafor/reference/escalc.html)

新研究真实效应的预测区间

Stata

``` stata
meta summarize, random(reml) predinterval
```

R `metafor`

``` r

{ fit <- metafor::rma(yi, vi, data = data, method = "REML"); out <- stats::predict(fit); half <- stats::qt(.975, df = fit$k - 2) * sqrt(fit$tau2 + fit$se^2); out$pi.lb <- out$pred - half; out$pi.ub <- out$pred + half; out }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
随机效应REML真实效应预测区间。显式采用Stata的t(K-2)及sqrt(tau2+SE(mu)^2)；合并均值置信限保留正态参考。要求至少三项研究。

[Stata 参考](https://www.stata.com/manuals/metametasummarize.pdf) · [R
参考](https://cran.r-project.org/web/packages/metafor/metafor.pdf)
