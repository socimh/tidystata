## `mi`

Extract first completed dataset

Stata

``` stata
mi extract 1
```

R `mice`

``` r

mice::complete(imp, 1)
```

Fixed workflow; adapt the named data columns explicitly. R mids metadata
and storage structures differ from Stata MI data styles.

[Stata reference](https://www.stata.com/manuals/mi.pdf) · [R
reference](https://cran.r-project.org/web/packages/mice/mice.pdf)

Chained-equation imputation using pmm

Stata

``` stata
mi impute chained (pmm, knn(5)) x z = y, add(3) rseed(108) burnin(10)
```

R `mice`

``` r

mice::mice(data, m = 3, maxit = 10, method = "pmm", seed = 108, donors = 5L, printFlag = FALSE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fresh FCS imputation of x and z using each other and complete y. These
packages implement the same model families but use different
random-number streams. R performs 10 iterations per chain; Stata uses
burnin(10). Assess convergence rather than treating this illustrative
schedule as sufficient.

[Stata reference](https://www.stata.com/manuals/mimiimputechained.pdf) ·
[R reference](https://cran.r-project.org/web/packages/mice/mice.pdf)

Pool coefficient vectors and covariance matrices directly

Stata

``` stata

```

R `mitools`

``` r

{ fits <- lapply(mice::complete(imp, "all"), function(d) stats::lm(y ~ x + z, data = d)); mitools::MIcombine(lapply(fits, stats::coef), lapply(fits, stats::vcov), df.complete = stats::df.residual(fits[[1L]])) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)

df.complete=n-3 for intercept,x,z. This preserves finite complete-data
degrees of freedom instead of MIcombine default infinity.

Stata

``` stata
mi impute chained (logit) category (pmm, knn(5)) x z = y, add(3) burnin(10)
```

R `mice`

``` r

{ methods <- mice::make.method(data); methods["category"] <- "logreg"; methods[c("x", "z")] <- "pmm"; mice::mice(data, m = 3, maxit = 10, method = methods, seed = 131, donors = 5L, printFlag = FALSE) }
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Data contains only y, x, z and category; y is complete, category is a
binary/unordered/ordered factor as stated. The visible method vector
selects its categorical model and PMM for x,z. Three fresh FCS
imputations use 10 iterations; inspect convergence. Random draws and
separation safeguards differ across software.

Combine repeated complete-data Wald tests

Stata

``` stata
mi test x
```

R `mice`

``` r

{ full <- with(imp, stats::lm(y ~ x + z)); reduced <- with(imp, stats::lm(y ~ z)); mice::D1(full, reduced) }
```

D1 pools coefficient estimates and covariance matrices for a
multivariate MI Wald test, as Stata mi test does. Use the same
coefficient ordering and complete-data degrees of freedom; D2 pools test
statistics and is a different rule.

[Stata reference](https://www.stata.com/manuals/mi.pdf) · [R
reference](https://cran.r-project.org/web/packages/mice/mice.pdf)
