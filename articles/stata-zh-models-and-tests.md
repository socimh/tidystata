## `biprobit`

联合拟合相关的二元probit方程

Stata

``` stata
biprobit y1 y2 x
```

R `VGAM`

``` r

VGAM::vglm(cbind(y1,y2)~x,family=VGAM::binom2.rho(),data=data)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
两个二元方程共享x并采用固定潜在相关；rho连接参数化不同，但拟合联合概率具有相同模型含义。

[Stata 参考](https://www.stata.com/manuals/rbiprobit.pdf) · [R
参考](https://cran.r-project.org/web/packages/VGAM/VGAM.pdf)

参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/predict.glm.html)

## `runtest`

检验阈值二分序列的游程是否随机

Stata

``` stata
runtest y, threshold(0)
```

R `stats`

``` r

{ above <- data$y>0; n1 <- sum(above); n0 <- sum(!above); runs <- 1+sum(diff(above)!=0); expected <- 1+2*n1*n0/(n1+n0); variance <- 2*n1*n0*(2*n1*n0-n1-n0)/((n1+n0)^2*(n1+n0-1)); z <- (runs-expected)/sqrt(variance); c(runs=runs,z=z,p.value=2*stats::pnorm(-abs(z))) }
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
使用大样本无连续性校正的游程统计量，对应Stata默认约定；使用此流程前需删除缺失值。

[Stata 参考](https://www.stata.com/manuals/rruntest.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)

``` r

{ z <- (10-12)/sqrt(2^2/30+3^2/40); c(z=z,p.value=2*stats::pnorm(-abs(z))) }
```
