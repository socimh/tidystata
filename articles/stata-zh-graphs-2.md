## `scatter`

散点图

Stata

``` stata
scatter y x
```

R `ggplot2`

``` r

ggplot(data, aes(x, y)) + geom_point()
```

[Stata 参考](https://www.stata.com/manuals/g-2graphtwowayscatter.pdf) ·
[R 参考](https://cran.r-project.org/package=ggplot2)

另有 23 个示例及替代实现

给点加标签

Stata

``` stata
scatter y x, mlabel(name)
```

R `ggplot2`

``` r

ggplot(data, aes(x, y, label = name)) + geom_point() + geom_text()
```

[Stata 参考](https://www.stata.com/manuals/g-2graphtwowayscatter.pdf) ·
[R 参考](https://cran.r-project.org/package=ggplot2)

添加参考线

Stata

``` stata
scatter y x, xline(0)
```

R `ggplot2`

``` r

ggplot(data, aes(x, y)) + geom_point() + geom_vline(xintercept = 0)
```

geom_hline(yintercept = 0) 相当于 yline()。

[Stata 参考](https://www.stata.com/manuals/g-2graphtwowayscatter.pdf) ·
[R 参考](https://cran.r-project.org/package=ggplot2)

使用 ggplot2 绘制散点图

Stata

``` stata
scatter y x
```

R `ggplot2`

``` r

ggplot2::ggplot(data, ggplot2::aes(x, y)) + ggplot2::geom_point()
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
对应所示坐标轴及图层；ggplot的折线按x排序，此处Stata使用sort。主题、坐标轴留白、缺失点警告和分面尺度采用R默认设置。

[Stata 参考](https://www.stata.com/manuals/g-2graph.pdf) · [R
参考](https://ggplot2.tidyverse.org/reference/index.html)

将绘图区设为正方形

Stata

``` stata

```

R `ggplot2`

``` r

ggplot2::ggplot(data, ggplot2::aes(x, y)) + ggplot2::geom_point() + ggplot2::theme(aspect.ratio = 1)
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
该 R 示例实现相同的作图目的，但尺寸、随机扰动和主题参数的数值尺度不与
Stata 完全一致。

[Stata 参考](https://www.stata.com/manuals/g-2graph.pdf) · [R
参考](https://ggplot2.tidyverse.org/reference/index.html)
