## Look it up from the console

With tidystata loaded,
[`findit()`](https://socimh.github.io/tidystata/reference/findit.md)
searches the same catalogue. Use a bare command, quote longer syntax, or
supply variable names:

``` r

findit(reg)
findit("merge 1:1 id, keep(match)")
findit(tab, sex, region)
```

R functions and English or Chinese questions also work. Append
`|> print(n = Inf)` to see all returned examples, notes and sources. See
[`findit()`](https://socimh.github.io/tidystata/reference/findit.md) for
details.

## Adapt an example

Replace illustrative variable names with yours. `data` is your dataset;
`data1` and `data2` are merge inputs, and `fit` is a fitted model.

The R label names the main package. Load any packages needed for
unqualified calls; many data-preparation examples use
[`library(dplyr)`](https://dplyr.tidyverse.org).
[`findit()`](https://socimh.github.io/tidystata/reference/findit.md)
does not load or install packages.

## About the notes

**Differs from Stata** flags a difference in defaults, missing-value
handling, estimation or output; the note explains it. Other notes offer
practical tips.

Execution checks test the R code, rather than numerical equivalence with
Stata. Check missing values, weights, factor reference levels, join
rules and standard errors before adapting an example. A search match
does not imply support for every option.
