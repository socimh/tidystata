## `recode`

Recode selected values with Stata rules

Stata

``` stata
recode x (1 = 10) (2 = 20), generate(z)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, z = tidystata::stata_recode(x, 1 ~ 10, 2 ~ 20))
```

Unmatched values, including missing values, are kept. Rules are compared
with the original values, so stata_recode(x, 1 ~ 2, 2 ~ 1) swaps codes.
NA ~ 0 recodes missing values, like (missing = 0).

[Stata reference](https://www.stata.com/manuals/drecode.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/stata_recode.html)

Recode ranges of values with Stata rules

Stata

``` stata
recode x (1/2 = 0) (3/6 = 1) (else = .), generate(binary)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, binary = tidystata::stata_recode(x, 1:2 ~ 0, 3:6 ~ 1, .default = NA))
```

In stata_recode() (alias recode()), 1:2 is the closed range 1 \<= x \<=
2, including decimals, like 1/2 in Stata. The first matching rule wins.
.default = NA plays the role of else = .; without it, unmatched values
are kept, as in Stata.

[Stata reference](https://www.stata.com/manuals/drecode.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/stata_recode.html)

Collapse closed numeric ranges to two groups

Stata

``` stata
recode x (1/2=0) (3/6=1), generate(binary)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, binary = tidystata::stata_recode(x, 1:2 ~ 0, 3:6 ~ 1))
```

Rules include both endpoints and decimal values; unmatched values stay
unchanged.

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/stata_recode.html)

## `xi`

Create indicator variables omitting the lowest category

Stata

``` stata
xi i.g
```

R `tidystata`

``` r

data <- dplyr::select(tidystata::as_dummy(data, g, .names = "index"), -tidyselect::any_of("g_1"))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Keeps the original columns and omits the first observed category.
Numeric categories are ordered by value; R factors follow their level
order, which must match Stata's omitted category. Stata names indicators
by category code; R numbers observed categories with .names="index". Use
factor(g) in models; xi: interactions are not reproduced.

[Stata reference](https://www.stata.com/manuals15/rxi.pdf) · [R
reference](https://socimh.github.io/tidystata/reference/as_dummy.html)
