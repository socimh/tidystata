## `svy`

Survey-weighted logit

Stata

``` stata
svy: logit y x
```

R `survey`

``` r

survey::svyglm(y ~ x, design = design, family = quasibinomial())
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Match design and missing-data exclusions first; singleton-PSU policy,
degrees of freedom and confidence-interval transformations can differ
between R and Stata.

[Stata reference](https://www.stata.com/manuals/svysvy.pdf) · [R
reference](https://cran.r-project.org/package=survey)

2 more examples and alternatives

Subpopulation estimate

Stata

``` stata
svy, subpop(rural): mean x
```

R `srvyr`

``` r

design |> filter(rural == 1) |> summarise(x = srvyr::survey_mean(x, na.rm = TRUE))
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Filtering a survey design keeps the full design for the variance, as
subpop() does. Match design and missing-data exclusions first;
singleton-PSU policy, degrees of freedom and confidence-interval
transformations can differ between R and Stata.

[Stata reference](https://www.stata.com/manuals/svysvy.pdf) · [R
reference](https://cran.r-project.org/package=srvyr)

## `svyset`

Declare a survey design

Stata

``` stata
svyset psu [pweight = wt], strata(stratum)
```

R `srvyr`

``` r

design <- srvyr::as_survey_design(data, ids = psu, strata = stratum, weights = wt, nest = TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Stratified PSU probability-weighted design; nests PSU IDs within strata
as Stata does. Inference requires the same sample, singleton-PSU policy
and design df.

[Stata reference](https://www.stata.com/manuals/svysvyset.pdf) · [R
reference](https://cran.r-project.org/web/packages/srvyr/srvyr.pdf)
