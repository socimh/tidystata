## `mhodds`

Mantel-Haenszel common odds ratio

Stata

``` stata
mhodds case exposed stratum
```

R `stats`

``` r

stats::mantelhaen.test(tabs, correct = FALSE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Fixed workflow; adapt the named data columns explicitly. Table
orientation determines the odds-ratio direction; assumes a common
stratum effect.

[Stata reference](https://www.stata.com/manuals/repitab.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/00Index.html)
