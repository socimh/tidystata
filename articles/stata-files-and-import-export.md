## `checksum`

Compute a file integrity digest

Stata

``` stata
checksum sample.txt
```

R `tools`

``` r

tools::md5sum(src)
```

MD5 is a workflow alternative: Stata checksum uses POSIX CRC, so digest
values are not comparable.

[Stata reference](https://www.stata.com/manuals/dchecksum.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/tools/html/md5sum.html)

Save a file digest in a sidecar text file

Stata

``` stata
checksum sample.txt, saving(sample.sum)
```

R `tools`

``` r

digest <- tools::md5sum(src); writeLines(unname(digest),dst)
```

Writes an R MD5 sidecar, not a Stata .sum file; Stata cannot validate
this format as its CRC sidecar.

[Stata reference](https://www.stata.com/manuals/dchecksum.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/tools/html/md5sum.html)

## `copy`

Copy a local file to a new path

Stata

``` stata
copy source.txt destination.txt
```

R `base`

``` r

file.copy(src,dst,overwrite=FALSE)
```

src and dst are temporary paths in this runnable fixture; no network
transfer is involved.

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Overwrite a destination file with a local copy

Stata

``` stata
copy source.txt destination.txt, replace
```

R `base`

``` r

file.copy(src,dst,overwrite=TRUE)
```

Demonstrates overwrite on newly created temporary files only.

[Stata reference](https://www.stata.com/manuals/d.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `filefilter`

Replace literal text throughout a small file

Stata

``` stata
filefilter source.txt destination.txt, from("old") to("new")
```

R `base`

``` r

writeLines(gsub('old','new',readLines(src),fixed=TRUE),dst,useBytes=TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Line-oriented small-file workflow; binary patterns and large-file
streaming are not covered.

[Stata reference](https://www.stata.com/manuals/dfilefilter.pdf) · [R
reference](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

Replace tab separators in a text file

Stata

``` stata

```

R `base`

``` r

writeLines(gsub('\t',';',readLines(src),fixed=TRUE),dst,useBytes=TRUE)
```

[Differs from
Stata](https://socimh.github.io/tidystata/articles/coming-from-stata.html#example-labels)
Literal small-text-file replacement; quoted delimiters in tabular data

[Stata reference](https://www.stata.com/manuals/dfilefilter.pdf) · [R

## `jdbc`

Stata

``` stata

```


not ODBC/JDBC driver connection; use an appropriate DBI backend in
production.

reference](https://dbi.r-dbi.org/reference/index.html)
