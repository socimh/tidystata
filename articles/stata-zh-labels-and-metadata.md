## `char`

查看自定义列特征

Stata

``` stata
char list x[]
```

R `base`

``` r

attributes(data$x)
```

返回全部 R 属性，包括自定义元数据。

[Stata 参考](https://www.stata.com/manuals/p.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

保存自定义列特征

Stata

``` stata
char x[source] "questionnaire"
```

R `base`

``` r

attr(data$x,'source') <- 'questionnaire'
```

R 属性可用作本地元数据；许多变换不保留任意属性。

[Stata 参考](https://www.stata.com/manuals/p.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `decode`

将数值标签解码为文本

Stata

``` stata
decode x, generate(text)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, text = tidystata::decode(x))
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/type_conversion.html)

## `encode`

按排序顺序编码非空类别

Stata

``` stata
encode s, generate(code)
```

R `tidystata`

``` r

data <- dplyr::mutate(data, code = tidystata::encode(s))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
字符输入按 UTF-8 基数排序从 1 分配新编码；NA 和空字符串视为缺失。可能与
Stata 的区域排序不同。因子输入保留原编号和全部水平。

[Stata 参考](https://www.stata.com/manuals/dencode.pdf) · [R
参考](https://socimh.github.io/tidystata/reference/type_conversion.html)

## `label`

附加数值标签字典

Stata

``` stata
label values x yesno
```

R `haven`

``` r

data$x <- haven::labelled(data$x,labels=yesno)
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://haven.tidyverse.org/reference/index.html)

另有 6 个示例及替代实现

添加数据集标签

Stata

``` stata
label data "Research sample"
```

R `base`

``` r

attr(data,'label') <- 'Research sample'
```

固定流程示例；更改时需同时调整对象名与列名。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

定义可复用的数值标签映射

Stata

``` stata
label define yesno 1 "No" 2 "Yes"
```

R `base`

``` r

yesno <- c(No=1,Yes=2)
```

R 将映射存为命名向量；需分别附加到各标签列。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

读取列的数值标签映射

Stata

``` stata
label list yesno
```

R `base`

``` r

attr(data$x,'labels')
```

固定流程示例；更改时需同时调整对象名与列名。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

删除数值标签并保留数值

Stata

``` stata
label values x
```

R `haven`

``` r

data$x <- haven::zap_labels(data$x)
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://haven.tidyverse.org/reference/index.html)

删除变量标签

Stata

``` stata
label variable x ""
```

R `base`

``` r

attr(data$x,'label') <- NULL
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

添加描述性变量标签

Stata

``` stata
label variable x "Response"
```

R `base`

``` r

attr(data$x,'label') <- 'Response'
```

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `labelbook`

逐列查看数值标签字典

Stata

``` stata
labelbook
```

R `base`

``` r

lapply(data,function(z) attr(z,'labels'))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
列出已附加字典；不复制 Stata 完整的多语言标签检查。

[Stata 参考](https://www.stata.com/manuals/dlabelbook.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `labmask`

将已有文本值设为数值标签

Stata

``` stata
labmask code, values(text)
```

R `haven`

``` r

dictionary <- unique(data[c('code','text')]); stopifnot(!anyDuplicated(dictionary$code)); data$code <- haven::labelled(data$code,stats::setNames(dictionary$code,dictionary$text))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
要求每个数值编码唯一对应一个文本标签；保留所给数值编码，不按文本字母顺序重新编码。

[Stata
参考](https://journals.sagepub.com/doi/pdf/10.1177/1536867X0800800208) ·
[R 参考](https://haven.tidyverse.org/reference/index.html)

## `notes`

读取一列的注释

Stata

``` stata
notes list x
```

R `base`

``` r

attr(data$x,'notes')
```

读取自定义 R notes 属性；后续操作是否保留取决于变换方式。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

为一列附加文本注释

Stata

``` stata
notes x: Measured at baseline
```

R `base`

``` r

attr(data$x,'notes') <- 'Measured at baseline'
```

使用 R 属性保存；不复刻 Stata 编号注释管理。

[Stata 参考](https://www.stata.com/manuals/d.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `numlabel`

给每个标签添加数值编码前缀

Stata

``` stata
numlabel, add
```

R `base`

``` r

labs <- attr(data$x,'labels'); names(labs) <- paste0(unname(labs),'. ',names(labs)); attr(data$x,'labels') <- labs
```

固定流程示例；更改时需同时调整对象名与列名。

[Stata 参考](https://www.stata.com/manuals/dlabelbook.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

删除已知格式的编码标签前缀

Stata

``` stata
numlabel, remove
```

R `base`

``` r

labs <- attr(data$x,'labels'); names(labs) <- sub('^[0-9]+[.] ','',names(labs)); attr(data$x,'labels') <- labs
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
仅处理示例中的正整数前缀格式；其他格式需调整匹配模式。

[Stata 参考](https://www.stata.com/manuals/dlabelbook.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)

## `uselabel`

生成数值标签字典表

Stata

``` stata
uselabel using sample.dta, clear
```

R `base`

``` r

labs <- attr(data$x,'labels'); dictionary <- data.frame(lname='x',value=unname(labs),label=names(labs),trunc=0L)
```

使用已导入的标签列。R 无独立 Stata 标签定义名；lname 使用列名。

[Stata 参考](https://www.stata.com/manuals/dlabelbook.pdf) · [R
参考](https://stat.ethz.ch/R-manual/R-devel/library/base/html/00Index.html)
