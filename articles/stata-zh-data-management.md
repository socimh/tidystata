## `cf`

``` stata

```

``` r

which(data$x != other$x | xor(is.na(data$x),is.na(other$x)))
```

有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)

## `cumul`

生成变量的经验累积分布

Stata

``` stata
cumul x, generate(c)
```

R `dplyr`

``` r

data$c <- dplyr::row_number(data$x) / sum(!is.na(data$x))
```

[与 Stata
有差异](https://socimh.github.io/tidystata/articles/coming-from-stata-zh.html#example-labels)
缺失值仍为缺失，且不计入分母。Stata
默认对相同取值按任意顺序赋予不同的累积值，R 按行顺序处理相同取值。权重及
by() 需另行按组或加权计算。

[Stata 参考](https://www.stata.com/manuals/rcumul.pdf) · [R
参考](https://dplyr.tidyverse.org/reference/row_number.html)

相同取值共享累积值的经验累积分布

Stata

``` stata
cumul x, generate(c) equal
```

R `dplyr`

``` r

data$c <- dplyr::cume_dist(data$x)
```

相同取值共享最大的累积比例，与 ecdf(x)(x) 相同；缺失值仍为缺失。

[Stata 参考](https://www.stata.com/manuals/rcumul.pdf) · [R
参考](https://dplyr.tidyverse.org/reference/percent_rank.html)
