# tidystata: Tidy Tools Inspired by 'Stata'

Stata-inspired tools for frequency tables, summary statistics, variable
inspection, column selection, row calculations, and binning. Use
[`tab()`](https://socimh.github.io/tidystata/reference/tab.md),
[`summ()`](https://socimh.github.io/tidystata/reference/summ.md), and
[`codebook()`](https://socimh.github.io/tidystata/reference/codebook.md)
to start exploring a dataset.

Coming from Stata?
[`findit()`](https://socimh.github.io/tidystata/reference/findit.md)
gives the R equivalent of a Stata command, such as `findit(reg)` or
`findit("merge 1:1 id")`.

## Tutorials

Read

for a short workflow and
[`vignette("containers-and-missing-values", package = "tidystata")`](https://socimh.github.io/tidystata/articles/containers-and-missing-values.md)
for output containers, grouping and missing-value conventions.
